# 일본숙소 — 3-2단계 썸네일 이미지

작성: solhee 방 / 2026-09-17 축 신설
낱장: `표지_2줄`(또는 `표지_3줄`) 배경 · `CTA` 배경

## 이 단계에서 하는 일

3-1 확정 훅과 어울리는 **인물 5장 + 호텔 5장을 생성**해 **갤러리 링크 하나**로 전달한다.

## 이미지

- `generate_image` 로 **10장을 한 번에** 만든다(`prompts` 에 10개) → `make_gallery` 로 묶어 **링크 하나**만 준다. jpg·png 파일은 보내지도 안내하지도 않는다.
- **인물 5장** — 주제와 관련된 장면에 인물이 들어간 컷(객실 창가 · 라운지 · 로비 · 호텔 앞 거리 등). 인물 지정이 없으면 20대 한국인 여자.
- **호텔 5장** — 주제와 관련된 호텔 컷(외관 · 객실 · 창밖 뷰 · 수영장 · 조식 등). 사람을 넣지 않는다.
- 방 지침서의 **이미지 품질(인물·풍경)** · **중앙 1:1 구도** 문장을 프롬프트에 그대로 넣는다.
- ⚠ **생성한 호텔은 실제 그 호텔이 아니다.** 호텔 이름·간판·로고를 그리지 않는다(배경에 글자를 넣지 않는 규칙과 같다).
- 만든 뒤 Read 로 열어 기준에 맞는지 보고, 안 맞는 장만 다시 그린다.

## 비율·구도 (2026-09-17 사람 지시)

- **모든 이미지는 4:5** (표지 1080×1350).
- 메인 영역(인물 얼굴 · 중심 건물)은 **중앙 1:1 안**에 들어오게.
- **배경은 잘리지 않고 자연스럽게 이어지게** — 여백·띠 없이 가장자리까지.
- 생성 크기가 1024×1536(2:3)이면 4:5 로 깔 때 위아래가 잘린다. 잘려도 주요 피사체가 남는지 본다.

## 지도 이미지 — ⚠ 사람 확인 대기

사람이 준 안에 「해당 관광지 5개가 모두 지도에 표시한 이미지 생성」 이 있다.
이 축의 소재는 관광지가 아니라 숙소이고 수도 1곳·8곳이라 **무엇을 몇 곳 표시할지 문장만으로는 알 수 없다.**
사람에게 확인해 여기에 적는다. 확인 전에는 인물 5 + 호텔 5 만 만든다.

## 고른 1장은 두 곳에 같이

- 사람이 고른 **1장**을 **표지와 `CTA` 배경에 같은 값**으로 쓴다(방 지침서 「이미 정해진 것」). 같은 장면을 다시 생성하지 않는다.
- `CTA` 는 템플릿 그림(70% 검정 판)이 덮어 사진이 옅게만 비친다. 고를 때는 **표지에서 훅 글자(아래쪽 y 825~) 뒤가 읽히는지**를 본다.
