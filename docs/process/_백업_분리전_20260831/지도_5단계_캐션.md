# 지도 — 5단계 캐션

작성: solhee 방 / 갱신 **2026-08-26 — 캐션을 고정 틀로 바꿈. 자유 작문 6원칙은 이 축에서 폐기**
**2026-08-27 틀 2줄 수정** — 3-1 훅 2줄이 「지역 + 카테고리 + 지도/공유/모음 + 이모티콘」 구조로 바뀜 데 맞춤
최신 회차: 2026-08-27 (도쿄 쇼와 킷사텐 · 캐러셀 432)

## 이 단계에서 하는 일

편집 링크를 전달한 뒤 **인스타 캐션(게시물 본문) 문구를 만들지 사람에게 묻는다.**
**이 질문은 4단계에서 링크를 보내는 그 메시지에 붙여서 한다** — 따로 한 턴을 더 쓰지 않는다.
묻지 않고 미리 만들어 두지 않는다.

## 캐션 틀 — 고정 (2026-08-26 확정 · 2026-08-27 2줄 수정)

**새로 작문하지 않는다.** 아래 틀에 그 회차 문구를 끌어다 채우는 것이 전부다.

```
[공유]
<3-1 확정 훅 문구 — 두 줄을 한 줄로 펜 것>

<3-4 CTA1 HEADLINE>

<3-4 CTA1 BODY 1줄>
<3-4 CTA1 BODY 2줄>

#해시태그1 #해시태그2 #해시태그3
```

| 자리 | 무엇을 넣나 | 가져오는 곳 |
|---|---|---|
| 1줄 | `[공유]` — **글자 그대로 고정** | — |
| 2줄 | 훅 문구 **그대로** (뒤에 아무것도 붙이지 않는다) | [3-1](지도_3-1단계_훅문구.md) 확정 훅 |
| 3문단 | CTA1 강조 문구 | [3-4](지도_3-4단계_CTA1문구.md) `headline` |
| 4문단 | CTA1 팔로우 유도 문구 (**2줄 그대로**) | [3-4](지도_3-4단계_CTA1문구.md) `body` |
| 마지막 | 해시태그 **3개** | 봇이 주제에 맞게 |

### 2줄에 ` 맛지도 공유` 를 붙이지 않는다 (2026-08-27 변경)

예전 틀은 `<훅 문구> 맛지도 공유` 였다. **이젠 붙이지 않는다.**

- 3-1 훅 문구의 **2줄에 이미 「지역 + 카테고리 + 지도/공유/모음」 이 들어 있다**
  (2026-08-27 개정 → [3-1 문서](지도_3-1단계_훅문구.md)).
  그 뒤에 `맛지도 공유` 를 또 붙이면 `…도쿄 킷사텐 지도 ☕ 맛지도 공유` 처럼 **지도·공유가 두 번** 나온다.
- 그러니 **훅 문구를 한 줄로 펜 것으로 끝낸다.**
- 지난 회차 캐션(429·431·432)에 `맛지도 공유` 가 남아 있어도 보고 베끼지 않는다.

### 지킬 것

- **큰따옴표는 찍지 않는다** (2026-08-26 확인). 사람이 틀을 설명할 때 쓴 `"…"` 는
  **자리 표시일 뿐**이다. 캐션에는 내용만 들어간다.
- **훅 문구와 CTA1 강조 문구는 원래 2줄이지만 캐션에서는 한 줄로 펌다.**
  캐러셀의 줄바꿈을 그대로 가져오지 않는다.
- **CTA1 `body` 는 2줄 그대로** 넣는다. 계정명 `@travel.view_official` 을 빼거나 바꾸지 않는다.
  그 회차가 **개수를 비운 문장이면 캐션에도 비운 채로** 들어간다 (2026-08-27 회차 실제).
- 문구는 **3단계 산출물에서 글자 그대로** 가져온다. 캐션에서 다듬거나 줄이지 않는다.
- **캐션에서 이모지를 새로 붙이지 않는다.** 다만 **훅 문구 2줄에 들어 있는 이모티콘 하나는
  문구의 일부라 그대로 따라온다** (2026-08-27 추가). 문구를 글자 그대로 옮기는 원칙이 앞선다.
  떼지도, 더 붙이지도 않는다.
- 매장명·주소는 여전히 안 들어간다. 틀을 그대로 따르면 자동으로 지켜진다.
- 해시태그는 **3개** — 4~5개가 아니다(예전 규칙과 다르다).

> **자유 작문 6원칙은 이 축에서 쓰지 않는다.** 오프닝 장면·공감 문단·이모지·저장·친구 소환 문구를
> 직접 지어내던 방식은 2026-08-26 부로 폐기됐다. **상황별 일본어 축은 그대로 6원칙을 쓴다.**

## 새 틀로 쓴 모양 (형태 예 — 회차마다 다르다)

```

커피 한 잔 시키면 1926년이 딸려 나옵니다

#도쿄여행 #도쿄킷사텐 #도쿄카페
```
