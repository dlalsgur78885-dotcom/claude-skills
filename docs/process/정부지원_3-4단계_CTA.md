# 국내여행할인 — 3-4단계 CTA 문구

작성: solhee 방 / 2026-09-15 추가 (사람이 준 안 2차)
낱장: `CTA(정부지원)` 의 `headline` (템플릿 89 — x190 y155 폭697 · 50px 가운데, 2026-09-30 확인)

## 이 단계에서 하는 일

마지막 장에 **「주제」 신청 링크** 한 줄을 넣는다.

## 형식

| 슬롯 | 키 | 적는 것 | 예 |
|---|---|---|---|
| HEADLINE | `headline` | **「주제」 + ` 신청 링크`** | `영암 1년살이 신청 링크` |

- **받는 방식이 예약이면 `「주제」 예약 링크` 로 쓴다** (2026-10-01 사람 확정 — 「예약으로 하고 만들어줘」).
  추첨·선발로 뽑는 국내 프로그램은 그대로 `신청 링크`, 예약하면 자동으로 붙는 할인은 `예약 링크` 다.
- 사람이 준 안 그대로 — `[HEADLINE] "주제" 신청 링크`. 「주제」 자리에 **1단계에서 고른 주제**를 넣는다(큰따옴표는 자리 표시로 읽었다 — 사람이 따옴표까지 원하면 여기를 고친다).
- 템플릿 85 기준(2026-09-15): 칸 폭 920 · 높이 56 · 글자 50 · 흰 글씨 · 가운데 정렬 · y 191. **한 줄, 한글 18자 안팎**이 들어간다(폭으로 어림한 값).
  주제가 길어 넘치면 **지역 + 프로그램 이름**만 남겨 줄인다 — 예) `영암살래 1년살이 주택 3차 입주자 모집` → `영암 1년살이 신청 링크`.
- 틀이 정해진 한 줄이라 후보를 여러 개 짓지 않는다. 줄여야 할 때만 codex sol 로 짧은 이름을 받는다.
- 실제 **신청 페이지 URL** 은 3-2 에서 확인한 원문 링크다. 캐러셀에는 안 들어가지만 「이번 회차」에 함께 적어 둔다 — 캡션의 댓글 DM 으로 보낼 링크다.
