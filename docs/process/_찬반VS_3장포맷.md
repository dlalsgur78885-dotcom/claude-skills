분석해서 앞으로 템플릿 중 하나로 활용하도록 해」.

**본보기 = 캐러셀 1003**(회차 114 · 2026-10-26 · 「밥 남기고 잘 먹었다고 / 일본인들 사이에 논란」

아래 수치는 **대표가 고친 완성본 3장(2160×2700)을 직접 재서** 적었다. 괄호 안은 캔버스 1080×1350 환산값이다.

## 언제 쓰나

**예절·민폐처럼 독자가 편을 고를 수 있는 소재.** 한 장면 + 그걸 두고 갈린 일본인 반응이
있으면 된다. 쓰는 유형은 찬반이 갈리는 셋 — **커뮤화제 · 일본충격뉴스 · 일본인관점의한국**.

- **반전 소재에는 쓰지 않는다** — 반전은 「A인 줄 알았는데 B」를 2장째에 푸는 구성이 따로 있다
  ([일본커뮤니티화제](일본커뮤니티화제_유형지침.md) 「2장째」 표).
- **일본인 반응이 3~4개 안 긁히면 쓰지 않는다.** 2장째가 통째로 비는 포맷이다.
- 사진은 **한 장이면 충분하다.** 그 한 장을 세 장에서 돌려 쓴다.

## 장 구성 — 표지 + 반응 1 + 마무리 (+ CTA)

[_유형공통.md](_유형공통.md) 기본 구성(표지+본문 2+마무리)의 **본문을 한 장으로 줄인 꼴**이다.
반응 캡처를 여러 장에 흩지 않고 한 장에 몰아서 장수를 줄인다.

| 장 | 낱장(96) | 사진 | 글 |
|---|---|---|---|
| 1 표지 | `표지` | 그 장면을 **확대 크롭**해 4:5 꽉 채움 | 로고 + 흰 굵은 2줄 훅 |
| 2 반응 | `캡처카드` | **원본 그대로** 위쪽에 레터박스로 | 아래 검정에 X 캡처 3~4개 |
| 3 마무리 | **`VS마무리`** | **표지와 같은 크롭** | 가운데 `A` / `VS` / `B` + 아래 질문 한 줄 |
| 4 CTA | `CTA` | — | 기본으로 붙인다 |

### 1장 — 표지

- 로고 상단 가운데 (y 270~324 · 1080 기준 135~162).
- 훅 두 줄은 **아래쪽**에 — 1줄 y 1857~2031 · 2줄 y 2115~2289 (1080 기준 928~1144).
  글자 높이 174 = **92pt**, 줄당 **9~10자**([_유형공통.md](_유형공통.md) 표지 규격 그대로).
- **판정하는 말을 쓴다** — 「못 참는」·「최악의」. 고유명사를 범주로 올려도 된다
  (「밥 남기고 잘 먹었다고」 → 「일본인들이 못 참는 / 최악의 식사 예절」).
- **표지에서 질문을 던지지 않는다.** 질문은 3장과 캡션 끝에서만 한다.

### 2장 — 반응 (이 포맷의 핵심)

사진을 위에 깔고 **그 아래 검정에 캡처를 좌우로 어긋나게 쌓는다.** 실측값:

| 자리 | y (2160×2700) | 비율 |
|---|---|---|
| 위 검정 여백 | 0~50 | 2% |
| 사진 | 50~1184 | **42%** |
| 캡처 4개 + 사이 여백 | 1234~2666 | **53%** |

- **사진은 원본 비율 그대로** 가로 꽉 채워 레터박스로 넣는다. 표지처럼 확대하지 않는다 —
  표지에서 못 본 주변(상 위 다른 그릇·식탁)이 여기서 보여야 「진짜 사진」으로 읽힌다.
- **캡처는 폭을 맞추지 않는다.** 실측 1340~1832 (1080 기준 670~916)로 제각각이고,
  **좌·우에 번갈아 붙였다** — 1번 오른쪽 · 2번 왼쪽 · 3번 오른쪽 · 4번 왼쪽.
- **사이 여백 36~50px** (1080 기준 18~25).
- **마지막 캡처는 화면 밖으로 잘려도 된다.** 1003 의 4번째가 아래에서 잘렸다 — 「더 있다」로 읽힌다.
- 자르는 모양·개수·합치지 않기는 [_유형공통.md](_유형공통.md) 「캡처는 한 장에 셋까지」를 따른다.
  이 포맷은 짧은 반응을 모으므로 **4개까지** 올린다.
- X 로고는 **첫 캡처 오른쪽 위에 한 번만.**
- 고르는 기준 — **서로 다른 말을 하는 것만.** 1003 은 ① 강한 거부 ② 자기 경험담
  ③ 비틀기(「밥 쪽이 더 잘못했다」) ④ 사람 평가로 넷이 다 다르다. 「ㅋㅋ」류는 뺀다.

### 3장 — VS 마무리

**표지와 같은 사진** 위에 흰 글씨를 가운데 세로로 얹는다. 배경 그라데이션은 표지와 같고,
**로고는 넣지 않는다**(1003 완성본에 없다).

**낱장 `VS마무리` 를 2026-10-27 에 템플릿 96 에 넣었다.** 더 그릴 것 없이 쓰면 된다.

| 자리 | 낱장 슬롯 | 어디서 오나 |
|---|---|---|
| A — 관대한 쪽 | `headline` 76pt | 슬라이드 `headline` |
| VS | `footer` 64pt | **고정 문구** — 채울 것 없다 |
| B — 강한 거부 | `headline2` 76pt | 슬라이드 `headline2` |
| 질문 | `caption` 44pt | **고정 문구** 「여러분은 어떻게 생각하시나요?」 |

```python
{"index": 2, "type": "content",
 "headline": "그럴 수 있다", "headline2": "이런 사람하고 식사 못 한다"}
# layout_overrides {"2": "VS마무리"} · user_image_urls 에 표지와 같은 사진
```

- **A 는 관대한 쪽, B 는 강한 거부** 순서다. 길이를 맞추지 않는다.
- **B 는 13자 안쪽**이다(76pt·칸 1020px 실측 — 14자부터 두 줄로 접힌다).
- **A·B 는 2장 캡처에서 실제로 나온 말로 쓴다.** 지어내면 캡처와 따로 논다.
- 질문 줄을 바꾸려면 **편집기에서 고친다** — 고정 문구라 자동 생성이 못 덮는다.
- 원본 실측 y (2160 기준) — A 915~1071 · VS 1203~1296 · B 1395~1554 · 질문 1875~1965.

## 캡션

틀은 [준혁_캡션공통.md](준혁_캡션공통.md) 그대로다(후킹+이모지 → 사실 → 공감 → `💬` CTA ·
해시태그 없음 · 300~400자). 이 포맷에서만 더 지키는 것 둘:

- **일본인 반응을 큰따옴표로 한 문단** 넣는다 — 2장 캡처와 같은 말을 쓴다.
- **한국 쪽 공감을 한 문단** 붙여 남의 나라 이야기로 끝내지 않는다
  (「한국에서도 밥풀을 남기는 식사 습관을 좋지 않게 보는 시선이 있는 만큼」).

본보기(1003 캡션, 대표 확정본):

```
일본인들 열 받게 만든 사진 한 장 😳

식사를 마친 뒤 찍은 밥그릇 사진 한 장이 일본 SNS에서 논란이 됐습니다.

밥그릇에는 밥풀이 잔뜩 붙어 있었고, 사진에는 '잘 먹었습니다'라는 문구가 적혀 있었는데요.

이를 본 일본 네티즌들은 "예의가 없다", "자라온 환경이 보인다" 등 식사 예절을 지적하는 반응을 보였습니다.

한국에서도 밥풀을 남기는 식사 습관을 좋지 않게 보는 시선이 있는 만큼, 공감하는 분들도 있을 것 같은데요.

💬 여러분은 이렇게 밥풀을 남기는 식사 습관, 어떻게 생각하시나요?
```

## 쓸 때 체크

- [ ] 서로 다른 말을 하는 일본인 반응 **3~4개**를 긁었나
- [ ] 2장 사진은 **원본 비율**인가 (표지 크롭을 그대로 쓰지 않았나)
- [ ] 캡처를 **합치지 않고 개별 이미지**로 올렸나 — 합치면 글자를 못 읽는다
- [ ] A·B 문구가 **캡처에 실제로 나온 말**인가
- [ ] B 가 **13자 안쪽**인가 (넘으면 두 줄로 접힌다)
- [ ] 훅에 **국적·인종을 세우지** 않았나 ([_유형공통.md](_유형공통.md))
