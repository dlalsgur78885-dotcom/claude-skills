# 여행코스 — 5단계 캡션 문구

작성: solhee 방 / 2026-10-16 축 신설 (사람이 준 예시 그대로)

## 이 단계에서 하는 일

인스타그램에 올릴 **캡션**을 짓는다. 묻지 않고 바로 만들지 않고, 4단계 끝에서 만들지 물어본 뒤 쓴다.

## 고정 틀 — 다섯 덩어리 (2026-10-20 사람이 준 예시로 교체 — DM 한 줄이 위로 올라갔다)

1. **훅 한 줄** — `<지역> <기간> 여행코스 공유✨`
2. **DM 유도 한 줄** — `댓글 남겨주시면 정리 링크 보내드릴게요💌` (글자 그대로 고정 · **훅 바로 다음**)
3. **일차별 한 줄씩** — `<이모지> N일차: 코스1, 코스2, 코스3, 코스4` (본문 장수만큼 · 하루 4개 · 본문 순서 그대로)
4. **마무리 두 줄** — ① 이 코스가 어떤 코스였는지 한 줄 ② 꼭 알려야 할 주의 한 줄(없으면 ①만)
5. **해시태그 3개** — 지역·지역+기간·지역+여행코스

사람이 준 예시(2026-10-20 · 그대로 기준이다):

```
도쿄 1박 2일 여행코스 공유✨

댓글 남겨주시면 정리 링크 보내드릴게요💌

🍡 1일차: 제일 오래된 절, 이모요칸 화과자집, 줄 서는 도라야키, 노포 안미츠
☕ 2일차: 도심 숲 신사, 원조 크레페집, 식빵 베이커리, 4층 커피 로스터리

디저트 먹고 산책 코스까지 완벽하게!
우사기야는 수요일에 쉬니 그날만 피해서 가세요.

#도쿄여행 #도쿄1박2일 #도쿄여행코스
```

> **바뀐 것 두 가지(2026-10-20).** ① DM 유도가 **3줄 → 1줄**이 되고 자리도 **맨 아래 → 훅 바로 아래**로 올라갔다.
> ② 마무리가 **한 줄 → 두 줄**이 됐다 — 코스 한 줄과 주의 한 줄을 **빈 줄 없이 붙여** 쓴다.
> **옛 틀(2026-10-16~10-19)은 「동선 요약 2~3줄 + 📌 팁」 → 「일차 줄 + 마무리 1줄 + DM 3줄」 이었다.**
> 아래 「이번 회차」의 1~6회차 캡션은 **옛 틀로 지은 것**이다 — 참고할 때 섞지 않는다(6회차는 절 끝의 「새 틀로 다시」가 확정본).

## 지킬 것

- **일차 줄은 본문(3-3)과 같아야 한다.** 그날 코스 4개를 **본문 순서 그대로** 쉼표로 잇는다. 캡션에서 새 장소를 만들지 않고, 빠뜨리지도 않는다.
- **이름은 짧은 말로 줄여도 된다** — 예시의 「줄 서는 도라야키」·「4층 커피 로스터리」처럼 **그곳이 무엇인지**로 적는 쪽이 읽기 쉽다.
  장소 이름을 그대로 쓸 때는 **본문에 쓴 이름 그대로** 쓴다. 주소·역 이름은 넣지 않는다.
- **일차 줄 머리에 이모지 하나** — 그날 결에 맞는 것으로(먹는 날은 음식, 눈·산은 ❄️·🏔). 줄 안에는 더 붙이지 않는다.
- **마무리 첫 줄**은 코스 전체를 한 줄로 — 예시의 「디저트 먹고 산책 코스까지 완벽하게!」 자리다. 문장을 다 안 맺어도 되고 느낌표로 끊어도 된다.
- **마무리 둘째 줄**은 요일 휴무·품절·조기 마감처럼 **꼭 알려야 할 주의 하나**. 확인된 사실만 쓰고, 없으면 줄을 비운다. 따로 📌 줄을 만들지 않는다.
- **DM 유도는 한 줄 — 「댓글 남겨주시면 정리 링크 보내드릴게요💌」 치환 없이 그대로**, 훅 다음 자리에 둔다.
- 덩어리 사이는 **빈 줄 하나**로 띄운다. **일차 줄끼리, 마무리 두 줄끼리는 붙여 쓴다.**
- 해시태그는 **3개**. 기간은 띄어쓰기 없이 붙인다(`#삿포로2박3일`).
- 톤은 방 지침서 「문구 톤 — AI 티 안 나게」를 따른다. 일차 줄은 나열이라 톤을 타지 않지만, **마무리 첫 줄은 회차마다 결을 바꾼다.**
  - 단, **마무리 첫 줄은 사람이 준 예시처럼 짧은 감탄 맺음(「~까지 완벽하게!」)을 허용한다** — 톤 절의 「완벽한」 금지는 긴 수식 문장에 적용한다(2026-10-20).
