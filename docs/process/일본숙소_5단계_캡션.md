# 일본숙소 — 5단계 캡션 문구

작성: solhee 방 / 2026-09-17 축 신설
사람이 준 안에는 「6단계」로 적혀 있지만 5단계가 비어 있어 **5단계로 뒀다**(X인용 축과 같다).

## 이 단계에서 하는 일

4단계 편집 링크와 함께 캡션을 만들지 묻고, 만들라면 codex sol 로 짓는다. 아래 5원칙을 prompt 에 **그대로** 싣는다.

## 5원칙 (2026-09-17 사람 지시)

1. **도입부·오프닝** — 저장·팔로우·댓글을 유도하는 문구를 먼저 쓰되, **매번 같은 위치나 박제된 문장으로 쓰지 않는다.** 콘텐츠 흐름에 맞춰 자연스럽고 유연하게 배치한다.
   ⚠ **2026-09-21 개정 — 팔로우 유도는 첫 줄·첫 문단에 넣지 않는다.** 사람 지시 — 「첫번째 줄에 팔로우 유도 문구가 필수야? 너무 억지스러운데, 팔로우 유도는 마지막에 넣거나 빼줘」.
   팔로우는 **마지막 참여 유도 문단에 자연스럽게 넣거나 뺀다.** 도입은 무엇을 추천하는지로 연다(아래 「무엇을 추천하는지 바로 알게」).
2. **이모지** — 절대 고정하지 않는다. 매번 그 이미지의 분위기(충격 · 유머 · 감동 · 심각 등)에 가장 잘 맞는 것으로 다채롭게 고른다.
3. **본문** — 긴 설명이나 장황한 배경 지식은 빼고, 핵심 상황만 직관적이고 짧은 문장으로 전한다.
   억지스럽지 않은 말투로, 문단 안쪽에 공감·몰입을 부르는 **질문형 문장**을 자연스럽게 녹인다.
4. **참여 유도(CTA)** — 본문 아래에 **「저장」과 「공유(친구 소환)」 유도 문구를 반드시** 넣는다. 콘텐츠 성격에 맞게 매번 문장을 바꾼다(예시를 그대로 복사하지 말고 내용에 맞춰 새로 쓴다).
5. **해시태그·톤앤매너** — 콘텐츠와 밀접한 핵심 해시태그 **4~5개**. 설명충 같은 딱딱한 말투를 피하고 트렌디한 SNS 감성을 유지한다.

## 문단 수 · 같은 말 되풀이 (2026-09-18 사람 지시)

사람 지시 — 「본문 3문단으로」 · 「중복되는 말도 여러 번 안 들어가게」. 아래도 prompt 에 **그대로** 싣는다.

- **해시태그 줄을 뺀 글은 정확히 3문단**(빈 줄로 나뉜 덩어리) — 도입 / 본문 / 참여 유도(CTA). 문단마다 1~3줄.
  3문단 안에 도입 · 질문형 문장 · 저장·공유 유도가 모두 들어가야 한다(5원칙은 그대로다).
- **같은 낱말·표현을 여러 번 쓰지 않는다** — 4회차 첫 판에서 `저장`(도입·CTA)과 `골라요`·`골라봐요` 가 두 번씩 나왔다. 해시태그 줄은 세지 않는다.
  - 도입과 CTA 가 둘 다 저장을 말하게 되기 쉽다. **`저장` 은 CTA 에만** 쓴다. 팔로우도 도입에 넣지 않는다(2026-09-21 — 원칙 1 개정).
  - ⚠ **주제어(지역·숙소 종류·주제 — 예: `유후인`·`료칸`·`객실 온천`)는 빼지 않는다.** 되풀이를 피하려고 주제어까지 막았더니 비유만 남아
    「무슨 말인지 하나도 모르겠다」는 말을 들었다(4회차). 막는 것은 같은 동사·표현의 되풀이다.
- 돌아온 글에서 되풀이된 말을 찾으면 **네가 고치지 말고** 그 낱말을 적어 codex sol 을 다시 부른다.

## 무엇을 추천하는지 바로 알게 (2026-09-18 사람 지시)

사람 지시 — 「숙소를 추천하는 캡션 문구인데, 주제와 어울리는 인스타용 캡션 문구로」. prompt 에 **그대로** 싣는다.

- **첫 문단에서 어느 지역의 어떤 숙소를 몇 곳 모았는지, 왜 추천하는지를 바로 말한다.**
- 분위기 비유·장면 묘사만으로 채우지 않는다. 본문은 그 숙소를 고를 이유(확인한 사실)를 누구나 한 번에 알아듣게.
- 인스타그램 여행 계정이 숙소를 추천하는 말투 — 친근하고 가볍게, 그러나 뜻은 분명하게.
- 실패 예(4회차) — `둘만의 속도로 쉬고 싶은 유후인 여행이라면` · `문 닫고 말차와 간식을 곁들인 뒤, 밤엔 별빛을 따라가면 어떨까요?`
  → 무엇을(유후인 · 방에 온천 딸린 료칸 · 8곳) 왜(대욕장 안 가도 방에서 온천) 추천하는지가 안 보였다.

- 방 지침서 「문구 톤 — AI 티 안 나게」 를 prompt 에 함께 싣는다.
