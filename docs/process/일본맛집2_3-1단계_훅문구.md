> 다만 **표지 문구 규격은 이 문서가 전부 다시 정한다** — 82 의 후보 구성 틀(2줄 5 · 3줄 3 · 자유 2)은 쓰지 않는다.

## 전체 문구 스타일 — **블로그 일기체** (2026-09-28 사람 지시)

이 축의 모든 문구는 **일본 맛집을 소개하는 블로그 일기**다.
정보 전달문이 아니라 **다녀온 사람이 쓴 글**로 읽혀야 한다.

- 1인칭·구어체. 「~했어요」·「~더라고요」·「~좋았다」 처럼 쓴다.
- 광고 문구·수식어 나열 금지. 겪은 것을 말한다.
- 이모티콘·특수문자는 **표지 HEADLINE 에서** 자유롭게 쓴다. **BODY 는 한 줄에 하나까지**(2026-09-29 — 사람이 준 예시에 `🍥`·`💗` 가 있다). 나머지 칸엔 넣지 않는다.

## 표지는 네 칸을 다 채운다

82 의 표지는 HEADLINE 하나였다. **90 의 `표지` 는 네 칸이다.**

| 칸 | 넣는 것 | 분량 |
|---|---|---|
| **HEADLINE** | 훅 문구 | **1줄** |
| **SUBHEADLINE** | 날짜·시각 | 1줄 (`2026. 09. 28 15:16`) |
| **BODY** | 일기체 맛집 소개 | **3줄** |
| **TAG** | 해시태그 | **3개** |

### HEADLINE — 1줄

사람이 준 예시 그대로가 결이다.

```
나고야 맛집 정리본 ദ്ദി ´ڡ` )
내가 다녀온 후쿠오카 맛집 모음 🍚( '༥' 🥢 )
내돈내산 일본 맛집 🍛🥄
나만 알고픈 오사카 맛집 공유!
```

- **1줄이다.** 줄바꿈을 넣지 않는다(90 의 표지는 하나뿐이라 줄 수로 낱장이 갈리지 않는다).
- ⚠ **화면에서도 한 줄로 앉아야 한다** (2026-09-28 사람 지시 — 「표지 headline은 한 줄로 들어가야해」).
  템플릿 90 의 HEADLINE 칸은 **가로 920px · 글자 85px** 이라 한글이 **열 자 남짓**에서 넘친다.
  넘치면 에러가 아니라 **두 줄로 접혀** 날짜·사진 자리를 밀어낸다.
  - **한글 12자 · 공백까지 합쳐 15자 이내**로 짓는다 (2026-09-29 개정 — 「공백 포함 12자·이모지 2자」는 실제보다 빡빡했다).
    **얼굴 이모티콘·특수문자 덩어리는 글자 수에서 뺀다** — 폭이 좁아 한 줄을 넘기지 않는다.
  - 실측 근거 — 사람이 고쳐 쓴 두 표지가 둘 다 한 줄로 앉았다(저장된 줄 높이 84.75 = 한 줄).
    `오사카 야키니쿠 맛집 모음!`(한글 12·공백 3) · `나고야 스파게티 맛집 ( • ᴗ - )✧`(한글 9·공백 2 + 얼굴 이모티콘)
  - 예) `도쿄 라멘 맛집 정리본`(10자) · `내돈내산 오사카 맛집`(11자) · `나만 알고픈 교토 맛집`(11자)
  - 사람이 준 예시(`내가 다녀온 후쿠오카 맛집 모음 🍚( '༥' 🥢 )`)는 **글자 수 기준이 아니라 결의 예시**다.
    그 결을 지키되 길이는 위 한도에 맞춘다.
  - 칸을 다시 잡아 글자를 줄이면 이 한도도 함께 고친다.
- **기본 꼴은 `지역 + 소재 + 맛집` 에 `모음!` 이나 얼굴 이모티콘을 붙이는 것이다** (2026-09-29 개정 —
  사람이 고쳐 쓴 644·645 가 둘 다 이 꼴이다: `오사카 야키니쿠 맛집 모음!` · `나고야 스파게티 맛집 ( • ᴗ - )✧`).
- 「정리본 · 모음 · 공유 · 내돈내산 · 나만 알고픈」 처럼 **저장하고 싶어지는 말**은 **선택이다.** 반드시 넣지 않아도 된다
  (2026-09-29 개정 — 전에는 넣으라고 했으나 사람이 고친 둘 다 소재를 앞세웠다).
- 이모티콘·특수문자(`ദ്ദി ´ڡ` )` 같은 얼굴 이모티콘 포함)는 **여기서만** 쓴다. 한 줄에 한 덩어리면 충분하다.
- 후보는 **10개**를 내고 사람이 고른다.

### SUBHEADLINE — 날짜·시각

**`YYYY. MM. DD HH:MM`** 한 줄. 예: `2026. 09. 28 15:16`

- **날짜는 만드는 날(생성일) 기준**이다. 지어내지 않는다.
- **시각은 무작위**다. 블로그 글이 올라간 시간처럼 보이게 하는 장치다.
- 초·요일·「오전/오후」는 붙이지 않는다.

### BODY — 일기체 소개 3줄 (2026-09-29 사람 지시로 전면 개정)

사람 말 그대로 — 「표지 body 문구도 좀 더 자연스러운 소개 문구로」. **사람이 준 예시 셋이 기준이다**(`/` 는 줄바꿈 자리).

```
미식도시 나고야 맛집 알짜배기만 빠르게 정리해볼게요🍥
나고야에서는 줄서는 맛집보다 현지인 맛집이 찐!
그래서 그런지 가는 곳마다 존맛; 사실 내가 보려고 쓰는 글
```

```
분위기, 맛 둘 다 포기할 수 없는 사람의 도쿄 여행
3박 4일간 다녀온 곳 중 좋았던 곳만 공유드립니다
그래서 내가 뭐 먹었냐면..
```

```
후쿠오카만 10번 다녀온 사람의 맛집 공유!
한국인 입맛 저격하는 찐 맛집만 모아모아💗
저장해두고 여행 전 꺼내보세요!
```

**사람이 직접 고쳐 쓴 표지 둘도 같은 자격의 기준이다** (2026-09-29 — 캐러셀 644 · 645).

```
직접 다녀온 오사카 야키니쿠 맛집 모음!
한국에 돌아온 지금까지 못잊는 이 맛,,
심지어 구글 평점 4.7 이상이라는 거 믿먹ㄱ
```

```
스파게티에 환장하는 1인의 나고야 스파게티 맛집 모음!
3박 4일동안 스파게티만 5번 먹음ㅋㅋ
이렇게까지 먹을 줄은 나도 몰랐지..
```

- **3줄 고정.** 줄마다 한 호흡으로 끊는다.

**줄 순서 틀은 폐기다.** 「1줄 무엇인지 · 2줄 어떤 가게 · 3줄 저장 권유」로 박아 두니 회차마다 같은 글이 나왔다.
세 줄을 이 순서로 맞추지 말고, 아래를 지켜 매번 다르게 쓴다.

- **말하는 사람이 보이게 연다** — 「후쿠오카만 10번 다녀온 사람의」·「분위기, 맛 둘 다 포기할 수 없는 사람의」처럼
  **내가 누구라서 이걸 모았는지**로 시작한다. 「~를 소개합니다」·「~를 정리했습니다」 같은 정보 전달문으로 열지 않는다.
  - **가장 잘 맞는 꼴은 `내가 누구라서 + 지역·소재 맛집 모음!` 한 문장이다** (2026-09-29 — 644·645 둘 다 이 꼴).
    `직접 다녀온 오사카 야키니쿠 맛집 모음!` · `스파게티에 환장하는 1인의 나고야 스파게티 맛집 모음!`
  - **HEADLINE 과 말이 겹쳐도 그냥 둔다.** 644 는 표지 훅과 1줄이 둘 다 「맛집 모음!」으로 끝난다.
- **2줄은 다녀와서 남은 것이다** (2026-09-29 추가) — 여운(`한국에 돌아온 지금까지 못잊는 이 맛,,`) 이나
  숫자로 밝히는 기록(`3박 4일동안 스파게티만 5번 먹음ㅋㅋ`) 중 하나로 쓴다.
- **실제로 쓰는 말로 쓴다** — 찐·존맛·알짜배기·모아모아·저격처럼 구어를 써도 된다. 홍보 문구 투가 아니라 친구에게 하는 말이다.
- **맺는 줄은 넷 중 하나로** — 혼잣말(`이렇게까지 먹을 줄은 나도 몰랐지..`) · 다음 장으로 넘기기(`그래서 내가 뭐 먹었냐면..`) ·
  **자랑·근거 한마디**(`심지어 구글 평점 4.7 이상이라는 거 믿먹ㄱ` — 2026-09-29 추가) · 저장 권유(`저장해두고 여행 전 꺼내보세요!`).
  **세 줄을 모두 권유로 끝내지 않는다.**
  - **저장 권유는 필수가 아니다** (2026-09-29 개정 — 사람이 고쳐 쓴 644·645 는 둘 다 안 썼다). 저장 유도는 5단계 캡션에서 한다.
- 존댓말·반말을 한 글 안에서 섞어도 된다(예시 2·3). `!` · `..` · `;` 처럼 말하듯 끊는 부호를 쓴다.
  **`,,`·`ㅋㅋ` 같은 자음·흘린 부호와 `~먹음`·`믿먹ㄱ` 같은 음슴체·줄임말도 쓴다** (2026-09-29 추가 — 644·645 에 그대로 있다).
- **이모지는 없어도 된다** (2026-09-29 추가). 사람이 고쳐 쓴 644·645 의 BODY 에는 이모지가 하나도 없다 —
  위 「한 줄에 하나까지」는 허용이지 권장이 아니다.
- ⚠ [방 지침서](솔희_캐러셀기획.md) 「문구 톤 — AI 티 안 나게」의 **안내문 말투 금지**에서 이 칸만 예외가 하나 있다 —
  맺는 줄의 **저장 권유(`꺼내보세요!`·`저장해두고 ~`)는 사람이 준 예시라 쓴다.** 그 밖의 `~하시길 바랍니다`·`~라 할 수 있습니다` 는 그대로 금지다.

**지어내도 되는 것과 안 되는 것**

- **화자의 경험은 목소리다** — 「10번 다녀온」·「3박 4일간 다녀온 곳 중」처럼 내가 어떻게 다녀왔는지는 지어 써도 된다.
- **가게 사실은 아니다** — 지역·메뉴는 본문 8곳에 실제로 들어간 것과 맞춘다. 본문에 없는 메뉴를 표지에 적지 않는다.

### TAG — 해시태그 3개

`#나고야여행 #나고야맛집 #나고야맛집모음` 처럼 **한 줄에 3개**, 띄어쓰기로 잇는다.

- **지역 중심**으로 짠다 — 여행·맛집·맛집모음 같은 검색되는 말.
- 본문 태그와 겹쳐도 된다. 다만 세 개가 서로 같은 말이 되지 않게 한다.
