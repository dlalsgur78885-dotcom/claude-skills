- 대체 문장이 있다면 추가로 더 생성해도 된다.
- **각 칸은 캐러셀에 그대로 들어갈 최종 문장으로 쓴다.** 4단계에서 다듬거나 줄이지 않는다.
  4단계에서 손봐야 할 만큼 길거나 어색하면 **3-3 표 자체를 고친 뒤 넘어간다.**

#### 사람에게 보여줄 때의 형식 — 항목마다 네 줄 세로 (2026-08-21 추가)

3-3 후보를 대화로 보여줄 때는 **한 항목을 네 줄로 세로로** 쓴다. 표로 묶거나 한 줄로 이어 붙이지 않는다.

```
1. 일본어
읽는 방법
의미
사용 상황

2. 일본어
읽는 방법
의미
사용 상황
```

- 번호는 첫 줄의 **일본어 앞**에 붙이고, 나머지 세 칸은 **각각 한 줄씩** 아래로 내려 쓴다.
  순서는 항상 일본어 → 읽는 방법 → 의미 → 사용 상황.
- 항목과 항목 사이는 빈 줄로 띄운다.
- 「사용 가능한 상황」이 두 줄이면 **두 줄 그대로** 보여준다. 합쳐서 한 줄로 만들지 않는다.
- 「의미」의 큰따옴표도 보여줄 때 그대로 붙인다.
- 작품명·해설 같은 곑가지는 네 줄 안에 섞지 않는다. 할 말이 있으면 목록 아래에 따로 적는다.
- 이 규칙은 **대화로 보여줄 때**의 형식이다. 산출물 문서의 저장 형식은 그대로 둔다.

#### 「의미」(한국어 뜻)는 큰따옴표로 감싼다 (2026-08-21 추가)

한국어 의미 칸(`body`)은 **큰따옴표를 붙여 적는다.**

```
"물건을 두고 내렸어요"
"지갑이 없어요"
```

- **따옴표까지가 문자열이다.** 4단계는 3-3 표를 글자 그대로 옮기므로 스튜디오 BODY 슬롯에도 따옴표가 그대로 들어간다.
- 3-3 표에 적을 때부터 붙인다. 4단계에서 붙이거나 떼지 않는다.
- **일본어(`headline`)·읽는 방법(`subtext`)·사용 가능한 상황(`tag`) 에는 붙이지 않는다.** 의미 칸에만.
- 작은따옴표(`'…'`)나 낫표(`「…」`)로 바꿔 쓰지 않는다. 큰따옴표 하나로 통일한다.

#### 설명 문장 속 일본어는 "한국어 발음" 으로 적는다 (2026-09-03 사람 지시)

「사용 가능한 상황」처럼 **설명 문장 안에 일본어가 섞여 들어갈 때는 일본어 글자를 그대로 쓰지 않는다.**
한국어 발음으로 바꾸고 **큰따옴표로 감싼다.**

| 이렇게 쓰지 않는다 | 이렇게 쓴다 |
|---|---|
| だっけ가 붙으면 자기한테 묻는 말이 돼요 | "닷케"가 붙으면 자기한테 묻는 말이 돼요 |
| おもしろい를 확 줄인 간사이 말이에요 | "오모시로이"를 확 줄인 간사이 말이에요 |
| 笑가 w 로 줄어 草가 됐어요 | "와라이"가 w 로 줄어 "쿠사"가 됐어요 |

- 가나든 한자든 마찬가지다. 발음은 「읽는 방법」 칸과 같은 표기법으로 적는다.
- **「일본어」 칸(`headline`)은 예외다.** 그 칸은 원래 일본어를 보여주는 자리라 그대로 둔다.
- 「의미」 칸의 큰따옴표와는 붙이는 이유가 다르다. 표기는 같은 큰따옴표 하나로 통일한다.

#### 「사용 가능한 상황」 쓰는 법 (2026-08-21 추가)

**두 줄로 쓴다.** 줄바꿈(`\n`)을 넣어 두 줄을 만든다. 뭉뚝그린 한 줄("강조하고 싶을 때")로 끝내지 않는다.

| 줄 | 내용 | 끝맺음 |
|---|---|---|
| 1줄 | 언제·어디서인지 **장면**을 구체적으로 그린다 | **`~할 때` / `~일 때`** 로 끓는다 |
| 2줄 | 그때 이 말을 **어떻게 쓰는지 / 왜 필요한지** | **`~요`** 로 끝낸다 |

예:

```
에어컨 센 숙소에서 자고 목만 칼칼할 때
없는 증상을 먼저 빼 주면 감기약 대신 목약을 줘요
```

- **1줄을 억지로 해요체로 닫지 않는다.** `~할 때예요`, `~상황이에요` 처럼 늘여 붙이면 어색해진다.
  장면만 딱 끓고 설명은 2줄로 넘긴다.
- 2줄도 문어체(`~한다`)나 개조식으로 쓰지 않는다. 말하듯 `~요` 로 닫는다.
- **1줄의 장면은 「일본을 여행하는 중」에 겪는 자리로 잡는다** (2026-10-06 사람 지시).
  직장 동료·회사 휴게실·학교 교실·어학원·면접장·병원·집 안처럼 **여행 중에 있을 수 없는 자리는 쓰지 않는다.**
  같은 말이라도 쓸 자리를 여행 쪽으로 옮긴다 — 「직장 동료에게 엄마 이야기를 꺼낼 때」가 아니라
  「카페에서 친구에게 엄마 이야기를 꺼낼 때」로, 「처음 맡은 일을 시작하기 겁날 때」가 아니라
  「처음 혼자 환승하는 역 앞에서 겁이 날 때」로.
  > 이 줄이 **3-2 사진의 장면이 된다**(`studio_worker._lines_block`). 여행 밖 자리를 적으면
  > 사진이 사무실 휴게실·어학원 교실로 나온다 — 2026-10-06 실측으로 「가족 호칭」 10장 중 4장이
  > 일본 사무실 휴게실, 「자신감을 북돋는 표현」은 10장 중 7장이 어학원 교실·면접실이었다.
- **말투를 바꿀 때 어미만 갈아 끼우지 않는다** (2026-09-01 사람 지시). `~한다` 를 `~해요` 로 바꿔 다는 것으로 끝내면
  문장 구조는 문어체 그대로라 읽을 때 겉돈다. **문장 구조와 호흡을 그 말투의 성격에 맞춰 통째로 다시 쓴다** —
  어순·끊는 자리·조사·군더더기까지 손봐서 처음부터 그 말투로 쓴 문장처럼 만든다.

**→ [사용자 선택]** 어느 문장을 넣을지 사람이 고른다. 10개를 전부 쓸 수도 있다.

**넘길 때 남길 것** — 3-3 산출물에 적는다.
- 쓰는 문장 번호와 **표에 적힌 순서** (그 순서가 곹 페이지 순서다)
- **본문 낱장 = `본문(상황일본어)`**, 고른 문장 수만큼 반복
- 본문 페이지 수 / 캐러셀 총 장수 = 표지 1 + 본문 N + CTA 1
- 확정 표의 **네 칸을 칸 그대로** (4단계가 `headline`·`subtext`·`body`·`tag` 로 옮겨 담는다)

#### 문장을 확정하면 **그 자리에서 4단계를 진행한다** (2026-08-21 규칙 · 2026-08-31 순서 변경으로 3-2 썸네일 문서에서 옮겨 옴)

사람이 쓸 문장을 고른 그 순간이 3-3 의 끝이자 4단계의 시작이다. **다시 묻지 않고 이어서 만든다.**

1. 확정 표를 이 문서에 적는다. 표지·CTA 배경에 쓸 사진 URL 은 **3-2 산출물에 이미 적혀 있다** — 거기서 가져온다.
2. 바로 `generate_carousel` 로 **트래블뷰(id 80)** 템플릿을 적용해 캐러셀을 만든다.
   `slides`·`layout_overrides`·`user_image_urls` **세 인자를 함께** 넘긴다(4단계 규칙).
3. 만들어진 **편집 링크를 그 자리에서 바로 전달**하고, 같은 메시지에 **캐프션 문구도 만들지** 묻는다(5단계).
   **그 메시지는 캐러셀을 만든 메시지이므로 첫 문구는 `[4단계 — 캐러셀 스튜디오 생성]`,
   마지막 문구는 `[5단계 — 캐프션 문구] 만들까요?`** 다 (2026-08-28 추가).

- "이제 만들까요?", "템플릿은 트래블뷰로 할까요?" 처럼 **이미 정해진 것을 다시 묻지 않는다.**
  문장 확정 = 만들라는 신호다.
- 사람이 3-2 에서 **편집기에서 직접 사진을 고르겠다**고 했으면 `user_image_urls` 없이 같은 흐름으로 만들어 링크를 준다.
- 문장만 고르고 링크를 안 주는 것으로 턴을 끝내지 않는다. **선택 → 생성 → 링크**가 한 흐름이다.
