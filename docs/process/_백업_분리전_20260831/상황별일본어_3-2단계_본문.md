# 상황별 일본어 — 3-2단계 본문

작성: solhee 방 / 2026-08-31 회차
주제: **택시에서 기사님께 쓰는 일본어**
확정 훅(3-1): `일본 택시 탈 때\n꼭 필요한 말 10개` / 표지 낙장 `표지_2줄`

네 칸은 그대로 네 슬롯으로 들어간다 — 일본어 `headline` / 읽는 방법 `subtext` / 의미 `body` / 사용 가능한 상황 `tag`.
**4단계는 이 표를 글자 그대로 옮긴다.**

## 확정 — 8개 (사람이 8번·9번을 뻐다)

페이지 순서는 아래 번호 순서 그대로: 1 → 2 → 3 → 4 → 5 → 6 → 7 → 10

- 본문 낙장 = `본문(상황일본어)` × 8
- 총 장수 = 표지 1 + 본문 8 + CTA 1 = **10장**
- ⚠ 확정 훅은 "말 10개" 인데 본문은 8개다. 숫자를 맞출지 사람에게 확인 중.

### 1
- 일본어: ここで大丈夫です
- 읽는 방법: 코코데 다이조부데스
- 의미: "여기서 세워주세요"
- 사용 가능한 상황:
```
목적지 근처까지 왜는데 정확한 지점을 못 말할 때
세워달라고 길게 설명 안 해도 이 한마디면 바로 세워줘요
```

### 2
- 일본어: この住所までお願いします
- 읽는 방법: 코노 주쇼마데 오네가이시마스
- 의미: "이 주소로 가주세요"
- 사용 가능한 상황:
```
지명 발음이 자신 없어 휴대폰 지도를 내밀 때
화면을 보여주면서 말하면 발음 걱정 없이 통해요
```

### 3
- 일본어: トランク開けてもらえますか
- 읽는 방법: 토랑쿠 아케테 모라에마스카
- 의미: "트렁크 좀 열어주시겠어요"
- 사용 가능한 상황:
```
캐리어를 실어야 하는데 기사님이 그냥 앉아 계실 때
트렁크는 운전석에서 여는 거라 말하지 않으면 안 열려요
```

### 4
- 일본어: 急いでもらえますか
- 읽는 방법: 이소이데 모라에마스카
- 의미: "조금만 서둘러 주실 수 있을까요"
- 사용 가능한 상황:
```
신칸선이나 비행기 시간이 아슬아슬할 때
재촉하는 느낌 없이 부드럽게 부탁할 수 있어요
```

### 5
- 일본어: 下道でお願いします
- 읽는 방법: 시타미치데 오네가이시마스
- 의미: "일반도로로 가주세요"
- 사용 가능한 상황:
```
기사님이 "고속도로 쓸까요?" 하고 물어볼 때
고속 요금이 따로 붙어서 급하지 않으면 이렇게 답해요
```

### 6
- 일본어: カードで払えますか
- 읽는 방법: 카-도데 하라에마스카
- 의미: "카드로 낼 수 있나요"
- 사용 가능한 상황:
```
현금이 얼마 없어 타기 전에 확인하고 싶을 때
아직 현금만 받는 차가 있어서 먼저 물어보면 안전해요
```

### 7
- 일본어: 領収書もらえますか
- 읽는 방법: 료-슈-쇼 모라에마스카
- 의미: "영수증 주시겠어요"
- 사용 가능한 상황:
```
회사 경비로 올리거나 물건을 두고 내릴까 걱정될 때
영수증에 차 번호가 찍혀 있어 분실물 찾을 때 결정적이에요
```

### 8 (원래 10번 — 마지막 본문)
- 일본어: 一万円しかないんですが
- 읽는 방법: 이치만엔시카 나인데스가
- 의미: "만 엔짜리밖에 없는데요"
- 사용 가능한 상황:
```
짧은 거리인데 지갑에 큰 지폐만 있을 때
타자마자 말해 두면 기사님이 잔돈을 미리 준비해 줘요
```

## 이 단계를 하는 법 (2026-08-31 메인 지침서에서 옮겨 옴)


> 산출물: [상황별일본어_3-2단계_본문.md](상황별일본어_3-2단계_본문.md)

각 항목은 네 가지를 갖춘다: **일본어 / 읽는 방법 / 의미 / 사용 가능한 상황**
이 네 칸이 그대로 네 개의 슬롯이 된다 → [본문 4칸 ↔ 텍스트 슬롯 매핑](#본문-4칸--텍스트-슬롯-매핑-2026-08-21-추가)

- 따라 하기 쉬운 한 줄 문구로 뽑는다.
- 누구나 다 아는 쉬운 일본어는 제외한다.
- **자주 사용하는 말 위주**로 고른다.
- **오타가 없는지 확인한다.**
- **실제 일본인이 쓰는 말인지 확인한다** — 교과서에만 있는 표현이나 직역투는 빼고, 현지에서 실제로 쓰는 말로.
- 대체 문장이 있다면 추가로 더 생성해도 된다.
- **각 칸은 캐러셀에 그대로 들어갈 최종 문장으로 쓴다.** 4단계에서 다듬거나 줄이지 않는다.
  4단계에서 손봐야 할 만큼 길거나 어색하면 **3-2 표 자체를 고친 뒤 넘어간다.**

#### 사람에게 보여줄 때의 형식 — 항목마다 네 줄 세로 (2026-08-21 추가)

3-2 후보를 대화로 보여줄 때는 **한 항목을 네 줄로 세로로** 쓴다. 표로 묶거나 한 줄로 이어 붙이지 않는다.

```
1. 일본어
읽는 방법
의미
사용 상황

2. 일본어
읽는 방법
의미
사용 상황
```

- 번호는 첫 줄의 **일본어 앞**에 붙이고, 나머지 세 칸은 **각각 한 줄씩** 아래로 내려 쓴다.
  순서는 항상 일본어 → 읽는 방법 → 의미 → 사용 상황.
- 항목과 항목 사이는 빈 줄로 띄운다.
- 「사용 가능한 상황」이 두 줄이면 **두 줄 그대로** 보여준다. 합쳤서 한 줄로 만들지 않는다.
- 「의미」의 큰따옴표도 보여줄 때 그대로 붙인다.
- 작품명·해설 같은 곑가지는 네 줄 안에 섞지 않는다. 할 말이 있으면 목록 아래에 따로 적는다.
- 이 규칙은 **대화로 보여줄 때**의 형식이다. 산출물 문서의 저장 형식은 그대로 둔다.

#### 「의미」(한국어 뜻)는 큰따옴표로 감싼다 (2026-08-21 추가)

한국어 의미 칸(`body`)은 **큰따옴표를 붙여 적는다.**

```
"물건을 두고 내렸어요"
"지갑이 없어요"
```

- **따옴표까지가 문자열이다.** 4단계는 3-2 표를 글자 그대로 옮기므로 스튜디오 BODY 슬롯에도 따옴표가 그대로 들어간다.
- 3-2 표에 적을 때부터 붙인다. 4단계에서 붙이거나 떼지 않는다.
- **일본어(`headline`)·읽는 방법(`subtext`)·사용 가능한 상황(`tag`) 에는 붙이지 않는다.** 의미 칸에만.
- 작은따옴표(`'…'`)나 낫표(`「…」`)로 바꿔 쓰지 않는다. 큰따옴표 하나로 통일한다.

#### 「사용 가능한 상황」 쓰는 법 (2026-08-21 추가)

**두 줄로 쓴다.** 줄바꿈(`\n`)을 넣어 두 줄을 만든다. 뭉뚝그린 한 줄("강조하고 싶을 때")로 끝내지 않는다.

| 줄 | 내용 | 끝맺음 |
|---|---|---|
| 1줄 | 언제·어디서인지 **장면**을 구체적으로 그린다 | **`~할 때` / `~일 때`** 로 끓는다 |
| 2줄 | 그때 이 말을 **어떻게 쓰는지 / 왜 필요한지** | **`~요`** 로 끝낸다 |

예:

```
에어컨 센 숙소에서 자고 목만 칼칼할 때
없는 증상을 먼저 뺀 주면 감기약 대신 목약을 줘요
```

- **1줄을 억지로 해요체로 닫지 않는다.** `~할 때예요`, `~상황이에요` 처럼 늘여 붙이면 어색해진다.
  장면만 딱 끓고 설명은 2줄로 넘긴다.
- 2줄도 문어체(`~한다`)나 개조식으로 쓰지 않는다. 말하듯 `~요` 로 닫는다.

**→ [사용자 선택]** 어느 문장을 넣을지 사람이 고른다. 10개를 전부 쓸 수도 있다.

**넘길 때 남길 것** — 3-2 산출물에 적는다.
- 쓰는 문장 번호와 **표에 적힌 순서** (그 순서가 곹 페이지 순서다)
- **본문 낱장 = `본문(상황일본어)`**, 고른 문장 수만큼 반복
- 본문 페이지 수 / 캐러셀 총 장수 = 표지 1 + 본문 N + CTA 1
- 확정 표의 **네 칸을 칸 그대로** (4단계가 `headline`·`subtext`·`body`·`tag` 로 옮겨 담는다)
