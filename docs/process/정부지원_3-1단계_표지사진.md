낱장: `표지` 배경 · `CTA(정부지원)` 배경 (2026-09-30 템플릿 89 확인)

## 이 단계에서 하는 일

2단계 확정 훅과 어울리는 **인물 5장 + 풍경 5장을 생성**해 **갤러리 링크 하나**로 전달한다.

## 이미지

- `generate_image` 로 **10장을 한 번에** 만든다(`prompts` 에 10개) → `make_gallery` 로 묶어 **링크 하나**만 준다.
- **jpg·png 파일은 보내지 않는다 — 링크만.** 파일이 있다는 안내도 하지 않는다.
- 방 지침서의 **이미지 품질(인물·풍경)** · **중앙 1:1 구도** 문장을 프롬프트에 그대로 넣는다. 인물 지정이 없으면 20대 한국인 여자.
- 장면은 **그 지역·프로그램에 실제로 어울리는 것** — 한달살기면 시골집 마루·마을길, 템플스테이면 산사, 섬 여행이면 여객선·섬 바다.
  주제와 먼 명소로 빠지지 않는다.
- 배경 이미지에 **글자를 넣지 않는다**(훅은 텍스트 슬롯이 채운다).
- 만든 뒤 `local_path` 를 Read 로 열어 기준에 맞는지 보고, 안 맞는 장만 다시 그린다.

## 고른 1장은 두 곳에 같이

- 사람이 고른 **1장**을 **`표지` 와 `CTA(정부지원)` 의 배경에 같은 값**으로 쓴다(4단계 `user_image_urls` 의 0번·3번). 같은 장면을 다시 생성하지 않고, CTA 용 사진을 따로 고르지도 않는다.
- CTA 장 위쪽(y 191)에 흰 글씨 한 줄이 올라간다 — 고를 때 **사진 윗부분이 너무 밝지 않은지** 본다.

## 세 장은 한 세트로 보여야 한다 (2026-10-01 사람 지시)

> 사람 말 그대로 — 「생성되는 이미지는 모두 주제와 관련된 이미지인데, 표지·본문1·본문2 이미지는 결이 모두 비슷한데 다른 장면처럼 보여야 해. 한 세트로 보일 수 있도록」

- **결은 맞추고 장면만 다르게 한다.** 세 장(표지 · 본문① · 본문②)이 같은 날 같은 카메라로 찍은 것처럼 보여야 한다.
- 맞추는 것 — **시간대·광원**(한낮/아침 같은 자연광 계열로 통일. 한 장만 밤·노을로 가면 튄다) · **색 팔레트** · **계절** · **소재와 질감**(이 축이면 기와지붕·목조·노렌·돌바닥) · 사진이냐 일러스트냐.
- 다르게 하는 것 — **장소와 거리감**(실내 / 건물 외관 / 거리 전경처럼 층을 달리한다). 같은 피사체를 각도만 바꿔 반복하지 않는다.
- 기준은 **사람이 고른 표지 사진**이다. 본문① · 본문② 프롬프트에 **표지의 시간대·색·계절을 그대로 적고**, 「이 세트의 두 번째/세 번째 장면」 이라고 밝힌다.
- ⚠ 4회차에서 본문②를 해질녘 노을로 만들었다가 사람이 물렸다 — 표지(가을 낮 실내)·본문①(가을 아침 외관)과 톤이 튀어 한 세트로 안 보였다.
