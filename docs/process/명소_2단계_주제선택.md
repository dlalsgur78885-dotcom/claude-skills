# 명소 — 2단계 주제 선택

축 전체는 [솔희_축_명소.md](솔희_축_명소.md). 틀은 [일본숙소 2단계](일본숙소_2단계_주제선택.md) 와 같다.

## 이 단계에서 하는 일

사람이 고른 주제를 받아 **꼴·템플릿·장수·낱장 구성을 확정**하고 3-1단계로 넘긴다.
**주제를 바로 주면 1단계를 건너뛴다.**

## 고정값

| 항목 | 값 |
|---|---|
| 템플릿 | **트래블뷰(본문) id 101**(바탕) — 표지는 **트래블뷰(표지) 99**, CTA 는 **트래블뷰(CTA) 102** 에서 `@99:…`·`@102:…` 로 빌린다 (2026-11-05 솔희 지시) |
| 낱장 | `@99:표지_2줄` · `@99:표지_3줄` · `본문4` · `본문5` · `@102:CTA1` |
| 표지 | 훅이 2줄이면 `@99:표지_2줄`, 3줄이면 `@99:표지_3줄` (3-1 에서 고른 줄 수가 정한다) |
| 캔버스 | 1080 × 1350 |

## 주제가 꼴을 정한다

| 주제 꼴 | 꼴 | 본문 | 전체 |
|---|---|---|---|
| 지역 + 명소 분류 + 키워드 | ① 명소·전시 모음 | `본문4` × **8**(최소 5) | **10장** |
| 지역 + 행사 이름 + 기간 | ② 축제·팝업 하나 | `본문5` × **5** | **7장** |
| 지역(또는 일본 전역) + 행사 분류 + 기간 | ③ 축제·팝업 모음 | `본문4` × **5**(최소 4) | **7장** |

- ①에서 곳이 모자라면 **5곳까지** 줄여 만들고, 5곳도 못 채우면 **이 단계에서 말한다**(본문에서 터뜨리지 않는다).
- ②는 특징 5개가 공식 원문으로 받쳐져야 한다 — 모자라면 **행사를 바꾼다.**
- **③은 ①과 같은 낱장을 쓰고 `subtext` 만 주소 대신 지역 · 기간이다**(2026-11-04 · [축 문서 「세 꼴」](솔희_축_명소.md)).
  다섯 건이 **전부 진행 중이거나 시작이 30일 안**이어야 하고(2026-11-04 솔희 지시 — ③만 한 달 전부터), 넷까지 줄일 수 있다. 넷도 못 되면 이 단계에서 말한다.
- 본문 장수를 바꾸면 5단계 캡션의 목록 줄 수도 같이 바뀐다.

## 주제를 받으면 확인하는 것

- 지역·분류가 [명소_이력.md](명소_이력.md) 와 겹치지 않는지.
- **① 이면** 그 지역·분류에 명소가 장수만큼 있는지를 `place_info` 로 본다. 이미 나간 곳은
  [명소_쓴명소.md](명소_쓴명소.md) 에서 뺀다.
- **② 이면** 행사 장소 1곳의 실존·주소를 `place_info` 로 보고, **기간·요금·예약 여부**를 공식 발표로 본다.
  기간이 끝났거나 회차 올리는 날 기준으로 남은 기간이 짧으면 여기서 말한다.
- **③ 이면 다섯 건을 다** 그렇게 본다 — 건마다 공식 발표로 기간, 장소 1곳은 `place_info`.
  전역 모음이면 **다섯 건이 서로 다른 도시인지**도 본다(같은 도시가 둘이면 지역 모음으로 바꿔 받는다).
  이미 쓴 행사는 [명소_쓴명소.md](명소_쓴명소.md) 에서 뺀다.
- 주제에 쓴 지명이 [1단계 「지역」](명소_1단계_주제후보.md) 목록 안인지.
- **① 이면 키워드(셋째 칸)가 사실로 받쳐지는지** — `무료`·`전철로`·`야간개장`·`당일치기` 는 `place_info`·공식 발표로 본다.
  못 받치면 **키워드를 바꾼다**(그러면 훅도 새 키워드로 다시 짓는다).
- **주제 키워드를 고쳐 받았으면 3-1 훅 키워드도 같이 고친다** (2026-11-04 솔희 지시).
  훅을 이미 확정했어도 **새 키워드로 다시 짓는다** — 3-1 로 돌아간다. → [3-1단계](명소_3-1단계_훅문구.md)
