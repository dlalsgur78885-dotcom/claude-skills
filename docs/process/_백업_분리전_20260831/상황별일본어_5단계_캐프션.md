# 상황별 일본어 — 5단계 캐프션

작성: solhee 방 / 갱신 2026-08-31
주제: **한국인은 절대 모르는 일본어** — 캐러셀 [438](https://3-35-18-166.sslip.io:3443/editor/438)

## 확정 캐프션

```
일본어 좀 한다고 생각했는데
현지에서 말문 턱 막힌 적 있나요 🫠

교과서에 나온 말은 다 아는데
점원이 툙 던지는 한마디에서 멈추더라고요.
한국에서 배운 대로 말했다가
'그거 우리가 쓰는 말인데' 소리 들은 적도 있고요.

그래서 이번엔 아는 척하다 틀리기 쉬운 말,
번역기로는 감이 안 잡히는 말만 10개 모았어요.
1번은 아마 다들 잘못 알고 계실 거예요 👀
맞힌 분 있으면 댓글로 자랑해 주세요.

다음 일본 여행 전에 조용히 저장 📎
같이 갈 사람 태그해서 미리 맞춰두기 🧳

#일본여행 #여행일본어 #일본어회화 #일본여행팁 #현지어표현
```

## 원칙 점검

| 원칙 | 어떻게 |
|---|---|
| 오프닝 | 저장 유도를 맨 뒤로 미루고, 「앞다고 생각했는데 막혔다」는 장면을 먼저 던짐 |
| 이모지 | 🫠 👀 📎 🧳 — 앞 회차(☎️ 🔖 🫡)와 겹치지 않게 새로 골람 |
| 본문 | 설명 없이 장면만. 짧게 끊고 질문형은 오프닝 한 줄 |
| 참여 유도 | **댓글 유도를 본문 중간에** 넣어 앞 회차와 위치를 달리하고, 끝에 저장+태그 두 개 |
| 해시태그 | 5개 |
| 예시 문장 금지 | 일본어·읽는 법을 한 줄도 안 옮기고 **범위만** 말함(「10개」·「1번」) |
