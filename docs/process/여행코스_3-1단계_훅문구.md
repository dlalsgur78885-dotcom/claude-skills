# 여행코스 — 3-1단계 썸네일 훅 문구

작성: solhee 방 / 2026-10-16 축 신설

## 이 단계에서 하는 일

표지에 올릴 **훅 문구 후보 10개**를 짓는다. 사람이 하나를 고른다.

## 규격 — 3줄 고정 (사람 지시)

- **3줄. 한 줄은 공백 포함 12글자 이하.**
- 10개 **모두 3줄**이다 — 이 축 템플릿에는 표지가 `@99:표지(여행코스)` 하나뿐이라 2줄 표지가 없다.
- 줄 나눔은 **보여줄 때부터 넣을 모양 그대로** 적는다(`/` 로 줄을 끊어 보여주고, 4단계에서 `\n` 으로 넘긴다).
- 글자 칸: x80 · y510 · 폭 920 · 85px · 왼쪽 정렬 (템플릿 91 — 2026-10-16 확인).
  **글씨가 사진 가운데를 지나간다** — 3-2 에서 가운데가 복잡한 사진은 피한다.

## ⭐ 세 토막 틀 — 훅만 보고 무슨 캐러셀인지 알게 (2026-10-27 솔희님 지시)

사람 지시 — 「목표는 훅 문구만 보고 어떤건지 한 번에 알 수 있게 하는거야」. 아래 예시 여덟 개가 기준이다.

```
혼자 교토 여행 / 2박 3일 / 코스 총정리
도쿄 1박 2일 / 맛집투어 / 코스 총정리
쇼핑하러 / 나고야 1박 2일 / 코스 총정리
후지산 보러 / 시즈오카 / 당일치기 코스
인생샷 남기는 / 도쿄 3박 4일 / 여행 코스
현지인 맛집 / 오사카 2박 3일 / 먹방 코스
빵순이 필독! / 도쿄 1박 2일 / 디저트 코스
2026 삿포로 / 2박 3일 / 코스 완벽 정리
```

| 토막 | 넣는 것 | 예 |
|---|---|---|
| **소재·대상** | 무슨 여행인지 **한 단어로 못 박는다** | `맛집투어` · `쇼핑하러` · `후지산 보러` · `인생샷 남기는` · `현지인 맛집` · `빵순이 필독!` · `혼자` |
| **지역 + 기간** | 둘을 **한 줄에 붙이는 것이 기본** | `나고야 1박 2일` · `도쿄 3박 4일` · `오사카 2박 3일` |
| **코스 꼬리말** | **마지막 줄에 「코스」가 반드시 들어간다** | `코스 총정리` · `여행 코스` · `디저트 코스` · `당일치기 코스` · `코스 완벽 정리` |

- **소재는 명사로 못 박는다.** 「맛집투어」·「디저트」·「쇼핑」·「인생샷」처럼 **무엇을 하는 여행인지**가 한 단어로 보여야 한다.
  ⚠ **동작을 풀어 쓰면 안 된다** — 「혼자 골목 걷는」·「카페 들러 혼자 걷는」·「혼밥하고 걷는」은 무슨 캐러셀인지 안 보인다
  (2026-10-27 15회차 1차 결과가 여기서 물렸다). 「~걷는」·「~들러」·「~하며」 같은 풀어 쓴 동작 묘사를 첫 줄에 쓰지 않는다.
- **마지막 줄은 10개 모두 「코스」로 닫는다.** 「~ 총정리」만 쓰고 「코스」를 빼지 않는다.
- **세 토막이 줄과 1:1 로 맞지 않아도 된다.** 지역이 1줄에 붙거나(`혼자 교토 여행 / 2박 3일`) 기간이 3줄로 가도(`시즈오카 / 당일치기 코스`) 된다 — **소재 · 지역+기간 · 코스 셋이 다 보이기만 하면 된다.**
- 10개가 서로 다른 각도여야 하는 것은 그대로다 — 대상 지목 · 먹을 것 · 인생샷 · 숫자 · 동선 정리 · 연도.

## 짓는 법

- **숫자를 쓰면 실제와 맞춰야 한다** — 「12개 총정리」는 코스가 12곳(본문 장수 × 하루 코스 수)일 때만 쓴다.
- 문구 후보는 `generate_copy`(codex sol) 로 짓는다. 톤 규칙은 방 지침서 「문구 톤 — AI 티 안 나게」.

## ⭐ 깔끔하게 — 억지로 짜내지 않는다 (2026-10-22 사람 지시)

사람 지시 — 「훅 문구 너무 억지로 생성하지 말고, 깔끔하게 생성해줘」.
**아래를 `generate_copy` prompt 에 그대로 옮겨 적는다.** codex 는 이 문서를 읽지 않는다.

- **첫 줄은 평범한 말로 짧게.** 꾸며낸 신조어·유행어·과장된 비유를 만들지 않는다.
  - 나쁜 예(실제로 물린 것들) — `쇼핑파는 여기` · `편집숍 털러` · `두 손 가득` · `지갑 열고 온` · `쇼핑만 꽉 채운` · `쇼핑 동선만 쏙`
  - 좋은 예 — `쇼핑하러 가는` · `엄마랑` · `친구랑` · `처음 가는` · `백화점 둘러보는`
- **말장난·라임·의성어·강조 조사(`쏙`·`꽉`) 금지.**
- **호객·감탄 어투 금지** — 「여기!」 · 「이거 하나면」 · 「진짜」 를 붙이지 않는다.
  단 **「빵순이 필독!」처럼 대상을 지목하는 느낌표는 된다**(2026-10-27 솔희님 예시). 막는 것은 빈 감탄이지 대상 지목이 아니다.
- 한 번에 뜻이 잡히는 **평범한 한국어**로만 쓴다. 두 번 읽어야 이해되면 버린다.
- 한 줄에 **꾸밈말은 하나까지.** 수식어를 겹치지 않는다.
- **숫자는 10개 중 3개까지.** 나머지는 숫자 없이 담백하게 — 10개 중 8개에 「12곳」이 박히면
  같은 말의 되풀이로 읽힌다(2026-10-22 12회차에서 그렇게 물렸다).

> ⚠ 대신 **첫 줄이 서로 비슷해지는 쪽으로 쏠린다**(12회차 다시받기에서 7/10 이 「쇼핑~」으로 시작).
> 10개가 서로 **다른 각도**(누구와 · 무엇을 살지 · 동선 · 숫자 · 기간)여야 한다는 규칙을 함께 적는다.
