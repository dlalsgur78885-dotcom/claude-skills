대시보드의 여행 지원·할인·제도 중에서 **캐러셀 소재로 쓸 만한 주제**를 뽑아 보여준다.
**국내만이 아니다** — 사람 지시(2026-10-01)로 「국가별 제도·혜택」·「OTA·항공·카드 이벤트」 메뉴까지 포함한다.

## 소재를 어디서 가져오나

**사람 지시(2026-10-01) — 다섯 메뉴에서 가져온다.** 「국가별 제도·혜택」 · 「OTA·항공·카드 이벤트」 ·
「국내여행」 · 「시군구 정책할인」 · 「체류형 여행」. 그 전에는 뒤의 세 메뉴만 봤다.

https://marketing-dashboard-gray-nine.vercel.app/ 는 자바스크립트로 그리는 한 장 화면이라, 탭을 눌러야 목록이 나온다.
**브라우저로 열 필요 없이 탭이 읽는 JSON 을 그대로 받으면 된다**(2026-10-01 확인 — 경로는 화면 소스의 `fetch(...)` 와 같다).

- ⚠ **「체류형 여행」 은 띄어쓰기가 있다.** 사람이 준 안의 「체류형여행」 으로 찾으면 안 나온다.
- ⚠ **메뉴마다 갱신 주기가 다르다.** 위 표의 마지막 칸을 매 회차에 직접 찍어 보고, 낡은 메뉴의 「진행중」·「마감」 표시는 믿지 않는다.
  **낡았다는 이유로 그 메뉴를 건너뛰지 않는다** — 원문 링크로 지금 상태를 확인해 쓰면 된다.
- 체류형 자동 수집이 멈춰 있으면 **원문 한달러 API** 를 직접 읽는다 — `https://api.monthler.kr/programs?page=0&size=100`(최근 등록 100건), 상세 `.../programs/{id}`.
  ⚠ **`page=1` 이상은 403** 이다(2026-10-01).
- 반값여행은 대시보드가 낡아도 **원문 https://korean.visitkorea.or.kr/dgtourcard/tour50.do** 에 지역별 「신청접수중·준비중·마감」과 차수가 나온다.

## 고르는 순서

1. **최근 업데이트된 내용** 우선 — 탭의 「마지막 수집」·「기준일」 이 늦은 쪽, 그 안에서는 **모집 시작·등록이 늦은 순**.
2. 캐러셀 소재로 쓸 만한 것 — 지원 금액이 크거나 「전액」·「반값」·「무료 숙소」 처럼 한눈에 이득이 보이는 것.

- **이미 끝난 모집은 뺀다** — 마감일이 오늘보다 앞이면 제외. 오늘 마감이면 「오늘 마감」 으로 드러낸다.
- **아직 접수 전인 것은 「오픈일이 2주 안 + 날짜 확정」 만 올린다** (2026-10-06 사람 지시).
  날짜가 안 잡힌 것(「10월 중순 예정」)과 오픈까지 2주 넘게 남은 차수는 뺀다 — 뺄 때 「접수 10/26 시작 — 아직 접수 전」 처럼 이유를 적는다.
- **대시보드 상태 표시(진행중·차수 마감)를 믿지 않는다.** 대시보드가 멈춰 있으면 표시도 낡는다 — 후보에 올릴 것은 **카드의 신청·상세 링크(원문)를 열어** 지금 모집 중인지 본다.
  원문을 못 열면 후보 표에 「원문 미확인」 으로 적는다.

## 후보

- **1 주제 = 이벤트(프로그램) 1건.** 낱장이 `본문(국내할인)_1` · `본문(국내할인)_2` 한 쌍뿐이라 캐러셀은 **표지 1 + 본문 2 + CTA 1 = 4장**이다.
- 개수는 사람이 정하지 않았다 — **다른 축과 같게 10개**로 보여준다. 사람이 바꾸면 여기를 고친다.
- 주제 문구는 **지역 · 프로그램 · 지원 규모**가 보이게 — 예) `영암 1년살이 주택 입주자 모집`, `섬 여행 경비 10만원 지원`
- 주제 문구는 codex sol 로 짓는다(방 지침서 「문구 후보는 codex sol 로 짓는다」). 이벤트를 고르는 것은 봇이 한다.
- 표에 탭 · 대시보드 기간 · 원문 확인 여부를 함께 적는다.
- **접수 전인 건은 「모집」 칸 맨 앞에 접수 시작일·시각을 적는다** — 예) `접수 10/12 10:00 시작 · ~10/13`.
