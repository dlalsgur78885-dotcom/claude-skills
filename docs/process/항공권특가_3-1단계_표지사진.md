## 이 단계에서 하는 일

1. 훅과 어울리는 **풍경 이미지 5장 생성 → 갤러리 링크 하나로 전달**(비행기·하늘·그 여행지 풍경 등).
2. 표지 둥근 칸에 넣을 **항공권 목록 캡처**를 찍는다.

## 배경 이미지

- **jpg·png 파일은 보내지 않는다 — 링크만.**
- 방 지침서의 이미지 품질 · **중앙 1:1 구도** 규칙을 프롬프트에 넣는다. 만든 뒤 가운데 정사각형 경계를 그어 보고 벗어난 장만 다시 그린다.
- 고른 1장은 **표지와 CTA 배경에 같이** 쓴다(사람 지시 — 「표지 이미지를 CTA 배경에도 같은 사진맞아」). 같은 장면을 다시 생성하지 않는다.

## 표지 둥근 칸 — 항공권 목록 캡처

- 그 주제의 항공권 목록을 수집 페이지에서 캡처한다 — `flightCrash.apsl?dep=&arr=<코드>` 를 열어 최저가 카드를 찍는다.
  ⚠ 사람이 처음 준 `cordix.org` 는 로그인이 필요해 **로그인 화면이 찍힌다.** railway 주소에서 찍는다.
- 칸 비율 **880×600**(1.47:1)로 자른다(2026-09-30 확인 — 880×320 은 옛 값). 옆 카드가 비치면 흰색으로 지운다.
- **캡처는 `items` 한 개**로 넣는다 — `user_item_image_urls: {"0": {"0": 캡처}}` · `slides[0].items: [{}]`.
  로고에는 이제 템플릿 그림이 들어 있어 사진 자리로 세지 않는다(렌더러는 빈 칸이 하나라도 있으면 **빈 칸만** 짝짓는다 — `backend/app/services/carousel_renderer.py`).
  옛 규칙 `{"0":{"0":로고,"1":캡처}}` 로 넣으면 **로고가 둥근 칸에 들어가고 캡처는 사라진다.**
