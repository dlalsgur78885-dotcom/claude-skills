# 일본맛집 — 4단계 캐러셀 스튜디오 생성, 편집 링크 전달

작성: solhee 방 / 2026-08-31 축 신설

> **공통 규칙은 [지도_4단계_편집링크.md](지도_4단계_편집링크.md) 를 그대로 따른다.**
> 문구를 글자 그대로 옮기는 원칙·한글 오타 대조·낱장 이름 오타가 조용한 폴백이라는 이야기는 거기 한 벌만 둔다.
> **이 문서에는 다른 것만 적는다.**

## 이 단계에서 하는 일

3단계 결과(3-1 훅 문구 · 3-2 표지 사진 1장 · 3-3 본문 8곳과 가게 사진)를 스튜디오에 올리고 **편집 링크**를 준다.
**링크에서 사람이 낱장별로 문구·사진을 개별로 고친다.**

**시작 신호는 3-3 본문 확정이다.** 지도 축은 3-4 CTA1 문구 확정이 방아쇠였지만 **이 축엔 3-4 가 없다.**
본문과 사진이 확정되면 확인 없이 바로 이 단계로 들어온다.
"이제 만들까요?", "템플릿은 트래블뷰(맛집)으로 할까요?" 처럼 **이미 정해진 것을 다시 묻지 않는다.**

## 지도 축과 다른 점 — 이 표가 우선한다

| 항목 | 지도 축 | 일본맛집 축 |
|---|---|---|
| 시작 신호 | 3-4 CTA1 문구 확정 | **3-3 본문 확정** |
| 템플릿 | 81 | **82 (트래블뷰(맛집))** |
| 총 장수 | 6장 | **10장** (표지1 + 본문8 + CTA1) |
| 표지 SUBHEADLINE | 있다(`장소 N개 · …`) | **없다** — 낱장에 그 자리가 없다 |
| 칸(`items`+`user_item_image_urls`) | `CTA1` 에 쓴다 | **안 쓴다** — 전부 배경(`user_image_urls`) |
| 낱장 이름 | `표지_지도`·`본문_지도`·`CTA1`·`CTA2` | **`표지_2줄`/`표지_3줄`·`본문(맛집)`·`CTA`** |

## 문구는 3단계 산출물에서 **글자 그대로** 옮긴다

**4단계에서 문구를 새로 쓰거나 다듬지 않는다.** 복사해 붙이는 것이 전부다.

| 가져오는 곳 | 순번 | `slides` 키 | 슬롯 역할 |
|---|---|---|---|
| 3-1 확정 훅 문구 (줄바꿈 `\n` 그대로) | 0 | `headline` | HEADLINE |
| 3-3 매장명 | 1~8 | `headline` | HEADLINE |
| 3-3 📍위치 (우편번호 `〒` 포함) | 1~8 | `subtext` | SUBHEADLINE |
| 3-3 특징 설명 **3~4줄** | 1~8 | `body` | BODY |
| — (문구 없음) | 9 | `headline: ""` | — |

- **표지에는 `subtext` 를 넣지 않는다.** 이 축 표지 낱장에는 SUBHEADLINE 자리가 없다
  (2026-08-31 사람 지시). 지도 축의 `장소 N개 · …` 줄을 버릇처럼 가져오지 않는다.
- **표지 낱장은 3-1 훅이 몇 줄이냐로 정해진다** — 2줄이면 `표지_2줄`, 3줄이면 `표지_3줄`.
- **본문은 세 칸이다.** 매장명·위치·특징을 `body` 하나에 밀어 넣지 않는다.
- 위치 칸의 **일본어 주소도 한 글자도 고치지 않는다.**
- **키 이름 주의**: SUBHEADLINE 슬롯이 읽는 값은 `subheadline` 이 아니라 **`subtext`** 다
  (`backend/app/services/carousel_renderer.py:106-125`).

### CTA(순번 9)에는 **문구를 넣지 않는다** (2026-08-31 사람 지시)

사람 말 그대로 — 「맛집 캐러셀에 CTA 문구 없어도돼」. 마지막 장은 **3-2 인물 사진 배경만** 나간다.

- 그래도 **슬라이드 자리는 채운다** — `{ headline: "", type: "cta" }`.
  슬라이드를 통째 빼면 순번이 앞으로 밀려 `layout_overrides` 의 `"9"` 가 어깋난다.
- 지도 축의 `@travel.view_official …` 고정 문구를 가져오지 않는다 — 그건 `CTA1` 낱장 규칙이다.
- 저장·공유 유도는 **5단계 캐프션**에서 한다 → [일본맛집_5단계_캡션.md](일본맛집_5단계_캡션.md)

## 낱장 배치

| 순번 | 재료 | 낱장 | 이미지 |
|---|---|---|---|
| 0 | 3-1 확정 훅 문구 | `표지_2줄` (훅이 3줄이면 `표지_3줄`) | 3-2 확정 인물 사진 — **배경** |
| 1 ~ 8 | 3-3 확정 본문 8곳 (한 곳 = 한 장) | `본문(맛집)` | 그 가게 확정 사진 — **배경** |
| 9 | **문구 없음** (`headline: ""`) | `CTA` | 3-2 확정 인물 사진 (표지와 **같은 1장**) — **배경** |

캐러셀 총 장수 = **10장**

- **표지(0)와 `CTA`(9)에는 같은 URL 을 넣는다** (사람 지시 — "표지, CTA 동일한 사진으로").
  그 1장은 **3-2 에서 생성한 인물 이미지**다. 본문 8장은 `place_info` 로 받은 **실제 가게 사진**다. 섞지 않는다.
- **칸 방식(`items` + `user_item_image_urls`)은 이 축에서 쓰지 않는다.** 그건 지도 축 `CTA1` 전용이었고,
  이 축엔 `CTA1` 이 없다. 전부 배경이다.

## 세 인자를 **반드시 함께 넘긴다**

| 인자 | 안 넘기면 |
|---|---|
| `slides` | 서버가 문구를 **새로 지어낸다.** 3단계 확정본이 사라진다 |
| `layout_overrides` | **10장이 전부 표지로 렌더된다** |
| `user_image_urls` | 표지·본문·CTA **배경이 빈 채로** 나온다 |

```
generate_carousel(
  topic: "…",
  template_id: 82,
  slides: [
    { headline: "<3-1 확정 훅 1줄>\n<2줄>", type: "cover" },
    { headline: "<매장명1>", subtext: "📍<주솄1>", body: "<특징 3~4줄>" },
    … 8번째까지 같은 모양 …
    { headline: "", type: "cta" }   // 문구 없음 — 자리만 채운다
  ],
  layout_overrides: {
    "0":"표지_2줄",
    "1":"본문(맛집)", "2":"본문(맛집)", "3":"본문(맛집)", "4":"본문(맛집)",
    "5":"본문(맛집)", "6":"본문(맛집)", "7":"본문(맛집)", "8":"본문(맛집)",
    "9":"CTA"
  },
  user_image_urls: {
    "0":"https://…3-2 확정 인물 사진",
    "1":"https://…매장1 사진", …, "8":"https://…매장8 사진",
    "9":"https://…3-2 확정 인물 사진"   // 0 과 같은 값
  }
)
```

- 키는 **슬라이드 순번(0부터)**, 값은 **낱장 이름**. **열 순번을 빠짐없이** 적는다.
- 낱장 이름은 `list_layouts` 결과를 **글자 그대로** 복사한다. **오타는 에러가 아니라 조용한 폴백**이다
  (자동 선택으로 넘어가 첫 낱장 = 표지가 된다).
- 배경은 **외부 사이트 URL 을 그대로 넣어도 된다** — 구글맵·네이버 주소 모두 통과했다(지도 축 실측).

## 전달

메시지는 **첫 문구 `[4단계 — 캐러셀 스튜디오 생성]` 으로 열고,
마지막 문구 `[5단계 — 캐프션 문구] 만들까요?` 로 닫는다.**
그 사이에 아래를 적는다.

1. **편집 링크**
2. 배경 **위치·크기는 편집기에서 조정**하면 된다는 안내
3. **3단계 산출물과 스튜디오 낱장이 같은지 한 장만 확인해 달라**는 부탁
4. **위치 칸의 긴 일본어 주소는 한 줄에 안 들어갈 수 있다**는 안내

- 링크만 던지고 끓지 않는다. 마지막 문구가 곷 5단계 질문이다.
- 묻기 전에 캐프션을 미리 써 두지 않는다.

만든 뒤의 낱장 문구 수정은 봇이 못 한다. 그건 사람이 편집기에서 한다.
