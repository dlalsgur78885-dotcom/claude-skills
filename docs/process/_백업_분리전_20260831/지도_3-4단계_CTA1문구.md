# 지도 — 3-4단계 CTA1 정보 정리 문구

작성: solhee 방 / 2026-08-25 회차 진행 중 (주제: 비 와도 되는 도쿄 실내)
최종 수정: 2026-08-27 (**SUBHEADLINE 에 수량을 반드시 넣는다 — 3-1 SUBHEADLINE 의 `N` 과 같은 숫자**)
이전 수정: 2026-08-26 (**CTA1 지도를 봇이 넣는다 — `items` 의 칸 1 로. 「사람이 편집기에서 얹는다」 뒤집힘**)
최신 회차: 2026-08-27 (주제: 도쿄 쇼와 킷사텐)

## 이 단계에서 하는 일

마지막에서 두 번째 장(`CTA1`)에 들어갈 **전체 정보 정리 문구**를 만들고,
그 장에 **3-2 에서 고른 지도 캡처를 1:1 로 잘라** 얹는다.

## 한 장에 들어가는 것 (2026-08-26 변경)

| 칸 | 슬롯 역할 | `slides` 키 | 내용 |
|---|---|---|---|
| 강조 문구 | **HEADLINE** | `headline` | **2줄** — 눈길을 사로잡는 문구 |
| 공감·수량 문구 | **SUBHEADLINE** | `subtext` | **1줄** — 아래 조건 (**수량 필수**) |
| 팔로우 유도 | **BODY** | `body` | **2줄, 틀 고정** — 회차에 맞춰 채우는 자리만 바꾼다 |

> **2026-08-26 변경** — 전에는 `headline` 1줄 + `body` 2~3줄에 공감·수량·행동유도를 다 몰아넣었다.
> 이제 **셋을 칸으로 나눈다**: 강조는 HEADLINE(2줄), 공감+수량은 SUBHEADLINE(1줄),
> 행동유도는 **BODY 고정 틀**이 맡는다. 옛 구조로 쓰지 않는다.

- **키 이름 주의**: SUBHEADLINE 슬롯이 읽는 값은 `subheadline` 이 아니라 **`subtext`** 다
  (`backend/app/services/carousel_renderer.py:106-125`).
- **세 칸을 한 칸에 뭉치지 않는다.** 칸마다 다른 슬롯으로 들어간다.
- 낱장에 그 역할 슬롯이 없으면 **에러가 아니라 그 칸만 조용히 사라진다.**
  한 칸이 안 보이면 편집기의 텍스트 슬롯 역할 셀렉터로 맞춘다.

### HEADLINE — 강조 문구 2줄

- **3-1 에서 확정한 썸네일 훅 문구와 자연스럽게 이어지도록** 쓴다.
  훅에서 던진 것을 여기서 받아 준다는 느낌으로.
- 눈길을 사로잡는 문구로 **2줄**. 한 줄로 끝내지 않는다.
- **후보 3개**를 내고 사람이 고른다 (2026-08-25·08-26·08-27 세 회차 모두 이렇게 했다).

### SUBHEADLINE — 공감·수량 문구 1줄

한 줄 안에 아래를 담는다.

- 사용자의 시선을 **즉시** 사로잡고 **'저장'과 '공유'를 부르는** 문구
- **방문이 망설여지는 이유를 없애주는 공감 문구**
- **구체적인 수량** — 아래 규칙대로 **반드시 넣는다**

#### 수량은 반드시 넣는다, 숫자는 3-1 과 같다 (2026-08-27 확정)

- 이 줄에 **공유 목록 장소 수를 숫자로 넣는다.** 빼고 확정하지 않는다.
- 그 숫자는 **3-1 SUBHEADLINE 의 `N`** · **아래 BODY 둘째 줄의 개수**와 **같은 값**이다.
  한 캐러셀 안에서 세 자리의 숫자가 어긋나면 안 된다 (→ [3-1단계 문서](지도_3-1단계_훅문구.md)).
- **이전 규칙 「사람이 수량을 뺀 문장으로 확정하면 그대로 간다」 는 폐기됐다** (2026-08-27 사람 지시).
  2026-08-26 교토·2026-08-27 도쿄 회차가 수량 없이 확정된 것은 옛 규칙이라 따라 하지 않는다.
- 숫자를 모르면 **사람에게 묻는다.** 지어내지 않는다.

**확인되지 않은 사실을 편의로 넣지 않는다.** (2026-08-25 추가)
"역에서 도보 O분"·"전부 역과 직결" 같은 접근성 문구는 그럴듯해서 쓰기 쉽지만,
`read_travel_guide` 에 없으면 **지어낸 것**이다. 가이드에 있는 것만 쓴다.
수량도 마찬가지 — **실제로 담은 개수**를 쓴다.

- **길이는 사람이 정한다.** 2026-08-27 회차에서 사람이 "좀 더 짧게" 라고 해서 짧은 안 3개를 다시 냈다.
  초안이 길면 줄여 달라고 할 수 있으니 **문장을 길게 쓴 뒤 붙잡지 말고 짧은 대안을 바로 낸다.**
  줄일 때도 **수량은 남긴다.**

### BODY — 팔로우 유도 문구, 틀 고정 (2026-08-26 확정)

**틀은 고정이고, 둘째 줄의 지역·소재·개수만 회차에 맞춰 바꾼다.**

```
@travel.view_official 팔로우하고 댓글 남겨주시면
[지역] [소재] [개수]곳 구글 지도 공유해드립니다
```

2026-08-25 도쿄 회차 기준으로 채우면:

```
@travel.view_official 팔로우하고 댓글 남겨주시면
도쿄 찐맛집 50곳 구글 지도 공유해드립니다
```

- **첫 줄은 글자 그대로 고정.** 계정명 `@travel.view_official` 을 바꾸거나 줄이지 않는다.
- **둘째 줄은 그 회차 주제에 맞춘다.** 오사카 회차면 `오사카 …`, 소재가 맛집이 아니면 그 소재로.
  회차 주제가 도쿄가 아닌데 `도쿄` 가 그대로 남아 있으면 안 된다.
- **개수는 실제로 공유해 줄 지도에 담긴 개수**를 쓴다. 지어내지 않는다.
  **3-1 SUBHEADLINE 의 `N`·위 SUBHEADLINE 의 수량과 같은 숫자다.**
  회차마다 다를 수 있으니 **모르면 사람에게 묻는다.**
  (2026-08-26 교토 회차도 봇이 몰라서 물었고, 사람이 `30곳` 이라고 알려 줬다.)
- **사람이 「개수는 비우고 가자」고 하면 개수 없이 넣는다** (2026-08-27 도쿄 회차 실제).
  `도쿄 노포 킷사텐 구글 지도 공유해드립니다` 처럼 소재 뒤를 바로 잇는다. 봇이 임의로 숫자를 채우지 않는다.
- 문장 끝 「구글 지도 공유해드립니다」 형태는 유지한다.
- 줄바꿈은 `\n` 으로 그대로 넘긴다.

## CTA1 이미지 — 3-2 지도 캡처를 1:1 로 (2026-08-26 확정)

`CTA1` 장에는 **3-2 에서 고른 지도 캡처(표지·`CTA2` 배경과 같은 1장)** 를 얹는다. 새로 만들지 않는다.
3-2 는 2026-08-26 부터 `capture_page` 로 찍은 **트래블어시 가이드의 실제 지도 화면**이다
(→ [3-2 문서](지도_3-2단계_썸네일이미지.md)).

| 항목 | 값 |
|---|---|
| 쓰는 이미지 | 3-2 확정 지도 캡처 (표지·CTA2 와 같은 1장) |
| 비율 | **1:1 로 자른다** |
| 크기 | **650 × 650 px** |
| 위치 | **Y = 100**, **좌우 중앙** (캔버스 1080×1350 기준 X = 215) |

- **배경으로 까는 것이 아니다.** 장 위에 얹는 **오브젝트**다.
- 가운데를 1:1 로 잘라 쓴다. 주제 지역의 핀이 잘려 나가지 않게 본다.
- 캡처에 왼쪽 목록 패널이 붙어 있으면 **잘라내고** 지도만 쓴다(3-2 규칙).

### 봇이 넣는다 — `items` 의 **칸 1** (2026-08-26 뒤집힘, 실측 확인)

**옛 기록은 틀렸다.** 이 자리에 「봇이 낱장에 넣지 못한다 · `user_image_urls` 는 배경 1장이라
크기·위치를 못 준다 · `capture_page` 는 `local_path` 뿐이라 넘길 URL 이 없다」 고 적혀 있었다.
둘 다 사실이 아니다. 따라 하지 않는다.

- `capture_page` 결과에는 앱 주소인 **`url`** 이 함께 온다(3-2 문서와 같은 사실).
- 배경과 **별개로 「칸」에 넣는 길**이 있다 — `slides[i].items` + `user_item_image_urls`.
  이쪽은 낱장에 정의된 **위치·크기 그대로** 들어간다
  (`backend/app/services/carousel_renderer.py:549-586`).

쓰는 법 — CTA1 이 4번 순번이라면:

```
slides[4].items: [{}, {}]                              ← 칸을 만들어 둔다
user_item_image_urls: { "4": { "1": "https://…" } }    ← 지도는 **칸 1**
```

- **칸 0 이 아니라 칸 1 이다.** 렌더러는 낱장의 `kind:image` 자리를 **배열 순서대로** 집어
  `items[0]`→첫 상자, `items[1]`→둘째 상자로 짝짓는다(`carousel_renderer.py:564, 573`).
  CTA1 은 650×650 상자가 **첫 번째가 아니라서**, 칸 0 에 넣으면 앞 상자로 들어가 **화면을 덮는다.**
  > 2026-08-26 실측 — 칸 0 은 화면 전체(캐러셀 432), 칸 1 은 제자리(캐러셀 433).
- **`items` 를 빼먹으면 `user_item_image_urls` 는 조용히 무시된다.** 에러가 안 난다.
- **CTA1 순번에 `user_image_urls` 를 넣지 않는다.** 넣으면 배경으로 꽉 차게 깔린다.
- 크기·위치는 **낱장이 정한다.** `generate_carousel` 에는 크기·위치 인자가 없다.
  자리가 틀리면 캐러셀이 아니라 **템플릿의 CTA1 낱장**을 고친다.
- 칸 0 을 비워 두면 그 자리에 반투명 회색 사각형이 그려진다(`carousel_renderer.py:586`).
  거슬리면 편집기에서 지운다.

### 누끼 이미지 5장은 만들지 않는다 (2026-08-26 폐지)

전에는 CTA1 에 사물 누끼 5장을 만들어 얹었다. **이제 만들지 않는다.**
그 자리를 위 지도 이미지 1장이 대신한다. 옛 회차 문서에 누끼 링크가 남아 있어도 따라 하지 않는다.

## 이번 회차 문구 (2026-08-27 확정 · 도쿄 쇼와 킷사텐)

> **`subtext`·`body` 는 수량 없이 확정된 옛 규칙 결과다.** 2026-08-27 부터 SUBHEADLINE 에는
> 수량을 반드시 넣으므로, 다음 회차부터 이 형태를 그대로 따라 쓰지 않는다.

**강조 문구 (`headline`, 2줄 — 줄바꿈 `\n` 그대로)**

```
커피 한 잔 시키면
1926년이 딸려 나옵니다
```

**공감 문구 (`subtext`, 1줄)**

```
헤매지 말고 이것만 저장해 두세요
```

**팔로우 유도 (`body`, 2줄 — 줄바꿈 `\n` 그대로)**

```
@travel.view_official 팔로우하고 댓글 남겨주시면
도쿄 노포 킷사텐 구글 지도 공유해드립니다
```

- 낱장 = `CTA1`
- 강조 문구는 후보 3개 중 사람이 **1번**을 골랐다
  (탈락: 「도쿄에서 제일 / 느리게 흐르는 자리」·「스타벅스 옆에 / 90년이 서 있습니다」).
  1926년은 2단계에서 확인한 메이쿄쿠킷사 라이온의 창업 연도라 지어낸 숫자가 아니다.
- `subtext` 는 봇 초안이 길다고 해서 짧은 안 3개를 다시 냈고, 사람이 **3번**을 골랐다. 수량은 빠진 형태다.
- `body` 둘째 줄은 사람 지시로 **개수를 비웠다.**
