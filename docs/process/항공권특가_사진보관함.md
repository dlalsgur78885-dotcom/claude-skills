# 항공권특가 — 사진 보관함

작성: solhee 방 / 2026-10-21 신설 (솔희님 승인 — 제작 시간 줄이기)

생성해 둔 배경 사진을 **회차를 넘어 다시 쓰기 위한 목록**이다.
사진 생성이 한 회차에서 가장 오래 걸리는 구간이라, **있는 것부터 쓰고 없는 것만 만든다.**

## 쓰는 법

1. 3-1단계에서 이 파일을 먼저 읽는다.
2. 그 회차 도착지가 여기 있으면 **그 URL 을 그대로 쓴다**(생성하지 않는다).
3. 없는 도착지·장면만 생성하고, 만든 뒤 **아래 표에 한 줄 추가**한다.

## 지키는 것

- **한 캐러셀 안에서는 사진이 겹치면 안 된다** — 이 규칙은 그대로다(표지와 CTA 만 예외).
  장이 3장이면 같은 도착지라도 서로 다른 장면 3개를 집는다.
- **회차 간 재사용은 된다** (2026-10-21 솔희님 승인 — 전에는 앞 회차 장면까지 피했다).
  같은 도착지가 2주 뒤 다시 나오면 같은 사진을 다시 써도 된다.
- 계절이 안 맞으면 쓰지 않는다 — 단풍 사진을 1월에, 첫눈 사진을 8월에 쓰지 않는다. 그럴 때만 새로 만든다.
- URL 은 스튜디오 주소 뒤에 붙는 경로다(`https://3-35-18-166.sslip.io:3443` + 경로).
