# 캐러셀 디스코드 봇

디스코드에서 말로 지시하면 캐러셀 대시보드의 데이터를 조회·조작한다.
**대시보드와 같은 백엔드·같은 DB** 를 쓰므로, 봇이 한 일은 직원 화면에 그대로 나타나고
직원이 이어서 편집할 수 있다.

```
#트립앤라이프 ─┐
#이솔희       ─┤ 채널로 계정 판별 → 기존 HTTP API → 같은 DB ← 대시보드
```

## 왜 API 를 타는가

백엔드 코드를 직접 임포트하지 않는다. 봇은 **계정 하나로 로그인한 또 한 명의 사용자**다.
그래야 권한 규칙이 저절로 같아지고 인증 우회 경로가 생기지 않는다.

## ⚠ 계정 매핑이 첫 단추

이 앱은 소유자 스코프다 — 채널·템플릿·캐러셀이 전부 `user_id` 로 걸러진다.
계정을 잘못 잡으면 **보이는 채널 수부터 달라지고**(junhyeok 61개 vs solhee 24개),
봇이 만든 결과가 직원 대시보드에 안 보인다. 매핑에 없는 채널에서는 아무 반응도 하지 않는다.

## 준비

```bash
cp .env.example .env    # 값 채우기
npm install
npm run doctor          # 디스코드 없이 설정·로그인·읽기 도구 점검
npm start
```

`.env` 에서 사람이 직접 채워야 하는 것:

| 값 | 얻는 곳 |
|---|---|
| `DISCORD_TOKEN` | discord.com/developers → Bot → Reset Token |
| `CHANNEL_ACCOUNTS` | 디스코드 개발자 모드 → 채널 우클릭 → 채널 ID 복사 |
| `GEMINI_API_KEY` | 서버 `.env` 에 이미 있는 값과 동일 |
| `APPROVER_IDS` | 삭제 작업을 승인할 사람의 디스코드 사용자 ID |

**Bot 탭에서 `MESSAGE CONTENT INTENT` 를 켜야** 봇이 글을 읽는다. 이걸 빠뜨리면
연결은 되는데 아무 반응이 없다.

## 쓰는 법

**멘션은 대화를 시작할 때만** 하면 된다. 그 뒤 3분(`FOLLOWUP_WINDOW_SEC`)은 그냥 말하면
이어진다 — 사람과 대화할 때 매 문장마다 이름을 부르지 않는 것과 같다.

```
@봇 오늘 소재 좀 보자
     좋아요 많은 걸로              ← 멘션 없이 이어짐
봇: 기준을 어느 정도로 볼까요?      ← 애매하면 되묻는다
     1000 넘는 걸로
     그중에 릴스만
     새 대화                      ← 맥락 초기화
```

애매한 요청에 짐작으로 답하지 않고 **되묻는다.** 앞 대화를 기억하므로
"그거", "아까 그 채널" 같은 말이 통한다.

## 안전장치

도구는 세 등급이다.

| 등급 | 예 | 처리 |
|---|---|---|
| `safe` | 조회 | 바로 실행 |
| `create` | 수집, 그룹 만들기, 그룹 지정 | 바로 실행 |
| `danger` | 채널 삭제, 그룹 삭제·이름변경 | **버튼으로 승인받고 실행** (2분 내, 승인자만) |

승인 대기는 메모리에만 있다. 봇이 재시작되면 대기 중 확인은 사라진다 —
**실행되지 않은 채로** 사라지므로 안전한 쪽으로 실패한다.

## 구조

| 파일 | 역할 |
|---|---|
| `config.js` | 환경변수, 채널→계정 매핑 파싱 |
| `api-client.js` | 백엔드 호출. 계정별 토큰 캐시, 401 시 1회 재로그인 |
| `tools.js` | 도구 목록 + 위험 등급. 새 기능은 여기에 항목을 더한다 |
| `agent.js` | 지시 해석 → 도구 선택 → 실행 → 답변 (최대 4단계) |
| `structured-output.js` | 모델 답변에서 JSON 추출·검증·재시도 지시 |
| `session-store.js` | 채널별 최근 대화 (턴·시간 만료) |
| `followup-window.js` | 멘션 없이 이어 말할 수 있는 시간 관리 |
| `index.js` | 디스코드 배선, 승인 버튼 |
| `doctor.js` | 자가진단 |

## 아직 없는 것

- **작업 큐** — 지금 도구는 전부 빠른 HTTP 호출이라 필요 없었다. 캐러셀 생성처럼
  오래 걸리는 도구를 넣을 때 매거진 봇의 `job-queue.js` 방식(재시작 복구 포함)을 가져온다.
- **캐러셀 생성·템플릿 적용 도구** — 조회와 수집까지만 붙였다.
- **승인 이력 파일 저장** — 지금은 한 대화 안에서 끝나는 확인만 한다.
