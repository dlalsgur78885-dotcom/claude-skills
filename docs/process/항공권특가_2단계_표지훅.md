## 이 단계에서 하는 일

고른 주제로 **표지 훅 문구 후보 10개**를 짓는다(codex sol).

## 형식

- **2줄**, 줄마다 **공백 포함 15자 이내**, 후보 **10개**. 클릭을 부르는, 직관적이고 호기심이 드는 문구.
- 훅을 짓기 전에 **주제의 항공권이 3건 이상인지 다시 확인**한다.
- 사람이 준 예시 — `90만원 홍콩 항공권 / 오늘부터 왕복 29만원` · `고유가 시대에도 / 일본 5만원대 등장` ·
  `오사카 왕복 10만원대 / 여행 특가 풀렸다` · `26만원 중국 항공권 / 4만원대 가격 실화?ㄷㄷ`

## 숫자 규칙

- **크게 과장해도 된다. 단 숫자는 받은 데이터로 계산한 것만 쓴다.**
- **할인율은 「같은 노선 최고가 대비」로 계산한다** — `(최고가 − 최저가) ÷ 최고가` 를 **내림**.
  2026-09-14 실제 값 — 제주 52~56%, 오사카 39~44%, 도쿄 32%, 후쿠오카 10~34%. 사이트 배지(0~4%)보다 훨씬 크다.
- 가격·가격대(「5만원대」), 원래 가격(「26만원 항공권이 → 5만원대」 의 26만원 = **같은 노선 최고가**) 모두 이 목록에서 가져온다.
- 「최대」「부터」 를 붙여 **가장 큰 값 기준임을 드러낸다** — `제주 왕복 최대 56% ↓`.
- 숫자 없는 과장(「역대급」「실화?」「풀렸다」「초특가」)은 마음껏 쓴다.
- ⚠ **데이터로 계산할 수 없는 숫자(받은 값이 56% 인데 「98% 할인」)는 쓰지 않는다.**
  사람이 대표님 승인을 전제로 수치 과장을 요청했으나(2026-09-14), 실제 판매가에 붙는 지어낸 할인율은
  표시광고법상 거짓 광고라 봇이 위 계산 규칙으로 대신했다.
