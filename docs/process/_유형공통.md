## 모든 유형에 적용되는 규칙

1. **30개를 긁어 20~28개를 후보로 올리고, 맨 앞에 추천 5건**(2026-10-20 트립앤라이프 지시로
   10개에서 올림). 디스코드 메시지에는 **추천 5건만** 쓰고 **전체 목록은 파일로 보낸다.**
   문턱을 채우는 소재가 모자라면 **억지로 채우지 말고 몇 건이 모자랐는지 밝힌다.**
2. **표지** — 세로 4:5, 사진을 꽉 채우고 **아래쪽만** 어둡게, **흰 굵은 2줄**, 줄당 9~13자,
   계정 표시(트립초초는 훅 아래, 니혼테레비는 훅 위).
3. **본문 2~4장.** 4장을 넘겨 득 본 유형이 없다. 사진이 하나뿐이면 1장으로 끝낸다.
   **영상이 들어가는 캐러셀은 표지·CTA 두 장만 만든다** → [_영상캐러셀_제작흐름.md](_영상캐러셀_제작흐름.md).
4. **캡션은 두 틀** — `[대괄호 제목]` 기사체(사건·제도) / 줄바꿈 많은 대화체(가십·구경거리).
   어느 쪽이든 **확인 안 된 것은 「확인되지 않았습니다」로 못 박는다.**
5. **수치·URL 은 가공하지 않는다.** 받은 값을 그대로 쓰고, 못 받은 값은 「확인 불가」로 둔다.

# 한국 사람이 반응하게 — 2단계 게이트 5문항

일본에서 터진 글이 한국에서도 터지지는 않는다. **소재를 확정하기 전에 다섯 개를 센다.**

1. **한국인이 그 자리에 설 수 있나** — 가게·역·숙소·공항·편의점처럼 **여행 중 마주치는 자리**인가.
2. **한국이 당사자인가** — 한국인·한국 제품·한일 비교가 걸려 있나(137,536 · 3,743 이 그랬다).
3. **감정이 한 가지로 또렷한가** — 귀엽다 / 훈훈하다 / 어이없다 / 놀랍다 중 하나로 떨어지나.
4. **표지 한 장으로 전달되나** — 설명을 읽어야 이해되면 떨어진다(695 · 592 가 그 경우였다).
5. **마지막 장에 「그래서 당신은」이 붙나** — 여행자 연결 한 줄이나 찬반 질문으로 닫히나.

**3개 미만이면 만들지 않는다.** 4개 이상이면 추천 5건에 올린다.

**일본 맥락은 한국 말로 바꿔 쓴다** — 「道の駅」은 「휴게소 겸 특산물 시장」처럼 풀고,
고유명사는 한글 표기와 원문을 병기한다(예: 乗りものニュース(노리모노뉴스)).

**어느 유형에서든 쓰지 않는 것** — 일본 내부 정치·선거, 직장 내부 가십, 국적·인종을 세운 훅,
환율 숫자 단독, 재난 단독(레퍼런스 200). 사건은 쓰되 혐의 단계임을 캡션에 적는다.

# 반응도 — 플랫폼마다 수치의 뜻이 다르다

같은 「10만」이라도 플랫폼마다 무게가 다르다. **2026-10-20 실측 분포로 문턱을 잡았다.**

| 플랫폼 | 보는 수치 | A급(추천 후보) | B급(후보) | 근거 |
|---|---|---|---|---|
| **Togetter** | pv(조회) | **9만 이상** | **2만 이상** | 112건 분포의 상위 10% / 중앙값 |
| **X** | 조회 | 10만 이상 | 5만 이상 | 기존 축 문턱 유지. 인용·댓글 50개 이상 |
| **유튜브** | 조회 | 100만 이상 | 10만 이상 | 1주 조회수순 검색 상위의 실측 범위 |
| **스레드** | 좋아요 | 3,000 이상 | 500 이상 | 실측 상위 글이 3,000~8,800♥ |
| **RSS 매체** | 없음 | — | — | **수치가 없다.** 아래 대체 지표로 센다 |
| 하테나 북마크 | users | 90 이상 | 26 이상 | 같은 날 73건 분포의 상위 25% / 중앙값 |

- **RSS 기사는 반응 수치가 없으므로 셋으로 대신한다** — ① 같은 소재가 **두 매체 이상**에 떴나
  ② Togetter·야후 댓글에 **일본인 반응이 붙었나** ③ 하테나 북마크가 붙었나.
  **하나도 없으면 후보로 올리지 않는다.**
- 수치는 **플랫폼 사이에서 비교하지 않는다.** 「Togetter 3만 > 스레드 3천」 같은 비교는 뜻이 없다.
  **같은 플랫폼 안에서만 줄을 세운다.**
- 게시 **3일이 안 된 글은 수치가 익지 않았다.** 그대로 비교하지 말고 「안 익음」으로 표시한다.

```

요청문에 **기간 · 수량 · 필요 항목**(원문 URL · 게시 시각 · 조회수 · 좋아요 · 댓글)을 적는다.

## ② 유튜브 — `yt-dlp` (키 없이 된다)

이 PC 에 `yt-dlp 2026.08.19` · `ffmpeg 8.1.2` 가 깔려 있다. **API 키가 필요 없다.**

**발견 — 키워드로 조회수순 훑기** (최근 1주):

```
yt-dlp --flat-playlist --playlist-end 20 --print "%(view_count)s|%(channel)s|%(title)s|%(webpage_url)s" \
  "https://www.youtube.com/results?search_query=<일본어 키워드>&sp=CAMSBAgDEAE"
```

- `sp=CAMSBAgDEAE` = **조회수순 + 최근 1주**, `sp=CAMSBAgEEAE` = **조회수순 + 최근 1달**.
  (키워드는 URL 인코딩해서 넣는다. 기간을 넓힐수록 영어권 영상이 섞이니 키워드를 일본어로 조인다.)
- 숏폼이 많은 유형(화제·미녀·치이카와)은 **쇼츠를 따로 훑는다** — 검색 URL 에 `&sp=EgIYAQ%3D%3D`.

**확정 — 고른 영상의 수치와 날짜**:

```
yt-dlp --skip-download --print "%(upload_date)s|%(view_count)s|%(like_count)s|%(comment_count)s|%(channel)s" "<영상 URL>"
```

**내용 파악 — 자동 자막을 받아 읽는다** (일본어 영상도 내용을 그대로 읽을 수 있다):

```
yt-dlp --skip-download --write-auto-sub --sub-lang ja --sub-format vtt -o "tmp/yt/%(id)s.%(ext)s" "<영상 URL>"
```

**사진 — 썸네일과 장면**:

```
yt-dlp --skip-download --write-thumbnail -o "tmp/yt/%(id)s.%(ext)s" "<영상 URL>"   # 썸네일
```

- 특정 장면이 필요하면 영상을 받아 `ffmpeg -ss <시각> -i <파일> -frames:v 1 <out>.jpg` 로 뽑는다.
- **댓글 카드**는 이미 만들어 둔 것을 쓴다 — `node scripts/yt-comment-capture.mjs "<영상 URL>" 6`.

⚠ **키워드를 잘못 걸면 정치·혐오 채널이 상위를 덮는다**(2026-10-20 테스트 — 「日本人 衝撃」은
거의 전부 그랬다). **「外国人インタビュー」·「初来日」·「街の声」 계열**이 쓸 만했다.

**문턱(제안)** — 최근 14일 · 조회 **10만 이상**, 또는 기간 무관 **조회 100만 이상**(명예의전당).
댓글 200개 이상이면 반응 카드를 만들 수 있다.

```

- ⚠ **조회수는 스레드가 공개하지 않는다.** 좋아요·답글은 화면에 보이는 값이라
  **후보로 올릴 때는 링크를 열어 다시 확인한다.**
- ⚠ **투자·도박 스팸이 인기순 상위에 섞인다**(「炎上覚悟で言います」 류). 같은 문구가 반복되는

| `b.hatena.ne.jp/hotentry/all` | 그날 가장 많이 북마크된 글 | 몰랐던 일본 · 제도 뉴스 |
| `itaishinja.com` · `matomeantenna.com` | 5ch 정리 블로그·안테나 | 커뮤니티 화제 |
| `search.yahoo.co.jp/realtime` | X 실시간 검색 — **발견용으로만** | 키워드 잡을 때 |

- 야후 실시간에서 찾은 X 글도 **수치는 grok 으로 다시 확인**한다. 화면값을 그대로 옮기지 않는다.
- 커뮤니티 글은 **원문 URL 과 게시 시각을 반드시 남긴다.** 정리 블로그는 원문이 아니다 —
  가능하면 원글(X·5ch 스레드)까지 따라가 적는다.

## ⑥ 일본 매체 RSS — 3계층 ([_일본매체_RSS.md](_일본매체_RSS.md))

**발굴(J타운넷·Togetter·ねとらぼ·ロケットニュース24) → 실용(訪日ラボ·TRAICY) → 확정(NHK·기상청)**
2단 구조다. **발굴층 기사의 숫자를 그대로 올리지 않고 확정층으로 역추적한다.**

- ⚠ **기사 사진·본문 문장은 못 쓴다**(전재 금지·사전 허가제). 가져오는 것은 **사실·수치뿐**이고,
  인용하면 **매체명 + URL 을 캡션에 적는다.** 이미지는 자체 촬영·유료 스톡·관청 공개자료·AI 생성 넷 중 하나.
- ⚠ **기상청 자료만 2차 이용이 열려 있다**(출처 표기 조건). 날씨·재난 소재의 권리 위험이 가장 낮다.
- ⚠ **상태코드만 보고 믿지 않는다** — 200 을 주면서 404 HTML 을 돌려주는 피드가 실제로 있었다.
  **항목 수를 센다.**

주소·등급·막힌 피드 목록은 전부 [_일본매체_RSS.md](_일본매체_RSS.md) 에 있다.

## 남의 영상·남의 글을 쓸 때의 선

1. **영상 프레임을 쓰면 캡션에 채널명을 밝힌다.** 트립초초도 유튜버 소재에서 채널명을 그대로 적었다.
2. **영상을 통째로 올리지 않는다.** 캐러셀은 정지 이미지 2~3장까지다.
3. **일반인 얼굴은 가린다.** 사건 피의자·피해자 얼굴은 쓰지 않는다.
4. **스레드·커뮤니티 글은 캡처 + 번역으로 쓰고 개인 계정명은 가린다.**
5. 저작권이 있는 IP(치이카와 등)의 그림은 **다시 그리거나 합성하지 않는다.**
