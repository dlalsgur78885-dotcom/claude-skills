## 기본 원칙

- 간결하고 힘 있는 문장, 줄바꿈·이모지 활용.
- **종결은 존댓말** — 「바뀝니다」·「종료됩니다」·「놓쳐요!」 (2026-10-06 개정 — 전에는 「바뀐다/종료된다」 평서체였다. 훅 1행의 「풀렸다」 같은 평서체는 그대로 둬도 된다).
- **이모지는 문장 끝에 붙인다** — `가을 일본, 왕복 16만원대로 갈 기회! ✈️` (2026-10-06 개정 — 전에는 문장 머리였다).
- **블록 사이는 빈 줄 한 줄로 띄운다. `—` 구분선은 넣지 않는다** (2026-10-06 개정).
- **대화형 오프닝(「아니...」「여러분」「안녕하세요」) 금지**, 억지 좋아요·구독 강요 금지, 맥락 없이 국가·지역명 특정 금지.

## 구조 — 5블록, 순서를 지킨다 (2026-10-06 개정 — CTA 를 ✔ 앞으로 올렸다)

① 오프닝 훅 — 1행 혜택·문제 제기(이모지는 문장 끝) / 2행 넘기면 손해라는 경고
② `👉 댓글에 "핵심키워드" 남기시면...` — **✔ 요약보다 앞에 온다** (전에는 훅의 3행이었다)
③ 핵심 요약 ✔ 3개
④ 세부 정보 불릿(주의사항 — 「특가 가격은 실시간으로 바뀝니다」 / 「좌석이 빠지면 특가는 종료됩니다」)
⑤ 해시태그 — **메인 키워드만 2~3개 · 채널 이름(#트립앤라이프)은 넣지 않는다** (2026-09-16 사람 지시 — 「해시태그 문구 필요없는 건 지우고, 메인 키워드만 2~3개」·「해시태그에 채널 이름 빼줘」). 주제를 바로 가리키는 말만 남기고, 있으나 마나 한 태그는 뺀다. 공백 없이

- ⚠ **노선 리스트 블록과 마무리(타이밍 강조·알람 설정·저장 유도) 블록은 넣지 않는다** (사람 지시 — 「이 부분을 아예 없애도록」).
  처음 받은 안은 6블록이었다. OTA할인 축 캡션과 **다르다**(그쪽은 클로징이 있다).

## 문장 본보기 — 2026-10-06 사람이 준 캡션 예시 2개

위 규칙은 이 둘에서 뽑았다. 새 캡션은 **이 형태를 따르되 같은 문장 틀·이모지를 다시 쓰지 않는다.**

```
일본 왕복 항공권이 15만원대부터 풀렸다 🍁

평균보다 최대 45% 싼 표, 지금 넘기면 놓쳐요!

👉 댓글에 "일본" 남기시면 특가 링크 보내드려요

• 특가 가격은 실시간으로 바뀝니다
• 좌석이 빠지면 특가는 종료됩니다

#일본항공권 #항공권특가#일본여행
```

```
가을 일본, 왕복 16만원대로 갈 기회! ✈️

👉 댓글에 "일본" 남기시면 특가 링크 보내드려요

✔ 주변 날짜 평균 대비 최대 41% 할인
✔ 오사카·후쿠오카·도쿄·삿포로 노선

• 특가 가격은 실시간으로 바뀝니다

#일본항공권#항공권특가#가을일본여행
```

- 예시1 에는 ✔ 요약 블록이 없지만 **✔ 3개는 그대로 필수**로 둔다(2026-10-06 — 사람이 따로 풀지 않았다). 예시2 가 기본 꼴이다.

## 넣지 않는 것 (사람 지시 — 「출발일, 수집시각, 각 항공권 왕복 금액 부분은 안 나오도록」)

- **출발일**(날짜 범위 포함) · **수집 시각** · **항공권별 왕복 금액**
- 금액·날짜는 본문 장에 이미 있다. 캡션은 「일본 N개 노선」「최대 N% 하락」 같은 묶음 정보로 채운다.
- 숫자는 **받은 값으로 계산한 것만**. 할인율 규칙은 2단계와 같다.
