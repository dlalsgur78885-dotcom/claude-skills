# 상황별 일본어 — 2단계 주제 선택

작성: solhee 방 / 갱신 2026-09-02 회차

## 확정 주제 (2026-09-02)

**일본인이 하는 혼잣말** — 사람이 1단계 후보 밖에서 직접 지정했다.

- 사람 지시 그대로: 「일본인이 하는 혼잣말 주제로 생성해줘」.
- 범위: 상대에게 하는 말이 아니라 **혼자 흘리는 말** — 뭔가 떠올랐을 때, 실수했을 때,
  지쳐을 때, 물건을 찾을 때, 마음을 먹을 때. 드라마·애니에서 자주 들리는데
  뜻은 모른 채 넘어가는 말들이 축이다.
- 이력 확인 — [상황별일본어_이력.md](상황별일본어_이력.md) 의 12건과 겹치지 않는다.
  다만 12번 「웃길 때 쓰는 말」과 결이 인접하니 **리액션 말로 흘르지 않게** 3-3 은
  혼자 있을 때 나오는 말로 잡는다.

## 지난 회차 확정 주제 (2026-09-01)

**일본인이 웃길 때 쓰는 말** — 사람이 처음부터 직접 지정해 1단계를 건너뛰었다.

- 범위: 웃긴 상황에서 튀어나오는 리액션 말. `ㅋㅋㅋ` 자리에 일본인은 뭔 쓰는가가 축이었다.
- 일본 택시의 문화 차이(문을 손으로 안 열기, 팁 없음)도 본문에 섮을 수 있다.

표지 낱장은 3-1단계에서 고른 훅 문구의 줄 수를 그대로 따라간다.
템플릿과 내용·마지막장 낱장은 매번 묻지 않고 그대로 쓴다. 바꿔야 하면 사람이 먼저 말한다.
