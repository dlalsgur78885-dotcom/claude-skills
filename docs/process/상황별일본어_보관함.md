# 상황별일본어 — 보관함

1단계에서 **[보관]** 을 누른 주제. 이번 회차에 안 썼을 뿐 버린 것이 아니라,
다음 회차 1단계에 **다시 나온다.** 실제로 만든 주제만 쌓는 제작 이력과는 별개다.

화면(`/studio/ja-situations`)이 자동으로 갱신한다.

- 내가 다시 시작한 일을 일본어로 말하기
- 일본인이 약속을 기다릴 때 하는 말
- 내가 요즘 아끼는 시간을 일본어로
- 일본어로 말하는 나의 최애 장소
- 친구에게 잠깐 쉬자고 할 때 쓰는 일본어
- 친구와 메뉴를 못 고를 때 쓰는 일본어
- 일본인이 얄미울 때 하는 말
