# 여행코스 — 5단계 캡션 문구

작성: solhee 방 / 2026-10-16 축 신설 (사람이 준 예시 그대로)

## 이 단계에서 하는 일

인스타그램에 올릴 **캡션**을 짓는다. 묻지 않고 바로 만들지 않고, 4단계 끝에서 만들지 물어본 뒤 쓴다.

## 고정 틀 — 네 덩어리

1. **훅 한 줄** — `<지역> <기간> 여행코스 공유✨`
2. **동선 요약 2~3줄** — 일차별로 어느 권역을 묶었는지 + 마지막 날 실전 팁 하나(끝에 📌)
3. **DM 유도 3줄** — 글자 그대로 고정
4. **해시태그 3개** — 지역·지역+기간·지역+여행코스

사람이 준 예시(그대로 기준이다):

```
오사카 2박 3일 여행코스 공유✨

1일차는 난바·도톤보리, 2일차는 오사카성에서 우메다, 3일차는 난바 시장 권역으로 묶으면 이동이 깔끔해요.
마지막 날은 난바역에 짐을 맡겨두고 공항철도로 바로 이동하세요📌

필요하신 분들은
팔로우하고 댓글 남겨주시면
정리해둔 링크 보내드릴게요💌

#오사카여행 #오사카2박3일 #오사카여행코스
```

## 지킬 것

- **DM 유도 3줄은 치환 없이 그대로** 쓴다 — 「필요하신 분들은 / 팔로우하고 댓글 남겨주시면 / 정리해둔 링크 보내드릴게요💌」.
- 동선 요약은 **3-3 에서 확정한 권역과 같아야 한다.** 캡션에서 새 장소를 만들지 않는다.
- 장소 이름을 쓰면 **본문(3-3)에 쓴 이름 그대로** 쓴다. 주소·역 이름은 넣지 않는다(마지막 날 팁의 역 이름은 예외).
- 이모지는 예시처럼 **✨ 📌 💌 셋**만. 문장마다 붙이지 않는다.
- 톤은 방 지침서 「문구 톤 — AI 티 안 나게」를 따른다. 한 덩어리를 두 번 말하지 않는다.
- 해시태그는 **3개**. 기간은 띄어쓰기 없이 붙인다(`#오사카2박3일`).
