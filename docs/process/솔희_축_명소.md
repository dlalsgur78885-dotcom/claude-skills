## 템플릿은 99·101·102 한 벌이다 (2026-11-05 솔희 지시)

축마다 있던 템플릿 대신 **표지 `트래블뷰(표지)` 99 · 본문 `트래블뷰(본문)` 101 · CTA `트래블뷰(CTA)` 102**
한 벌을 쓴다. 바탕은 101 이고 표지·CTA 는 `@99:<낱장>`·`@102:<낱장>` 으로 빌린다.

- 아래에서 「템플릿 98」·`GET /templates/98` 로 적힌 자리는 **101**(표지는 99 · CTA 는 102)로 읽는다.
  낱장 값은 2026-11-05 에 한 벌과 **값이 같은지 대조**해 옮긴 것이다 — 글칸 위치·크기·폰트·장식이 같다.
- 옛 템플릿 98 는 **지우지 않았지만 쓰지 않는다**(솔희 지시). 이미 만든 캐러셀은 그대로 열린다.
- 회차를 시작할 때 낱장 이름을 다시 볼 때는 `GET /api/templates/layouts` 로 99·101·102 를 본다.

```
1 주제 후보 → 2 주제 선택(주제를 주면 여기서 시작) → 3-1 훅 → 3-2 썸네일 이미지 → 3-3 본문 → 4 스튜디오 생성·편집 링크(캡션 포함) → 6 세션 끊기
```

> **캡션은 4단계에서 함께 짓는다** — 저장할 때 `canvas_data.caption` 에 전문을 넣고, 편집 링크와 같은
> 메시지에 담아 `[6단계 — 세션 끊기]` 로 닫는다. 5단계 메시지는 없다(문구 규칙은 5단계 문서 그대로).

- 템플릿: **트래블뷰(본문) id 101**(바탕 · 표지 99 · CTA 102 — 2026-11-05 솔희 지시). 낱장 `@99:표지_2줄` · `@99:표지_3줄` · `본문4` · `본문5` · `@102:CTA1`
- **표지 낱장은 `트래블뷰(표지)` id 99 에서 빌린다** — `layout_overrides` 에 ``@99:표지_2줄` / `@99:표지_3줄`` (방 지침서 「표지는 `트래블뷰(표지)` 에서 빌려 쓴다」).
  (2026-11-02 `GET /templates/98` 실측). **원클릭 스튜디오에는 걸지 않는다** — 2026-11-02 솔희 「원클릭은 아직」.
- **일본 대도시 위주**다 (2026-11-02 솔희 지시) → [1단계 「지역」](명소_1단계_주제후보.md).

## 세 꼴 — ① 명소·전시 모음 · ② 축제·팝업 하나 · ③ 축제·팝업 모음

숙소 축이 「숙소 8곳 모음」과 「호텔 하나」로 갈리는 것처럼 명소도 꼴이 갈린다. **주제가 꼴을 정한다** —
지역 + 명소 분류로 쓰면 ①, 행사 이름 하나로 쓰면 ②, 행사 분류 + 기간으로 쓰면 ③이다.

| | ① 명소·전시 모음 | ② 축제·팝업 하나 | ③ 축제·팝업 모음 (2026-11-04 추가) |
|---|---|---|---|
| 무엇 | 그 지역에서 갈 만한 명소·전시 여러 곳 | 기간이 정해진 축제·팝업 한 건 | 지금 열리는 축제·팝업 여러 건 — **한 지역** 또는 **일본 전역** |
| 주제 꼴 | `[지역] + [명소 분류] + [키워드]` | `[지역] + [행사 이름] + [기간]` | `[지역 또는 일본 전역] + [행사 분류] + [기간]` |
| 본문 낱장 | `본문4` | `본문5` | `본문4` — **①과 같은 낱장** |
| 본문 한 장 | 명소 하나 | **궁금해할 항목 하나** (2026-11-03 솔희 — 전엔 「특징 하나」) | **축제·팝업 하나** |
| 맨 윗줄 | `headline` 명소 이름(52px) | `headline` **항목 이름**(56px 가운데) | `headline` **행사 이름**(52px) |
| 둘째 줄 | `subtext` 구글 지도 주소 1줄(28px) | — (칸이 없다) | `subtext` **지역 · 기간 1줄**(28px — 주소 대신 여기 기간을 쓴다) |
| `body` | 설명 2줄 | **상세 정보 2줄**(2026-11-03 솔희 지시 · 전엔 3줄까지) · **세 꼴 다 한 줄 최대 900px** | **설명 2줄** — 1줄 사실 · 2줄 읽는 사람 쪽 결과 |
| 본문 장수 | **8장**(최소 5장) | **5장** (2026-11-02 솔희 「본문 5장으로 변경」) | **5장**(최소 4장) |
| 전체 장수 | **10장** — 표지 1 + 본문 8 + CTA 1 | **7장** — 표지 1 + 본문 5 + CTA 1 | **7장** — 표지 1 + 본문 5 + CTA 1 |
| 확인 | 곳마다 `place_info` | 장소 1곳 `place_info` + **공식 발표로 기간·요금** | **건마다** 공식 발표로 기간 + 장소 1곳 `place_info` |
| 이름 | 본문 `headline` 에 **곳 이름을 쓴다** | **1번 장 윗줄에 행사 이름을 쓴다** (2026-11-03 — 옛 규칙은 「안 쓴다」) | 장마다 `headline` 이 **그 행사 이름**이다 |
| 쓴 것 기록 | [쓴명소](명소_쓴명소.md) | 같은 파일에 **행사 이름**을 적는다 | 같은 파일에 **다섯 행사 이름을 다** 적는다 |

- ②도 템플릿·표지·CTA·캡션 틀은 ①과 같다 — **본문 낱장과 칸의 뜻만 바뀐다.**
- **③은 ①의 낱장을 빌려 쓴다** (2026-11-04 솔희 승인 「그 지역에서만 열리는 축제나 일본 전역에서 열리는 축제 같은거 모음으로도」).
  템플릿은 안 건드린다 — `subtext` 에 주소 대신 **지역 · 기간**을 넣는 것이 ①과 다른 점 전부다.
  장수를 5장으로 둔 이유 — 공식 발표로 기간까지 확인되는 행사를 8건 모으기 어렵다.
  **담는 조건은 「진행 중이거나 시작이 30일 안」이다** (2026-11-04 솔희 지시 — ②의 「시작 일주일 전부터」보다 넓다).
- **③은 지역 모음과 전역 모음 둘 다 된다** — 전역 모음은 주제 지역 칸에 「일본 전역」을 쓰고
  대도시·지역 한도 밖으로 센다(회차당 1개까지) → [1단계 「지역」](명소_1단계_주제후보.md).
- **②는 낱장에 행사 이름을 쓴다** (2026-11-03). 1번 장 윗줄이 **행사 이름**이고, 2~5번은 항목 이름이다 →
  [3-3 「행사 이름은 쓴다」](명소_3-3단계_본문.md). 옛 규칙은 「훅·본문 어디에도 쓰지 않는다」(2026-11-02)였고,
  2026-11-02 솔희가 훅에 「치이카와」를 직접 넣어 보내며 풀렸다. 캡션은 원래부터 이름·요금을 쓴다([5단계](명소_5단계_캡션.md)).
- ①에서 본문이 8곳에 못 미치면 **최소 5곳**까지 줄여 만든다(그만큼 전체 장수가 준다). 5곳도 못 채우면 2단계에서 말한다.
- ②에서 다섯 자리(소개·기간·요금·볼거리·그 행사만의 것)가 공식 원문으로 받쳐지지 않으면 **그 행사를 바꾼다.** 억지 장으로 5를 채우지 않는다.

## ⚠ `본문5` 의 윗줄은 `headline` 키로 넘긴다

솔희가 준 안에는 「`본문5` SUBHEADLINE」이라고 적혀 있지만, **그 낱장에는 SUBHEADLINE 칸이 없다**
— 윗줄 칸의 역할이 `headline` 이다(2026-11-05 템플릿 101 확인). 숙소 호텔 하나도 같은 `본문5` 를 쓰고
같은 `headline` 으로 넘긴다.

- `subtext` 로 넘기면 **에러 없이 글이 사라진다**(방 지침서 「낱장 이름·자리는 템플릿 스튜디오가 기준이다」).
- 솔희가 템플릿 편집기에서 그 칸 역할을 SUBHEADLINE 으로 바꾸면 **이 문서와 4단계 문서를 그때 고친다.**
