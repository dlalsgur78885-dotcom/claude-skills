# X인용 — 5단계 캡션 문구

작성: solhee 방 / 2026-09-15 축 신설

사람이 준 안에는 이 단계가 「6단계」로 적혀 있었지만 5단계가 비어 있어 **5단계로 뒀다**(6단계는 세 축 공통 「세션 끊기」).

## 이 단계에서 하는 일

4단계 편집 링크와 함께 **캡션을 만들지 묻고**, 만들라고 하면 codex sol 로 짓는다. 아래 규칙을 prompt 에 **그대로** 싣는다.

## 캡션 문구 지침 (사람이 준 안 그대로)

1. **도입부 및 오프닝** — 저장 · 팔로우 · 댓글을 유도하는 문구를 먼저 활용하되, 매번 똑같은 위치나 박제된 문장으로 쓰지 말고 콘텐츠의 흐름에 맞춰 자연스럽고 유연하게 배치.
2. **이모지는 절대 고정하지 말고**, 매번 영상이나 이미지의 분위기(충격 · 유머 · 감동 · 심각 등)에 가장 잘 어울리는 것으로 다채롭게 선택.
3. **본문 작성 원칙** — 긴 설명이나 장황한 배경 지식은 배제하고, 핵심 상황만 직관적이고 짧은 문장으로 전달.
   억지스럽지 않은 말투를 사용하며, 문단 안쪽에 시청자의 공감이나 몰입을 유도하는 **질문형 문장**을 자연스럽게 녹여냄.
4. **참여 유도(CTA)** — 본문 하단에는 **「저장」과 「공유(친구 소환)」** 를 유도하는 문구를 반드시 포함하되, 콘텐츠의 성격에 맞게 매번 문장을 유연하게 변형. (예시를 그대로 복사하지 말고 내용에 맞춰 재창조할 것)
5. **해시태그 및 톤앤매너** — **메인 키워드만 2~3개** (2026-09-16 사람 지시 — 「해시태그 문구 필요없는 건 지우고, 메인 키워드만 2~3개」). 주제를 바로 가리키는 말만 남기고, 「#해외여행주의」처럼 있으나 마나 한 태그는 넣지 않는다. **채널 이름(#트립앤라이프)은 넣지 않는다**(2026-09-16 사람 지시). 설명충 같은 딱딱한 말투를 지양하고 트렌디한 SNS 감성을 유지.

## 짧게 쓴다 · 날짜와 계정은 쓰지 않는다 (2026-09-16 사람 지시)

사람 지시 — 「x 인용 캐러셀 캡션에 날짜 또는 원문 게시자는 표기할 필요없어, 캡션 문구를 좀 더 간결하게 써줘」.

- **게시 날짜·계정 아이디(@…)·조회수를 캡션에 쓰지 않는다.** 원문은 캐러셀 안 카드가 이미 보여준다.
- 한 문단에 한 가지만. 같은 말을 다른 문장으로 되풀이하지 않는다.
- ~~본문은 3문장 안쪽~~ → **아래 「본문 형식 — 3~5문단」으로 대체됨(2026-09-16 같은 날 지시).**

## 본문 형식 — 3~5문단 (2026-09-16 사람 지시)

사람 지시 — 「아래 예시 형식화해서 지침서에 추가. 예시 같은 문구인데, 너무 길지 않게 요약하도록. 최소 3문단~5문단」.

**문단 틀** — 문단 사이는 빈 줄로 띄우고, **한 문단은 1~2문장**.

1. **훅** — 상황을 한 문장으로 요약해 던진다. 이모지는 붙이면 0~1개.
   (예: 「너무 맛있어서 놀란 일본인😃」 / 「일본 요즘 근황.. 알바생들이 일본어를 모름..」 / 「지금 일본에서 실시간으로 엄청난 논란이 되고 있는 수신료 문제.」)
2. **배경·공감** — 읽는 사람이 아는 얘기로 잇는다. 「일본 살다 보면 ~」 「일본 편의점 가보면 ~하죠」
   ⭐ 이 문단이 **한국인 관점**이 들어가는 자리다(방 지침서 「이 축의 목표」). 일본 글을 옮기지 말고,
   **이걸 본 한국인이 드는 생각**을 쓴다. 건드릴 감정은 게시물마다 골라 잡는다 — 정해진 목록이 없다.
3. **사건 핵심** — 1~3단계에서 확인한 사실만 짧게. 여기가 뼈대다.
4. **반응·인용**(있을 때만) — 원문 반응은 큰따옴표로 1~2줄.
5. **마무리** — 해석 한 줄(「그래서 이런 반응이 나오는 게 아닐까 싶어요」) 또는 질문형(「~경험 있으신가요?」).

**3문단 이상 5문단 이하.** 2·4번은 소재에 없으면 건너뛰고, 대신 3번을 두 문단으로 쪼갠다. 문단이 6개를 넘으면 자른다.

**말투**

- 요약해서 짧게. 긴 배경 설명·설명충 문장을 붙이지 않는다.
- 단정하지 말고 여지를 둔다 — 「~같아요」 「~아닐까 싶어요」 「~에 가까워 보입니다」.
- 「~습니다」와 「~요」를 섞어 쓴다. 한쪽 어미로만 끝나면 기계 같다.

**그대로 유지** — 날짜·계정·조회수는 안 쓰고, 본문 뒤에 저장·공유 유도 한 줄 + 해시태그 2~3개를 붙인다(규칙 4·5). 예시에는 그 두 줄이 없지만 이 축 규칙은 유효하다.

## 함께 지킬 것

- 방 지침서 「문구 톤 — AI 티 안 나게」 를 prompt 에 함께 담는다.
- **원문에 없는 사실·숫자를 넣지 않는다.** 1~3단계에서 확인한 사실과 대조한다.
- 앞 회차 캡션(이 문서 「이번 회차」)과 **오프닝 위치·문장 틀·이모지가 겹치면** 다시 짓는다 — 1·2·4번 규칙이 「매번 다르게」다.
- 레퍼런스(트립초초 Dc7SZvuktzY) 캡션은 결만 참고한다. 문장을 가져오지 않는다.
