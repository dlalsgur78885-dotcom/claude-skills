# 캐러셀 템플릿 — 낱장 부품 (2026-10-21)

트립앤라이프가 준 **45건**(트립초초 39 · 니혼테레비 6)을 HikerAPI 로 받아
**전 슬라이드 150여 장**을 눈으로 분류했다. 원자료 `tmp/tpl/summary.json` ·
`tmp/tpl2/summary.json`, 한눈표 `tmp/tpl/sheet_1~4.jpg` · `tmp/tpl2/sheet_1~3.jpg`.
수치는 2026-10-21 조회 시점.

## 결론 — 부품은 다섯이면 된다

훅 종류·소재 종류로 나누지 않는다. **낱장이 화면에서 어떻게 생겼는가**로만 나눈다.

| 부품 | 생김새 | 45건 중 쓴 글 |
|---|---|---|
| **표지** | 사진 꽉참 · 아래만 어둡게 · 흰 굵은 2줄 · 계정표시 | **45 (전부)** |
| **사진+자막** | 배경 + 하단 가운데 흰 굵은 **1~2줄** | **21 (최다)** |
| **캡처카드** | 단색 배경 + 글 캡처(X·댓글·번역·리뷰) + 자막 | **17** |
| **사진** | 글이 하나도 없는 사진 | 15 |
| **텍스트** | 사진 없이 글만 | 6 |

- **다섯 중 넷은 「배경 + 하단 글」 한 틀의 변주다.** 글이 0줄이면 `사진`, 1~2줄이면
  `사진+자막`, 가운데 캡처가 얹히면 `캡처카드`, 배경이 없으면 `텍스트`.
  → 스튜디오에는 **글상자 자리가 같고 줄 수만 다른 낱장**으로 넣으면 된다.
- **CTA 낱장은 부품에 넣지 않았다.** 45건 중 1건에만 있었다(아래 §몰랐을 것).

## 자리 규격 (45건에서 안 흔들린 것만)

- 세로 4:5. 표지 훅은 **왼쪽 아래**, 흰 굵은 2줄, 줄당 9~13자. 3줄은 없었다.
- 본문 자막은 **가운데 아래**, 1~2줄. 3줄은 45건 중 1건(#13)뿐이다.
- 계정표시 — 트립초초는 훅 **아래** `일본 현지인 정보 @trip__chocho` + 좌상단 로고,
  니혼테레비는 훅 **위** `@니혼테레비`.
- 사진이 4:5 를 못 채우면 **위아래를 단색으로 깔고 가운데에 놓는다**(레터박스).
  영상에서 뽑은 장면은 전부 이 모양이다.
- **단색 배경은 검정이 기본**이고, 소재에 따라 갈색(#09)·회색(#16)·분홍(#41 치이카와)을 쓴다.
  한 게시물 안에서는 **같은 색으로 통일**한다.

## 사람이 몰랐을 것 세 가지

1. **CTA 장을 거의 안 붙인다 — 45건 중 1건**(#17, 마지막 장 구석에 `> 본문` 말풍선).
   우리 축은 전부 CTA 낱장을 매번 넣는다. **뺄지 말지는 사람이 정할 일이다.**
2. **2장짜리가 가장 많고(17건) 성적도 좋다.** 상위 5건 중 3건이 2~3장이다
   (8,508 · 7,684 · 11,901). 장수를 늘려서 득 본 흔적은 없다.
3. **니혼테레비는 본문에 글을 안 넣는다**(6건 중 5건이 `사진`만). 트립초초는 거의 넣는다.
   **글을 넣는 쪽이 우리와 맞다.**

## 등록 완료 (2026-10-21 사람 확정)

템플릿 **`트립앤라이프(종합)`** (id 96, **junhyeok 계정**) 하나에 낱장 여섯을 등록했다.
이름은 2026-10-21 사람 지시로 `트립초초(부품)` → `트립앤라이프(종합)` 으로 바꿨다.
처음 solhee 계정에 만든 것(95)은 사람 지시로 junhyeok 으로 옮기고 지웠다.
원본 `트립초초(사진only)`(93) 는 그대로 남아 있다.
**낱장 키는 아래 글자 그대로 넘겨야 한다** — 한 글자만 달라도 에러 없이 첫 낱장(`표지`)으로 떨어진다.

| 낱장 키 | 채우는 칸 | 생김새 |
|---|---|---|
| `표지` | `headline` (훅) | 사진 꽉참 + 아래 그라데이션 + 왼쪽 아래 흰 92px 2줄 + **그림자**(검정 80% · 거리 5 · 흐림 15 · 90°) |
| `사진+자막` | `headline` (1~2줄) | 사진 꽉참 + 아래 그라데이션 + 가운데 아래 흰 72px, 줄이 늘면 위로 자란다 |
| `캡처카드` | `headline` (자막) + 사진칸 1개 | 검정 배경 + 가운데 캡처(739×825) + 가운데 아래 흰 68px |
| `사진` | 없음 | 사진 꽉참, 글 없음 |
| `텍스트` | `body` | 검정 배경 + 왼쪽 54px 긴 글 |
| `CTA` | 없음 | 트립앤라이프 팔로우 이미지 한 판(93 에서 그대로) |

- 자막은 세 낱장 모두 **`headline`** 을 읽는다(`텍스트` 만 `body`). 캔버스는 1080×1350.
- `캡처카드` 의 사진칸은 `items[0].image_url` 로 들어간다 — 배경이 아니라 칸이다.
- 단색 배경은 검정으로 넣었다. 갈색·회색·분홍은 **낱장을 더 만들지 않고 편집기에서 배경색만 바꾼다.**
- **CTA 낱장은 사람 지시로 유지한다**(45건 중 1건뿐이지만 — §몰랐을 것 1).
- 여섯 낱장이 실제로 그려지는지 테스트 캐러셀 **898** 로 6장 전부 내보내 확인했다(2026-10-21).
- **표지 맨 위 가운데에 트립앤라이프 로고를 넣었다**(2026-10-21 사람 확정 — 「일단 이대로」) — 96·94 둘 다 `표지` 장식 이미지로 240×69, 위에서 110px, 가로 정가운데. 템플릿 데이터만 바꾼 것이라 **이미 만든 캐러셀에는 안 붙는다.**
- **트립초초 계정표시는 사람 지시로 지웠다**(2026-10-21) — `표지` 의 `TRIP CHOCHO KRJPMAG`·
  `일본 현지인 정보 @trip__chocho`, `사진` 의 `트립초초 일본 여행 매거진`. 계정표시는 CTA 낱장이 맡는다.
- ⚠ **방금 만든 캐러셀은 편집기를 처음 열 때 배경 사진이 검게 보인다.** 그 장을 열고
  **저장을 한 번** 하면 그때부터 제대로 보인다(2026-10-21 캐러셀 900 에서 확인).
