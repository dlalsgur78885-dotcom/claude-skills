# 영상이 들어가는 캐러셀 — 제작 흐름

작성: solhee 방 / **2026-10-20 트립앤라이프 결정** — 「표지(첫 장)와 CTA(끝 장)만 우리가 만들고,
사이 영상은 원본 그대로 **인스타 앱에서 직접** 올린다」.
글만 있는 캐러셀은 기존대로 스튜디오 → [업로드] 로 간다. 이 문서는 **영상형 전용**이다.

## 흐름 — 일곱 단계

1. **영상 확보** — 권리가 깨끗한 것만(자체 촬영 · 유료 스톡 · 관청 자료 · AI 생성).
   남의 유튜브·X 영상은 쓰지 않는다([_일본매체_RSS.md](_일본매체_RSS.md) 저작권 절).
2. **스튜디오에서 2장만 만든다** — 표지 + CTA. **본문 장은 아예 만들지 않는다.**
3. **한 폴더에 번호를 붙여 모은다** — `01_표지.png` · `02_영상.mp4` · `03_영상.mp4` … `99_CTA.png` · `caption.txt`.
   **한 폴더에 캐러셀 하나만.** 섞이면 앱에서 순서가 틀어진다.
4. **영상을 미리 1080×1350(4:5) 으로 잘라 둔다**(아래 명령 · 2026-10-20 트립앤라이프 지시).
   앱 크롭은 영상마다 손으로 맞춰야 하고 **아래쪽 자막이 잘린다.** 미리 자르면 앱에서는 고르기만 하면 된다.
5. **폰으로 한 번에 보낸다** — 받는 경로를 하나로 고정한다(드라이브 폴더 등). 매번 바꾸지 않는다.
6. **앱에서 표지부터 탭한다** — 인스타는 **첫 장 비율로 전체를 맞춘다.** 표지를 먼저 고르면
   뒤 영상이 그 비율에 맞춰 들어간다. 순서대로 탭 → 캡션 붙여넣기 → 게시(또는 앱 예약).
7. **이력에 한 줄 남긴다** — 「영상형 · 앱에서 수동 발행」. 스튜디오 [업로드] 를 안 거치므로
   기록이 저절로 남지 않는다.

## 1080×1350 자르기 (확인된 명령 · 2026-10-20 테스트)

**영상도 표지·CTA 와 같은 1080×1350(4:5) 이다**(2026-10-20 사람 확인 — 처음 1440 로 알았다가 정정).
스튜디오 템플릿·렌더러·본문 배경이 전부 1080×1350 이라 **비율이 전부 맞는다. 고칠 것이 없다.**

```
ffmpeg -i 원본.mp4 -vf "crop='min(iw,ih*4/5)':'min(ih,iw*5/4)',scale=1080:1350:flags=lanczos"   -c:v libx264 -crf 20 -pix_fmt yuv420p -an 02_영상.mp4
```

- 가운데를 기준으로 자르고 **1080×1350** 으로 맞춘다(출력 확인함).
- `-an` 은 **소리를 지운다.** 원본 소리를 살릴 거면 `-c:a aac` 로 바꾼다.
  ⚠ 남의 음악이 깔린 영상은 소리를 지우고 올린다.
- 세로 9:16 영상은 위아래가 잘린다. **자막이 아래 끝에 있으면 날아간다** — 자르기 전에 한 번 본다.

## 예상되는 불편과 대응

| 불편 | 왜 생기나 | 대응 |
|---|---|---|
| 장 순서가 뒤섞인다 | 앱 갤러리는 저장 시각순이라 헷갈린다 | **번호 파일명** + 한 폴더에 한 캐러셀 |
| 영상 아래 자막이 잘린다 | 앱이 자동으로 자르면서 위아래를 깎는다 | **미리 1080×1350 으로 잘라서** 넘긴다 |
| 전체 비율이 틀어진다 | 인스타가 **첫 장 기준**으로 맞춘다 | 표지를 **반드시 먼저** 탭 |
| 캡션 옮기기가 번거롭다 | PC 에서 쓴 글을 폰으로 옮겨야 한다 | 폴더에 `caption.txt` 를 같이 넣는다 |
| 예약이 안 된다 | 업로더 큐를 안 거친다 | **인스타 앱 자체 예약**을 쓴다(비즈니스 계정) |
| 이력이 안 남는다 | [업로드] 버튼을 안 누른다 | 7단계에서 사람이 한 줄 적는다 |
| 장수 한도 | 캐러셀은 2~10장 | 표지 1 + 영상 최대 8 + CTA 1 |

## 자동화로 줄일 수 있는 것 (아직 안 만듦)

**`pack_carousel`** — 캐러셀 번호를 주면 ① 표지·CTA 를 내려받고 ② 지정 폴더의 영상을 순번대로 복사하고
③ 1080×1350 크롭본을 만들고 ④ `caption.txt` 를 넣어 **폴더 하나로 묶는 스크립트**. 3·4·6단계가 한 번에 끝난다.
