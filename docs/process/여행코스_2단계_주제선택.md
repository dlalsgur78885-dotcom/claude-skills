# 여행코스 — 2단계 주제 선택 (템플릿 고정)

작성: solhee 방 / 2026-10-16 축 신설

## 이 단계에서 하는 일

1단계 후보 중 하나를 사람이 고른다. **사람이 주제를 바로 주면 여기서 시작한다**(1단계 건너뜀).
고른 주제로 **장수**를 정하고 3-1단계로 넘어간다.

## 템플릿 고정

- **트래블뷰(여행코스) id 91** (2026-10-16 API 확인). 사람이 다른 템플릿을 말하지 않으면 바꾸지 않는다.
- 낱장 세 개뿐이다 — `표지(여행코스)` · `본문(상황일본어)` · `CTA`.
  ⚠ 본문 낱장 이름이 **`본문(상황일본어)`** 다(상황별 일본어 축에서 복사된 이름). 보기에 안 맞아도 **그대로 쓴다** — 한 글자 틀리면 에러 없이 표지로 폴백한다.
  사람이 템플릿 스튜디오에서 이름을 바꾸면 **조회한 이름을 따라간다**(방 지침서 「낱장 이름·자리는 템플릿 스튜디오가 기준이다」).
- 표지는 하나뿐이다 — 다른 축의 `표지_2줄`·`표지_3줄` 구분이 **이 축엔 없다.**

## 주제에서 정하는 것

| 정할 것 | 기준 |
|---|---|
| 본문 장수 | 기간 그대로 — 당일치기 1 · 1박2일 2 · 2박3일 3 · 3박4일 4 · 4박5일 5 |
| 전체 장수 | 표지 1 + 본문 N + CTA 1 |
| 한 장에 들어가는 코스 | **4개 고정** (낱장에 사진·문구 칸이 4벌이다) |
| 전체 코스 수 | 본문 장수 × 4 — 2박 3일이면 12곳 |

- **기간이 애매하면 되묻는다.** 「오사카 여행 코스」처럼 기간이 없는 주제는 장수를 정할 수 없다.
- 코스 수가 4의 배수로 안 떨어지는 요청(예: 「하루에 3곳만」)이 오면 **빈 칸이 생긴다는 것을 알리고** 사람 판단을 받는다.
