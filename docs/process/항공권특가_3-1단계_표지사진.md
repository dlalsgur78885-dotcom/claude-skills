# 항공권특가 — 3-1단계 표지 사진

## 이 단계에서 하는 일 (2026-10-21 개정 — 사진을 덜 만들고, 4단계까지 이어 간다)

1. **표지 후보 3장**을 갤러리 링크 하나로 전달한다(비행기·하늘·그 여행지 풍경 등).
2. **본문 배경 사진**은 [사진 보관함](항공권특가_사진보관함.md) 에서 먼저 찾고, **없는 것만 생성**한다.
3. 표지 둥근 칸에 넣을 **항공권 목록 캡처**를 찍는다.
4. 사람이 표지를 고르면 **그 자리에서 4단계(생성·편집 링크)와 5단계(캡션)까지 한 메시지로 보낸다.**
   캡션을 만들지 묻지 않는다 (2026-10-21 솔희님 승인).

## 표지 배경 — 후보 3장

- **후보는 3장이다** (2026-10-21 솔희님 지시 — 전에는 5장. 사진 생성이 회차에서 가장 오래 걸리는 구간이다).
- 보관함의 표지 사진 중 **훅·계절에 맞는 것이 있으면 후보에 섞는다** — 그만큼 덜 만든다.
- **jpg·png 파일은 보내지 않는다 — 링크만.**
- 방 지침서의 이미지 품질 · **중앙 1:1 구도** 규칙을 프롬프트에 넣는다. 만든 뒤 가운데 정사각형 경계를 그어 보고 벗어난 장만 다시 그린다.
- 고른 1장은 **표지와 CTA 배경에 같이** 쓴다(사람 지시 — 「표지 이미지를 CTA 배경에도 같은 사진맞아」). 같은 장면을 다시 생성하지 않는다.
- 만든 사진은 **보관함에 한 줄 추가**한다(고르지 않은 후보도 적는다 — 다음 회차에 쓴다).

## 본문 배경 — 보관함 먼저 (2026-10-21 신설)

- [항공권특가_사진보관함.md](항공권특가_사진보관함.md) 에 그 도착지가 있으면 **그 URL 을 그대로 쓴다. 생성하지 않는다.**
- **한 캐러셀 안에서 사진이 겹치면 안 된다**는 규칙은 그대로다 — 같은 도착지가 3장이면 보관함에서 다른 장면 3개를 집는다.
- **회차 간 재사용은 된다** (2026-10-21 솔희님 승인 — 전에는 앞 회차 장면까지 피했다).
- 계절이 안 맞거나(단풍 사진을 1월에) 보관함에 없는 도착지만 생성하고, 만든 뒤 보관함에 적는다.
- 문구·칸 배분은 [3-2단계 본문](항공권특가_3-2단계_본문.md) 을 따른다(문구는 2단계에서 이미 보냈다).

## 표지 둥근 칸 — 항공권 목록 캡처

- 그 주제의 항공권 목록을 수집 페이지에서 캡처한다 — `flightCrash.apsl?dep=&arr=<코드>` 를 열어 최저가 카드를 찍는다.
  ⚠ 사람이 처음 준 `cordix.org` 는 로그인이 필요해 **로그인 화면이 찍힌다.** railway 주소에서 찍는다.
- 칸 비율 **880×600**(1.47:1)로 자른다(2026-09-30 확인 — 880×320 은 옛 값). 옆 카드가 비치면 흰색으로 지운다.
- **캡처는 `items` 한 개**로 넣는다 — `user_item_image_urls: {"0": {"0": 캡처}}` · `slides[0].items: [{}]`.
  로고에는 이제 템플릿 그림이 들어 있어 사진 자리로 세지 않는다(렌더러는 빈 칸이 하나라도 있으면 **빈 칸만** 짝짓는다 — `backend/app/services/carousel_renderer.py`).
  옛 규칙 `{"0":{"0":로고,"1":캡처}}` 로 넣으면 **로고가 둥근 칸에 들어가고 캡처는 사라진다.**
