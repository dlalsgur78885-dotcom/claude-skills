## 되는 것 / 안 되는 것

**되는 것 — 치이카와가 「현실에 나타난」 장면이다.**

1. **대기업·브랜드 협업 현물** — 맥도날드 종이봉투(130,183). 발표 기사가 아니라 **실물 사진**이다.
2. **의외의 사람·장소에서 발견** — 50대 부장님 넥타이(25,499). 「어울리지 않는 곳에 있다」가 웃음을 만든다.
3. **매장 현장** — 발주 실수로 쌓인 키링(4,081), 중국산 무허가 굿즈(7,636).
4. **공식 설정의 반전** — 실제 키(61,800). 팬도 몰랐던 숫자·설정이면 된다.
5. **랭킹·투표** — 캐릭터 랭킹(5,720, 댓글 214). 좋아요보다 **댓글이 목적일 때** 쓴다.

**안 되는 것**

1. **설명·배경 글** — 「치이카와의 역사」(1,970). 글 박스로 읽혀야 이해되는 소재는 떨어진다.
2. **만화 줄거리 옮기기** — 공식 만화 컷 번역(1,449, 댓글 2). 원작을 보는 사람은 이미 봤고, 안 보는 사람은 모른다.
3. **행사·공지 기사** — 「오늘부터 첫 운행」(318). **현물이 찍힌 사진이 없는 소식은 올리지 않는다.**
4. 이미 만든 소재 — 이력 확인.

> 한 줄로 — **「무슨 일이 있었다」가 아니라 「이런 게 있더라」** 다.
> 사진 한 장으로 「귀엽다 / 웃기다 / 신기하다」가 바로 와야 한다.

## 수집 — 문턱과 찾는 법

| 조건 | 값 |

| 기간 | **최근 14일** · 또는 **14일~6개월 전 — 명예의전당(조회 200만 이상 · 시의성 없는 글)** |

| 댓글 | **20개 이상** |
| 사진 | **현물 사진이 반드시 있어야 한다.** 글만 있는 소식은 후보에 올리지 않는다 |
| 수량 | **후보 10개** (그중 추천 3건) |

## 추천 3건을 맨 앞에 올린다

잣대 순서 — 1) **현물 사진이 있는가** → 2) **「이런 게 있더라」로 한 줄이 서는가** →
3) 위 「되는 것」 다섯 중 몇 개에 걸리는가 → 4) 조회수.

- 추천마다 **고른 이유 한 줄**(다섯 중 어느 것인지)을 적는다.
- 3건이 안 되면 억지로 채우지 않고 **2건·1건만 올리고 그 사실을 밝힌다.**

## 제작 — 표지

- 세로 **4:5**. **현물 사진을 꽉 채운다**(종이봉투 패턴·넥타이·진열대). 공식 그림을 쓸 때도 같다.
- 아래쪽만 어둡게 깔고 **흰 굵은 2줄**, 줄당 **9~13자**. 니혼테레비는 훅 **위**에 계정 표시를 둔다.
- 훅은 **「대상 + 벌어진 일」** — 「맥도날드 종이봉투 M로고 / 전부 치이카와로 '바꿨다'」,
  「일본 직장 50대 부장님, / 치이카와 넥타이 매고오셨다」.
  **핵심 단어에 작은따옴표**를 쳐서 한 군데만 세운다('바꿨다' · '실제 키' · '치이카와 키링').
- 표지는 **클로즈업**으로 가고, 전체 샷은 2장째에 둔다(아래).

## 제작 — 본문

레퍼런스의 잘된 것들은 **글이 거의 없다.**

- **기본 틀 = 표지(클로즈업) + 2장째(같은 것의 전체 사진).** 맥도날드 편(130,183)도,
  굿즈 가방 편(7,636)도 이 두 장이 전부다. **설명을 덧붙이지 않는다.**
- 사진이 더 있으면 **현장 사진을 그대로** 잇는다(매장 편 4장 — 일본어 POP 간판도 그대로 둔다).
- **랭킹형**을 쓸 때만 장수가 늘어난다 — 캐릭터 1마리당 1장, 아래에 **「5위. 랏코」**처럼
  순위·이름 한 줄. 5~6장. 캡션 마지막을 질문으로 닫아 **댓글을 받는 구조**다.
- ⚠ **글 박스를 만들어 설명하지 않는다.** 설명 장을 넣은 편(역사 1,970)이 이 유형에서 가장 약했다.
- ⚠ **공식 만화 컷을 번역해 옮기지 않는다**(퇴근길 1,449 · 댓글 2).
- 장수는 **1~4장**이 기본이다. 사진이 없으면 1장으로 끝낸다.

### 사진은 어디서 가져오나

- **원문 게시물에 올라온 사진**(목격자가 찍은 현물)을 그대로 쓴다. 생성 이미지로 대체하지 않는다.
- 공식 그림·설정 이미지를 쓸 때는 **공식 계정 게시물에서** 가져온다.
- ⚠ 치이카와는 **저작권이 있는 IP** 다. 굿즈·만화 그림을 우리가 다시 그리거나 합성하지 않는다.
  출처가 불분명한 사진은 뺀다.

## 제작 — 캡션

두 레퍼런스 계정의 틀이 다르다. **소재에 맞춰 고른다.**

- **사실형(니혼테레비 틀)** — `[대괄호 제목]` → 리드 한 문단 → 사실 전개 → 존댓말 '~습니다'.
  **확인 안 된 것은 못 박는다**(「공식 자료가 아닙니다」, 「라이선스 제품인지는 확인되지 않았습니다」).
  협업·발주 사고처럼 **사실관계가 있는 소재**에 쓴다.
- **대화형(트립초초 틀)** — 한두 문장마다 줄바꿈, 「~인데요」로 잇고 **마지막은 질문**으로 닫는다
  (「1위는 누구일까요?」). 랭킹·취향 소재에 쓴다. 해시태그 5~6개.
- 표지 훅과 캡션 첫 줄은 **달라도 된다** — 표지는 짧고 세게, 캡션은 사실 쪽이다.
