# 국내여행할인 — 5단계 캡션 문구

작성: solhee 방 / 2026-09-15 축 신설

## 이 단계에서 하는 일

릴스·숏츠 전용 캡션을 짓는다(codex sol). 아래 규칙을 prompt 에 **그대로** 싣는다.

## 1. 기본 원칙

- 정보 전달력이 높으면서 시선을 끄는 숏폼(릴스·숏츠) 전용 캡션.
- 불필요한 미사여구는 빼고 **간결하고 힘 있는 문어체**.
- 가독성을 위해 적절한 줄바꿈과 이모지.

## 2. 절대 금지

- 「아니...」「여러분」「안녕하세요」 같은 **대화형 오프닝**
- 억지스럽거나 부자연스러운 좋아요·구독 강요
- 맥락이 불분명한 상태에서 임의로 국가·지역명 특정
- 원문(공고)에 없는 숫자

## 3. 구조 — 4블록, 순서와 형태를 지킨다 (2026-10-01 사람 예시 2건으로 개정)

블록 사이는 **빈 줄 하나**로만 띈다. **`—` 구분선은 쓰지 않는다.**
전체 길이는 예시만큼 — **10줄 안쪽**으로 짧게.

① **훅 한 줄** — 핵심 혜택을 한 문장으로. **이모지는 문장 끝에 하나**(`…참가비 전액 무료🌲`).
- 돈이 안 드는 것이 가장 센 혜택이면 그걸 첫 줄에 쓴다(`무료로 한달살기🏡`).
- **경고·압박 줄은 넣지 않는다** — 「미루면 놓칩니다」·「그냥 넘기면 아쉽습니다」·「마감은 N일」 같은 줄을 따로 두지 않는다.

② **핵심 요약 ✔ 3줄** — ⓐ 기간·일정 ⓑ 장소·활동 ⓒ 대상·조건 순.
- 한 줄에 여러 사실을 담을 때는 `·` 로 묶는다.
- 문장으로 쓰면 존댓말, 끊어 쓰면 명사형(`…지원`·`중 선택`) — **반말은 쓰지 않는다.**

③ **댓글 유도 한 줄** — `👉 댓글에 "키워드" 남기시면 모집 정보를 DM으로 보내드립니다`
- ⚠ **맨 첫 줄이 아니라 해시태그 바로 위**다 (2026-10-01 사람이 준 예시 2건. 전에는 「첫 줄이 댓글 유도」 규칙이었고 **1~2회차 캡션이 옛 순서**다).
- **알람·저장 유도 클로징은 넣지 않는다** — 「마감 알람 설정하고 저장해 두세요」 줄을 따로 두지 않는다.

④ **해시태그** — **메인 키워드만 2~3개 · 채널 이름(#트립앤라이프)은 넣지 않는다** (2026-09-16 사람 지시 — 「해시태그 문구 필요없는 건 지우고, 메인 키워드만 2~3개」·「해시태그에 채널 이름 빼줘」). 주제를 바로 가리키는 말만 남기고, 있으나 마나 한 태그는 뺀다.

- 숫자·기간은 3-2·3-3 에서 확인한 원문 사실 목록과 대조한다.
