## 이 단계에서 하는 일

**일본 여행 코스 주제 후보 10개**를 뽑아 보여준다.
사람이 주제를 먼저 주면 이 단계를 건너뛰고 [2단계](여행코스_2단계_주제선택.md)로 간다.

## 시작 전에

1. [여행코스_이력.md](여행코스_이력.md) 를 먼저 읽는다 — **이미 캐러셀로 만든 주제는 다시 고르지 않는다.**
2. 다른 축 이력과 섞지 않는다.

## 주제 형식 — 세 토막 고정 (사람 지시)

```
[가야하는 이유 / 가야하는 사람] + [일본의 구체적인 지역] + [여행 기간]
```

- **세 토막을 모두 넣는다.** 하나라도 빠지면 후보에서 뺀다.
- 예 — `엄마랑 가는 교토 3박 4일` · `타코야키 먹으러 가는 오사카 당일치기` · `인생샷 찍는 삿포로 2박 3일`
- **카테고리가 골고루 섞이게 조합한다** — 같은 이유·같은 지역·같은 기간이 셋 이상 겹치지 않게.

### 이유 / 사람 — 사람이 준 풀

| 갈래 | 키워드 |
|---|---|
| 누구와 | 혼자 · 친구와 · 연인과 · 배우자와 · 아이와 · 부모님과 |
| 무엇을 | 체험·액티비티 · SNS 핫플레이스 · 자연과 함께 · 유명관광지 필수 · 여유로운 힐링 · 문화·예술·역사 · 쇼핑 · 먹방 |

- 10개 안에서 **「누구와」와 「무엇을」이 둘 다 나오게** 섞는다. 한쪽으로 쏠리면 다시 짓는다.

### 지역 — 사람이 준 풀

도쿄 · 오사카 · 교토 · 후쿠오카 · 삿포로 · 홋카이도 · 오키나와 · 나고야 · 나라 · 고베 · 요코하마 · 가마쿠라 · 시즈오카

- **이 목록 안에서만 고른다.** 더 좁은 동네 이름(난바·시부야 등)은 쓰지 않는다 — 지역은 도시 단위다.
- 같은 지역은 **10개 중 2개까지**.

### 여행 기간 — 기간이 본문 장수를 정한다

| 기간 | 본문 | 전체 장수 |
|---|---|---|
| 당일치기 | 1장 | 3장 |
| 1박 2일 | 2장 | 4장 |
| 2박 3일 | 3장 | 5장 |
| 3박 4일 | 4장 | 6장 |
| 4박 5일 | 5장 | 7장 |

- 전체 장수 = 표지 1 + 본문 N + CTA 1.
- **기간도 골고루 섞는다** — 10개가 전부 2박 3일이면 다시 짓는다. 당일치기·4박 5일도 한두 개 넣는다.

## 짓는 법

- 후보는 **`generate_copy`(codex sol) 로 짓는다** — 봇이 직접 쓰지 않는다(방 지침서 「문구 후보는 codex sol 로 짓는다」).
  위 형식·풀·섞는 규칙과 톤 규칙을 **prompt 에 다 옮겨 적는다.** codex 는 이 지침서를 읽지 않는다.
- 돌아온 10개를 규칙에 맞춰 검산한다 — 세 토막 · 지역 중복 2개 이하 · 기간 다섯 가지 모두 등장. 어기면 규칙을 더 적어 다시 부른다.

## 보여주는 법
