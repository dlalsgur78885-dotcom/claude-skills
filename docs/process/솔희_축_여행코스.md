## 템플릿은 99·101·102 한 벌이다 (2026-11-05 솔희 지시)

축마다 있던 템플릿 대신 **표지 `트래블뷰(표지)` 99 · 본문 `트래블뷰(본문)` 101 · CTA `트래블뷰(CTA)` 102**
한 벌을 쓴다. 바탕은 101 이고 표지·CTA 는 `@99:<낱장>`·`@102:<낱장>` 으로 빌린다.

- 아래에서 「템플릿 91」·`GET /templates/91` 로 적힌 자리는 **101**(표지는 99 · CTA 는 102)로 읽는다.
  낱장 값은 2026-11-05 에 한 벌과 **값이 같은지 대조**해 옮긴 것이다 — 글칸 위치·크기·폰트·장식이 같다.
- 옛 템플릿 91 는 **지우지 않았지만 쓰지 않는다**(솔희 지시). 이미 만든 캐러셀은 그대로 열린다.
- 회차를 시작할 때 낱장 이름을 다시 볼 때는 `GET /api/templates/layouts` 로 99·101·102 를 본다.

```
1 주제 후보 → 2 주제 선택(주제를 주면 여기서 시작) → 3-1 훅 → 3-2 썸네일 이미지 → 3-3 본문 → 4 스튜디오 생성·편집 링크(캡션 포함) → 6 세션 끊기
```

> **2026-10-26 — 캡션은 4단계에서 함께 짓는다.** 캐러셀을 만들 때 `canvas_data.caption` 에 전문을 넣어 저장하고,
> 편집 링크와 같은 메시지에 캡션을 담아 `[6단계 — 세션 끊기]` 로 닫는다. 5단계 메시지는 없다(문구 규칙은 5단계 문서 그대로).
> 공통 규칙은 [방 지침서 「캡션은 4단계에서 함께 짓는다」](솔희_캐러셀기획.md).

- 템플릿: **트래블뷰(본문) id 101**(바탕 · 표지 99 · CTA 102 — 2026-11-05 솔희 지시). 낱장 `@99:표지(여행코스)` · `본문6` · `본문7` · `@102:CTA2` **넷** (2026-10-21 API 재확인).
  ⚠ 2026-10-20 까지 쓰던 **`본문(상황일본어)` 는 없어진 이름**이다(사람이 템플릿에서 바꾸고 6코스 낱장을 더했다) — 넘기면 조용히 표지로 폴백한다.
  표지는 하나뿐이라 **다른 축의 `표지_2줄`·`표지_3줄` 구분이 없다.**
- **표지 낱장은 `트래블뷰(표지)` id 99 에서 빌린다** — `layout_overrides` 에 ``@99:표지(여행코스)`` (방 지침서 「표지는 `트래블뷰(표지)` 에서 빌려 쓴다」).
- **본문 한 장 = 하루.** 한 장에 넣는 코스가 **4개(`본문6`) 와 6개(`본문7`) 두 갈래**다 — **기본은 6개**다(2026-10-27 솔희님 지시 — 4개로 가려면 사람이 말해야 한다. 2026-10-22 갈래를 쪼갰을 때는 4개가 기본이었다). 장수는 기간이 정한다 — 당일치기 1 · 1박2일 2 · 2박3일 3 · 3박4일 4 · 4박5일 5 (전체 = 표지 1 + 본문 N + CTA 1).
- 사람이 준 안은 캡션이 5단계·편집 링크가 6단계였으나, **이 방 다른 축에 맞춰 4 편집 링크 / 5 캡션 / 6 세션 끊기로 뒀다**(일본숙소 축과 같은 처리).
