# 국내여행할인 — 5단계 캡션 문구

작성: solhee 방 / 2026-09-15 축 신설

## 이 단계에서 하는 일

릴스·숏츠 전용 캡션을 짓는다(codex sol). 아래 규칙을 prompt 에 **그대로** 싣는다.

> **2026-10-23 — 따로 메시지를 내지 않는다** (사람 지시 「캡션 문구도 캐러셀에 넣어서 생성해줘」).
> 캡션은 [4단계](정부지원_4단계_편집링크.md)에서 캐러셀을 만들 때 함께 짓고
> **`canvas_data.caption`(본문) · `canvas_data.hashtags`(해시태그 배열)** 에 넣어 저장한다 — 편집기 [업로드] 창이 그 값으로 채워진다.
> 아래 문구 규칙은 그대로 쓴다.

## 1. 기본 원칙

- 정보 전달력이 높으면서 시선을 끄는 숏폼(릴스·숏츠) 전용 캡션.
- 불필요한 미사여구는 뺀다. 다만 소개 2단락은 **말하듯 설명하는 `~어요` 체**로 쓴다(2026-10-26 개정 — 전에는 「간결하고 힘 있는 문어체」였다).
- 가독성을 위해 적절한 줄바꿈과 이모지.

## 2. 절대 금지

- 「아니...」「여러분」「안녕하세요」 같은 **대화형 오프닝**
- 억지스럽거나 부자연스러운 좋아요·구독 강요
- 맥락이 불분명한 상태에서 임의로 국가·지역명 특정
- 원문(공고)에 없는 숫자

## 3. 구조 — @nomadc.anna 틀 (2026-10-26 솔희님 지시로 전면 교체)

솔희님 지시 — 「표지 이미지, 캡션 문구 지침서만 nomadc.anna에 맞춰서 변경해줘」.
레퍼런스 계정 [@nomadc.anna](https://www.instagram.com/nomadc.anna/) 의 2026년 캡션 45건을 재서 뽑은 틀이다
(2026-10-26 조사 — 길이 중앙 **562자**, 해시태그 **5개 고정**, 댓글 중앙 238 : 좋아요 중앙 229).

> ⚠ **2026-10-22 「캡션문구 좀 더 요약해줘」 지시(훅 25자 · ✔ 3줄 45자 · 10줄 안쪽)는 이 개정으로 덮였다.**
> 레퍼런스 캡션은 그보다 길다(300~840자). 되돌릴 일이 생기면 이 줄을 보고 git 에서 옛 절을 꺼낸다.

블록 사이는 **빈 줄 하나**. `—` 구분선은 쓰지 않는다. 전체 **300~800자**(중앙 560자 어림).

① **제목 한 줄** — 무엇을 주는 건지 한 줄로. 표지 훅을 그대로 베끼지 않는다(표지는 짧고 센 쪽, 캡션은 사실 쪽).
- 조건을 괄호로 앞에 붙인다 — `(전액지원) 농촌 2박3일`, `(선착순) 전국 템플스테이 50% 할인`, `(곧 종료) 김해 3박~한달살기 여행지원금`.
- 이모지는 **안 쓰거나 끝에 하나**까지.
- 협찬이면 제목 끝에 `(광고)` 를 붙이고, 주관 기관 각주를 캡션 맨 끝에 `*` 한 줄로 단다.

② **소개 줄글 2단락** — 단락마다 2~3문장, **120~160자**. 존댓말 `~어요` 체. **✔ 기호를 쓰지 않는다. 줄글이다.**
- 1단락 = 무슨 프로그램이고 **왜 끌리는지**. 지역·장소 이름을 넣어 장면이 그려지게 쓴다.
- 2단락 = **선정되면 무엇을 받는지** + 참가비 + 누가 신청할 수 있는지.

③ **항목 블록** — 라벨을 한 줄에 쓰고 **다음 줄에 값**을 쓴다. 블록 사이는 빈 줄 하나. **5~8개.**
- 라벨은 이 중에서 고른다(순서도 이 차례) — `프로그램` `모집대상` `모집기간` `여행기간` `체류지역` `참가비용` `여행지원금` `참여혜택` `주요활동` `주요미션` `활동미션` `신청방법`.
- 그 회차에 없는 라벨은 뺀다. 날짜는 `2026.9.23(수) ~ 10.2(금) 13:00` 처럼 **원문 표기 그대로**.
- 값이 길면 다음 줄에 `(…)` 또는 `※ …` 로 보조 한 줄을 단다. 지역이 여러 곳이면 `📍` 를 줄마다 붙여 나열한다.

④ **`===` 한 줄** — 항목 블록과 댓글 유도 사이에만 넣는다.

⑤ **댓글 유도 두 줄 — 키워드를 지정하지 않는다**

```
💬 댓글 남기면
DM으로 프로그램 정보를 보내드려요
```

- ⚠ **옛 `👉 댓글에 "키워드" 남기시면` 꼴은 쓰지 않는다.** 키워드를 정확히 적어야 걸려서 문턱이 하나 더 있다.
  레퍼런스는 아무 댓글이나 받고, 그 결과 댓글이 좋아요와 거의 1:1 로 붙는다.
- 알람·저장·압박 클로징(「미루면 놓칩니다」·「마감 알람 설정하고 저장해 두세요」)은 여전히 넣지 않는다.

⑥ **해시태그 5개** — 공백으로 띄우고 **두 줄(3개 + 2개)** 로 나눈다. 채널 이름은 넣지 않는다.
- **좁은 것 3 + 넓은 것 2** 로 섞는다 — `#의성 #가족여행 #친구랑` / `#여행지원금 #캠핑`.
  좁은 것만 쓰면(`#장흥반값여행`) 검색으로 들어올 길이 없다. 넓은 것은 `#국내여행` `#여행지원금` `#한달살기` `#가족여행` `#친구랑` 류.
- 이 축은 해시태그를 `canvas_data.hashtags` 배열에 따로 넣는다(본문에 다시 쓰지 않는다).

- 숫자·기간은 3-2·3-3 에서 확인한 원문 사실 목록과 대조한다.
- codex sol prompt 에는 **이 절 전체를 그대로 싣는다**(앞 회차 `cap_front.txt` 를 복사해 쓸 때 이 절이 빠지지 않게 한다).
