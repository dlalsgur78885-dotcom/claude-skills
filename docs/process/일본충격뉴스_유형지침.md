## ⭐ 이 유형의 핵심 — 「일본 뉴스」가 아니라 「한국인이 걸린 일본 뉴스」다

8건 중 혼자 튄 **3,743(팔로워 대비 6.96%)** 은 아시안게임 태극기 게양 사고다.
**일본 소식이 아니라 한국이 당사자인 사건**이고, 본문 마지막이 **일본인 반응 번역**이었다.
나머지 일본 내부 사건은 전부 200~1,149 다.

| 소재 결 | 좋아요 |
|---|---|
| **한국이 당사자** (태극기 게양) | **3,743** |
| 피해 대상·숫자가 구체적 (고교 14곳 깔창 도난) | 1,149 |
| 일본 내부 사건, 구체적 (축제 수레 사고·병원 촬영) | 586~860 |
| 일본 내부 가십·재난 (21살차 결혼·태풍 피해) | 200~246 |

→ **후보 순서는 「한국이 걸렸는가」가 1번 잣대다.**

## 찾는 소재 — 네 갈래 (위가 우선)

1. **한국·한국인이 당사자인 일본발 사건** — 한국 선수/관광객/교민이 겪은 일, 한일전·국제대회 논란.
2. **한국인에게 그대로 생길 수 있는 일** — 관광지·숙소·병원·대중교통에서 터진 사건, 새 규제.
3. **피해 대상과 숫자가 박힌 일본 사회 사건** — 「고교 14곳」처럼 범위가 세어지는 것.
4. **일본 안에서 여론이 갈린 연예·사회 논란** — 일본인 반응이 양쪽으로 갈려야 쓸 값이 있다.

**후보가 되려면 셋이 있어야 한다.**

- **현장 사진·영상이 있다** — 기사 텍스트만 있는 소재는 뺀다.
- **일본인 반응을 모을 수 있다** — X 댓글·야후 재팬 코멘트가 붙어 있어야 한다(마지막 장 재료).
- **한 줄로 무슨 일인지 말할 수 있다** — 배경 설명이 필요하면 떨어진다.

## 빼는 것

1. **티저 훅으로밖에 못 쓰는 소재** — 「심각한 사건」·「역대급 논란」으로 뭉개야만 성립하는 것.
   레퍼런스에서 티저 훅 3건이 전부 하위권(200·586·860)이다. 아래 「제작 — 표지」 참고.
2. **환율·여론조사·일반 재난** — 태풍 피해 200, 위험국가 여론조사 236. 시의성은 반응을 보장하지 않는다.
3. **사망·자살·성범죄·아동 피해를 묘사해야 하는 사건** — 인스타 제재와 계정 위험이 실익보다 크다.
   사건의 결말이 사망이면 **사실만 한 줄**로 적고 장면·사진은 쓰지 않는다.
4. **실명·얼굴이 드러난 일반인** — 가해자든 피해자든 모자이크 없이는 쓰지 않는다.
5. **혐한·반일 감정을 때리는 각** — 「일본 또 이런다」 류로 몰아가지 않는다. 사실과 반응만 전한다.
6. 이미 만든 소재 — 이력 확인.

## 수집 — 문턱과 찾는 법

| 조건 | 값 |
|---|---|
| 소재원 | **야후 재팬 뉴스 댓글 랭킹 1순위**(`news.yahoo.co.jp/ranking/comment`) · X 일본어 묶음 · 일본 온라인 커뮤니티 · 유튜브 뉴스 클립 |
| 기간 | **최근 7일** (시의성 유형이라 명예의전당 묶음은 걸지 않는다) |
| 조회 | **10만 이상** (사건 소재는 X 에서 크게 돈다) |
| 댓글/인용 | **100개 이상** — 일본인 반응이 모여야 마지막 장을 만든다 |
| 사진 | **현장 사진·영상이 반드시 있어야 한다** |
| 수량 | **후보 10개** (그중 추천 3건) |

⚠ **X 는 웹 검색으로 찾지 않는다.** grok 헬퍼로만 — 타임아웃 480초 이상 주고 그 자리에서 기다린다.
**유튜브·스레드·커뮤니티 경로와 명령은 [_유형공통.md](_유형공통.md) 「소재원 — 다섯 경로」에 모아 뒀다.**

**검색 키워드**

| 묶음 | 키워드 |
|---|---|
| 사건·논란 | `炎上` · `物議` · `批判殺到` · `騒然` · `問題視` |
| 한국이 걸린 것 | `韓国人` · `日韓` · `韓国代表` · `韓国人観光客` |
| 관광객이 겪는 것 | `観光客` · `インバウンド` · `トラブル` · `マナー違反` |

- **한국이 걸린 묶음을 먼저 건다.** 1위 소재가 거기서 나왔다.
- 문턱을 채우는 글이 모자라면 **억지로 채우지 않고 부족한 건수를 밝힌다.**

### 사실 확인 — 이 유형만의 의무

사건을 다루므로 **틀리면 되돌릴 수 없다.**

- 날짜·장소·인원·기관명은 **원문에서 확인한 것만** 쓴다.
- 원문 게시자의 주장과 확인된 사실을 **섞지 않는다.**
- 확인 못 한 것은 캡션에 그대로 적는다 — 「사고 발생 날짜와 정확한 장소는 특정하기 어렵습니다」.
  니혼테레비가 실제로 쓰는 방식이고, 이 유형에서는 필수다.

## 추천 3건을 맨 앞에 올린다

잣대 순서 — 1) **한국이 걸렸는가** → 2) **대상·숫자가 구체적인가** →
3) **현장 사진이 있는가** → 4) **일본인 반응이 모였는가** → 5) 조회·댓글 수.

- 추천마다 **고른 이유 한 줄**(네 갈래 중 무엇인지 + 왜 한국인이 볼 이유가 있는지)을 적는다.
- 3건이 안 되면 억지로 채우지 않고 **2건·1건만 올리고 그 사실을 밝힌다.**

## 제작 — 표지

- 세로 **4:5**. 현장 사진을 꽉 채우고 아래쪽만 어둡게, **흰 굵은 2줄**, 줄당 **9~13자**.
- ⚠ **티저 훅 금지.** 「일본에서 터진 심각한 사건」·「역대급 논란」·「얼마나 심각하냐면..」은
  레퍼런스에서 전부 하위권이었다. **무슨 일인지 표지에서 밝힌다.**
- 통한 훅 셋 —
  - **대상 + 숫자**: 「일본내 고등학교 14곳 이상서 / 여학생들 깔창 도난사건 급증」
  - **한국이 걸린 장면**: 「국기가 게양되지 / 않았던 이유」
  - **전언체 + 반복**: 「또 터졌다는 일본 / 단지리 축제 사고」 (「또」가 사건의 누적을 깐다)
- 자극적인 단어(대참사·충격)로 세기를 만들지 말고 **구체적인 명사와 숫자로** 만든다.

## 제작 — 본문

**3~5장.** 레퍼런스에서 잘된 것과 안 된 것을 가른 건 장수가 아니라 **마지막 장**이다.

| 장 | 내용 |
|---|---|
| 1 | 표지 — 사건을 한 줄로 못 박는다 |
| 2~3(4) | 현장 사진 + **한 줄 자막으로 시간순 중계**. 한 장에 한 사실만 |
| 마지막 | ⭐ **일본인 반응 번역 카드** 또는 **결말 카드** |

- **마지막 장이 이 유형의 전부다.** 1위(3,743)는 검은 배경에 일본어 원문 + 한국어 번역을
  말풍선으로 3~5개 얹은 **반응 카드**였고, 6장짜리도 마지막이 「다음날 뜬 뉴스에서 /
  동일위치 사망 사건 보도」라는 **검은 텍스트 결말 카드**였다.
- **반응도 결말도 없는 소재는 만들지 않는다.** 사진만 늘어놓은 2건이 200·246 으로 바닥이었다.
- 일본어 원문을 쓸 때는 **원문 + 한국어 번역을 함께** 올린다. 번역만 올리지 않는다.
- 자막 톤은 **중계체 반말**(「검은옷 아저씨의 뺨을 때림」), 캡션은 존댓말이다. 섞지 않는다.

## 제작 — 캡션

두 틀 중 소재에 맞는 것을 쓴다.

**① 대화체** (한국이 걸린 소재 · 1위가 쓴 틀)
1. 첫 줄 — 상황 한 문장(「금메달 시상식이 끝난 뒤, 일본에서 예상보다 큰 비판이 나오고 있습니다」).
2. 사실 전개 — 한두 문장마다 줄바꿈, 「~인데요」로 이어간다.
3. **일본 현지 반응 3줄 인용** — 따옴표로 그대로 옮긴다. 여기가 핵심이다.
4. 마무리 한 줄 소감. 해시태그 5개 안쪽.

**② 기사체** (일본 내부 사건)
1. `[대괄호 제목]` → 리드 한 문단 → 사실 전개. 존댓말 '~습니다'. 800~1,200자.
2. **확인 안 된 것을 못 박는 문단을 반드시 넣는다** — 「~는 확인되지 않았습니다」.
3. 배경 설명 한 문단(용어·제도)을 끼운다.

- ⚠ **어느 틀이든 단정하지 않는다.** 전언은 「~라고 전해졌습니다」, 주장은 「~는 주장도 나왔습니다」.
