# 여행코스 — 3-1단계 썸네일 훅 문구

작성: solhee 방 / 2026-10-16 축 신설

## 이 단계에서 하는 일

표지에 올릴 **훅 문구 후보 10개**를 짓는다. 사람이 하나를 고른다.

## 규격 — 3줄 고정 (사람 지시)

- **3줄. 한 줄은 공백 포함 12글자 이하.**
- 10개 **모두 3줄**이다 — 이 축 템플릿에는 표지가 `표지(여행코스)` 하나뿐이라 2줄 표지가 없다.
- 줄 나눔은 **보여줄 때부터 넣을 모양 그대로** 적는다(`/` 로 줄을 끊어 보여주고, 4단계에서 `\n` 으로 넘긴다).
- 글자 칸: x80 · y510 · 폭 920 · 85px · 왼쪽 정렬 (템플릿 91 — 2026-10-16 확인).
  **글씨가 사진 가운데를 지나간다** — 3-2 에서 가운데가 복잡한 사진은 피한다.

## 짓는 법

- 주제의 세 토막(이유·지역·기간)이 **훅 안에 다 보이게** 한다. 특히 **지역과 기간은 반드시** 들어간다.
- 「여행 코스」·「코스 총정리」 같은 꼬리말을 한 줄로 쓰면 읽기 쉽다.
- 후킹 방식을 매번 새로 섞는다 — 대상 지목 · 먹을 것 · 인생샷 · 숫자 · 동선 정리.
- 사람이 준 예시(그대로 기준이다):

```
엄마랑 / 교토 3박 4일 / 여행 코스
도쿄 2박 3일 / 라멘 먹방 / 여행 코스 총정리
타코야키 먹으러 / 오사카 당일치기 / 완벽 코스 정리
빵순이의 / 나고야 여행 / 2박 3일 코스
인생샷 찍고 온 / 삿포로 여행 코스 / 12개 총정리
```

- **숫자를 쓰면 실제와 맞춰야 한다** — 「12개 총정리」는 코스가 12곳(본문 3장 × 4)일 때만 쓴다.
- 문구 후보는 `generate_copy`(codex sol) 로 짓는다. 톤 규칙은 방 지침서 「문구 톤 — AI 티 안 나게」.
