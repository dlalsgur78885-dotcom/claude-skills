# 명소 — 5단계 캡션

축 전체는 [솔희_축_명소.md](솔희_축_명소.md).
**4단계에 흡수됐다** — 캐러셀을 만들 때 `canvas_data.caption` 에 전문을 넣고, 편집 링크와 같은
메시지에 담는다. 5단계 메시지는 따로 보내지 않는다.

## ① 명소·전시 모음 — 다섯 덩어리

훅 → 정리해 둔 것 한 줄 → 댓글 유도 → 번호 목록 → 해시태그. 뼈대는 [일본숙소 모음 틀](일본숙소_5단계_캡션.md)과 같고
**댓글 유도만 이 축이 다르다**(2026-11-02 솔희 예시 — 숙소의 `⭐ 저장+팔로우` 2줄을 쓰지 않는다).

```
<훅 한 줄>(이모지)

<정리해 둔 것 한 줄>

💬[댓글] 남겨주시면 지도 링크 보내드릴게요!

1. <명소 이름 — 본문 headline 그대로>
<한 줄 설명>

2. <명소 이름>
<한 줄 설명>

…(본문 장수만큼)

#지역여행 #지역명소 #지역가볼만한곳 #일본여행 #세부동네여행
```

- **훅 한 줄** — 지역 + 주제 조건을 담고 끝에 이모지 하나. 특정 명소 이름은 넣지 않는다.
- **댓글 유도는 두 덩어리다** (2026-11-02 솔희 예시로 교체 — 옛 `⭐ 저장+팔로우` 2줄은 폐기).
  - 앞줄 — **왜 이걸 모았는지 + 무엇이 담겼는지** 한 줄. 「찾기 귀찮았던 …, 후기, 평점까지 전부 정리했습니다」처럼
    사람이 귀찮았던 일로 열고 「~했습니다」로 닫는다. 회차마다 소재에 맞게 새로 쓴다.
  - 뒷줄 — `💬[댓글] 남겨주시면 지도 링크 보내드릴게요!` **글자 그대로 고정.**
    대괄호 `[댓글]`이고 큰따옴표가 아니다. `저장+팔로우`·`DM으로`·`⭐`는 쓰지 않는다.
  - 두 줄 사이에 **빈 줄 하나**를 둔다.

> 솔희 예시 — 정본 (2026-11-02)
>
> ```
> 하나하나 비교하며 찾기 귀찮았던 맛집 정보, 생생한 후기, 평점까지 지도 한 장에 전부 정리했습니다.
>
> 💬[댓글] 남겨주시면 지도 링크 보내드릴게요!
> ```

- **명소 이름은 본문 `headline` 을 글자 그대로 옮긴다.** 캡션에서 다시 짓지 않는다.
- **주소는 캡션에 넣지 않는다** — 본문 `subtext` 의 구글 지도 주소는 낱장에만 쓴다.
- 한 줄 설명은 **15~20자**, 고를 이유 **한 가지만**(무료·전망·소요 시간·야간개장 중 하나).
- 해시태그 **5개**.

## 축제·팝업 모음(꼴 ③) — ① 모음 틀을 쓴다 (2026-11-04 추가)

⚠ **이 문서의 ①~④ 는 캡션 틀 번호**이고 꼴 번호와 겹친다. **꼴 ③ 축제·팝업 모음은 캡션 틀 ①(번호 목록)** 으로 쓴다.
④ 총정리형은 한 건짜리 틀이라 쓰지 않는다.

- 뼈대는 위 「① 명소·전시 모음」 그대로다 — 훅 한 줄 → 정리해 둔 것 한 줄 → `💬[댓글]` 두 덩어리 → 번호 목록 → 해시태그 5개.
- **번호 줄에 기간을 붙인다** — `1. <행사 이름> (11/7~12/25)`. 이름은 본문 `headline`, 기간은 본문 `subtext` 를 그대로 옮긴다.
- 전역 모음이면 번호 줄 앞에 **도시 이름**을 둔다 — `1. 삿포로 — <행사 이름> (11/20~12/25)`.
- 한 줄 설명은 ① 과 같이 **15~20자**, 고를 이유 한 가지만(무료·역에서 가깝다·야간).
- 훅 한 줄에는 **기간과 몇 개인지**를 담는다(개별 행사 이름은 넣지 않는다 — 번호 목록이 말한다).

## ② 축제·팝업 하나 — **폐기** (2026-11-02 ③ 으로 통일 → 2026-11-03 부터 ④ 총정리형)

축제·팝업·전시 한 건의 캡션은 **④ 총정리형**으로 쓴다(2026-11-03 솔희 원문).
2026-11-02 에 ③ 소식형으로 통일했다가 하루 뒤 ④ 로 다시 갈렸다. 옛 세 덩어리 틀(훅 2줄 + DM 유도 + 해시태그)은
쓰지 않는다 — 아래 「기록」에 남겨 뒀다.

- 캡션에서 **행사 이름·요금·예매처를 쓴다.** 감추지 않는다.
- **댓글 유도·DM 유도는 넣지 않는다.** 기간·요금·예매는 `📍` 블록으로 적는다.
- **해시태그는 3개 붙인다** (2026-11-03 ④ 로 바뀌며 되살아났다 — 2026-11-02 엔 「없음」이었다).
- ✅ **낱장도 이름을 쓴다** (2026-11-03) — ② 본문 1번 장 윗줄이 행사 이름이다
  ([3-3 「행사 이름은 쓴다」](명소_3-3단계_본문.md)). 캡션과 낱장의 어긋남은 없어졌다.

## ③ 한 건 소식 — 문단형 (2026-11-02 솔희 지시 「예시 형식화해서 지침서 반영」)

**개장·폐쇄·공사, 계절 소식**에 쓴다.
⚠ **기간 한정 축제·팝업·전시는 2026-11-03 부터 아래 「④ 기간 한정 행사 — 총정리형」 이다** — 이 축이 만드는 ② 꼴은 거의 다 ④ 다.
번호 목록도 DM 유도도 없다. 짧은 문단을 쌓아 **뉴스처럼** 읽히게 한다. 아래 솔희 예시 3개가 정본이다.

```
<제목 한 줄>(이모지)

<도입 1문장 — 큰 그림>

<핵심 1문장 — 날짜·기간·수치>

<부연 1문장 — 「~인데요」로 다음 줄에 넘긴다>

<추가 1~2문장 — 예외·장면·세부>

<맺음 1문장>(이모지)

(※ 주의 한 줄  또는  📍 정보 블록 — 필요한 것만)
```

- **문단 5개**, 문단 사이에 빈 줄 하나.
- **한 문단 한 문장.** 예외·세부를 말하는 네 번째 문단만 두 문장까지(예시 1·3).
- 종결은 「~습니다」로 통일한다. **제목 한 줄만** 「~내렸다」·「상륙!」처럼 제목체로 끊어도 된다.
- **이모지는 두 개** — 제목 끝과 맺음 끝에 하나씩. 중간 문단에는 달지 않는다.
- **해시태그는 넣지 않는다.**

### 자리마다 무엇을 쓰나

| 자리 | 쓰는 것 |
|---|---|
| 제목 | 지역·대상 + 무슨 일인지. 쉼표로 끊는다 |
| 도입 | 그게 무슨 일인지 한 발 물러서서 |
| 핵심 | **날짜·기간·수치를 여기 몰아 넣는다** |
| 부연 | 핵심에서 빠진 범위·배경 |
| 추가 | **읽는 사람이 걱정할 것**을 먼저 답한다(「다만 전체가 문을 닫는 것은 아닙니다」) |
| 맺음 | 여행 계획과 이어 준다 |

- **꼬리 두 가지** — 일정·이용이 바뀔 수 있으면 `※` 한 줄, 기간·요금·예매가 있는 행사면 `📍` 블록.
  둘 다 없어도 된다(예시 2).
- `📍` 블록은 예시 3 그대로 — `📍 전시 정보` 뒤에 `▫️ 기간` · `▫️ 장소` · `▫️ 입장료` · `▫️ 예매` 네 줄.
  칸 이름은 소재에 맞게 바꾸고(`📍 행사 정보`), **모르는 칸은 지어내지 말고 뺀다.**
- 날짜·기간·요금·관람객 수는 **공식 발표에서 확인한 것만** 쓴다 → [축 문서 「확인」](솔희_축_명소.md).

### AI 티 절과 어긋나는 것 하나

맺음의 `~해 보세요`·`~어떨까요?` 는 [캡션 공통](솔희_캡션공통.md) 「피할 것」에 걸리지만
**이 틀에서는 쓴다** — 솔희 예시 1·3이 그렇게 끝난다. 나머지(대구 반복·속 빈 수식어·접속 부사로
문단 열기)는 그대로 지킨다.

## ④ 기간 한정 행사 — 총정리형 (2026-11-03 솔희가 직접 쓴 캡션)

**축제·팝업·전시처럼 기간이 정해진 한 건은 이 틀로 쓴다.** ③ 문단형은 개장·폐쇄·공사·계절 소식에 남는다.
③ 과 다른 점은 셋 — **문단이 둘뿐 · 한 문장을 줄 단위로 끊어 쓴다 · 해시태그 3개를 붙인다.**

> **왜 짧아졌나** — 본문 5장이 기간·요금·볼거리를 이미 다 말한다(2026-11-03 새 본문 규칙).
> 캡션에서 같은 말을 되풀이하지 않고 **핵심 한 문장 + 정보 블록**만 남긴다.

```
<연도> <지역> <행사> 총정리 (이모지 1~2개)

오는 <기간>,
<장소>에서
‘<행사 이름>’이 열립니다.

<계절·지역으로 여는 조건절>,
<권유 한마디>(이모지)

📍 행사 정보
▫️ 기간: 2026.11.07 ~ 12.25
▫️ 장소: <장소> (<지역>)
▫️ 시간: <요일별 여닫는 시각>
▫️ 입장료: <무료/금액> (<따로 드는 것>)

#<지역>여행 #<소재><지역> #일본여행
```

- **문단은 둘이다** — ① 핵심 한 문장(기간·장소·행사 이름) ② 맺음 한 문장. ③ 의 도입·부연·추가 문단은 쓰지 않는다.
- **한 문장을 의미 단위로 2~3줄로 끊는다.** 줄 끝의 쉼표는 그대로 남긴다(솔희 원문이 그렇다).
- **행사 이름은 작은따옴표 ‘ ’** 로 감싼다. 공식 한국어 표기가 없으면 공식 일본어 이름을 옮겨 적는다.
- **제목은 「총정리」로 맺고 연도를 앞에 붙인다.** 이모지는 제목 끝에 1~2개, 맺음 끝에 1개다.
- **해시태그 3개를 맨 끝에 붙인다** (2026-11-03 되살림 — ③ 은 「넣지 않는다」였다).
  꼴은 `#<지역>여행` · `#<소재><지역>` · `#일본여행`. 다섯 개로 늘리지 않는다.
- `📍 행사 정보` 는 **기간·장소·시간·입장료 네 줄**이다. 날짜는 `2026.11.07 ~ 12.25` 꼴로 적고,
  **모르는 칸은 지어내지 말고 뺀다.** 예매가 필요한 행사면 `▫️ 예매` 를 더한다.
- 숫자는 **공식 발표에서 확인한 것만** 쓴다(→ [축 문서 「확인」](솔희_축_명소.md)).
- 종결은 「~습니다」로 맞추고, 맺음만 「~어떨까요?」·「~해 보세요」를 쓴다(③ 과 같다).

### 솔희 원문 — 정본 (2026-11-03 · 후쿠오카 크리스마스 마켓)

```
