## 2. 형식화 — 이 계정의 훅은 이 틀 하나다

```
[1줄] 시점 · 가격 · 상태 수식어          (언제 / 얼마 / 어떤 상태인가)
[2줄] 후쿠오카 + 숙소 유형 (+ 곳수 · 이모지)   (무엇을 소개하나)
```

두 줄의 앞뒤가 바뀐 것도 있다(1·3·5·11번은 「후쿠오카 + 유형」이 1줄). 틀은 같다.

관찰된 규칙:

| 항목 | 11건 실측 |
|---|---|
| 줄 수 | **2줄 100%** (3줄 0건) |
| 줄 글자 수 | 8~17자 (긴 줄 15자 초과가 4건) |
| 지역 표기 | **「후쿠오카」 하나뿐** — 하카타·텐진 같은 세부 지명 0건 |
| 호텔 이름 | **0건** — 표지에 상호를 아예 안 쓴다 |
| 「호텔/숙소」 | 11건 전부 들어 있다. 9건이 숙소 명사로 끝난다 |
| 곳수 숫자 | 모음 2건만 「5곳」. 호텔 하나 주제는 숫자 없음 |
| 이모지 | 6건 (👀 ♨️ ✨ · 끝에 1개) |
| 문장 꼴 | 명사구 종결이 주. 반말 권유(「~하자」·「~으로」)·물음(「~가?!」) 섞음 |

소재 3축 (겹침 포함) — **신상·오픈 시점 7건** · **가성비·가격 5건** · **온천·대욕장·사우나 6건**.
이 세 축 밖의 훅이 없다. 「언제 생겼나 / 얼마냐 / 물이 있나」로 전부 수렴한다.

## 3. 우리 숙소 축과 다른 점

비교 대상 — [일본숙소_3-1단계_훅문구.md](일본숙소_3-1단계_훅문구.md) 의 규칙과 18~20회차 후보 40개.

| | hi.miniii 11건 | 우리 (18~20회차) |
|---|---|---|
| 줄 수 | 2줄만 | 2줄 5 + **3줄 5** 로 반반 |
| 호텔 이름 | **안 쓴다** | 직관성 조건 1번이 **쓰라고 요구** (힐튼 씨호크·미마루) |
| 지역 입도 | 광역 1개(후쿠오카) | **세부 역·동네** (신오사카·아사쿠사·난바) |
| 주력 숫자 | **가격(2인 8만원대·1박 4만원대)** · **오픈 시점(9월 1일·10월)** | **역 도보 분 · 방 크기 · 인원수 · 평점** |
| 가격 | 5건에 등장 | **거의 0** — 「확인 못 한 요금은 금지」라 매번 프롬프트에서 막았다 |
| 모음 곳수 | 5곳 | 8곳 |
| 대상 호명 | 거의 없음 | **「넷이」·「가족 넷이」·「친구 넷이」가 20회차 10개 중 9개** |
| 당기는 장치 | 계절(「날도 추워지니까」) · 시리즈(「저장 많아서 2탄」) · 정보 우위(「아직 잘 모르는」) | 질문·도발·동선 압축 |

### 차이가 의미하는 것 네 가지

1. **가장 센 재료(가격·오픈일)를 우리는 못 쓰고 있다.** 저쪽은 11건 중 5건이 가격, 7건이 오픈 시점이다.
   우리 지침서는 「확인 못 한 스펙은 그 문구를 버린다」라 요금을 매번 막아 왔고(19·20회차 모두 금지),
   결과적으로 역 도보 분·인원수만 남았다. 재료가 약한 게 아니라 **조달을 안 한 것**이다.
2. **이름을 빼는 쪽이 후킹에 유리할 수 있다.** 「힐튼 씨호크」·「미마루」는 모르는 사람에겐 정보가 아니다.
   저쪽은 상호를 본문 1장으로 미루고 표지엔 「대욕장 있는 신상 호텔」처럼 **조건만** 남긴다(최고 반응 6,433♥ 가 이 꼴).
   단, 우리 직관성 조건 1번과 정면으로 부딪친다 — 바꾸려면 규칙을 고쳐야 한다.
3. **3줄은 저쪽에 아예 없다.** 우리 3줄 훅(「짐 들고 헤맬래? / 신오사카에서 / 3분 숙소 찾아봐」)은
   같은 정보를 세 토막으로 쪼개 한 줄의 밀도가 낮다. 저쪽은 두 줄에 **시점+가격+시설**을 욱여넣는다.
4. **세부 지명이 광역보다 약하다.** 「신오사카」·「아사쿠사」는 가본 사람만 안다.
   저쪽은 11건 전부 「후쿠오카」로 통일하고, 세부 위치는 본문에서 푼다.

### 그대로 베끼면 안 되는 것

- 11건이 **한 계정·한 지역(후쿠오카) 전문**이다. 지역을 하나로 고정한 건 계정 성격이지 훅 기법이 아닐 수 있다.
  우리 축은 일본 전역이라 「후쿠오카」 자리에 늘 광역을 넣으면 「오사카 호텔 8곳」처럼 밋밋해질 위험이 있다.
- 댓글 300개대 2건은 본문에 「댓글 달면 예약 링크 DM」을 건 게시물이다. 훅 성과로 읽으면 안 된다.
- 저쪽 줄 길이는 15자를 넘는 게 4건이다. 우리 표지 낱장이 그 길이를 감당하는지는 확인하지 않았다.

## 4. 지침서에 올릴지 사람이 정할 후보

**2026-10-07 — 1·2번은 사람 승인으로 지침서에 반영했다**(3-1 형식 2줄 7 · 3줄 3, 2단계 「요금은 반드시 조회한다」). 3·4번은 아직 미반영.

1. **가격대를 훅 스펙에 정식으로 넣기** — 2단계에서 2인 1실 최저가를 반드시 조회해 「2인 8만원대」·「1박 4만원대」로 범위 표기.
   (지침서에 조회 방법은 이미 있다. 「조회를 거르지 않는다」를 의무로 올리는 변경이다.)
2. **2줄 비중 올리기** — 10개 중 2줄 7 · 3줄 3 처럼.
3. **호텔 이름 대신 조건만 쓰는 꼴을 허용** — 직관성 조건 1번의 예외 칸을 만든다.
4. **계절·시리즈·정보 우위 후킹을 소재 목록에 추가** — 「날도 추워지니까」·「저장 많아서 2탄」·「아직 잘 모르는」.
