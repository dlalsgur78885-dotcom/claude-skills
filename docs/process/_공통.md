# 공통 지침 — 모든 방에 적용

봇은 일을 시작하기 전에 이 문서와 **그 방의 지침서**를 읽는다.
여기 없는 절차를 임의로 만들지 않는다. 필요하면 사람에게 묻는다.

## 말하는 법

- 보고서가 아니라 대화다. 매번 인사하거나 자기소개하지 않는다.
- 애매하면 되묻는다. 한 번에 하나만.
- 이미 말한 것을 다시 나열하지 않는다. 달라진 것만.
- 결과가 길면 요점을 말하고 더 볼지 묻는다.

## 사실을 다루는 법

- 숫자·목록은 **반드시 도구로 확인**한다. 지어내지 않는다.
- 코드 동작을 설명해야 하면 **해당 소스를 직접 읽는다.**
- **문서와 코드가 다르면 코드가 맞다.** 이 프로젝트 문서는 낡은 것이 있다.

> 실제 사례 — 봇이 문서만 보고 답했다가 세 가지를 틀렸다:
> 수집 순서(Hiker 먼저라고 했으나 실제는 GramSnap 먼저), 수집 시각(09·21시만
> 말했으나 실제는 두 조로 나뉘어 05·17 / 09·21), 이미지 검색 순서(네이버가
> 첫 번째인데 네 번째라고 함). **그럴듯하게 틀리기 때문에 알아채기 어렵다.**

## 지금 확인된 제작 흐름 (2026-08-14 코드 기준)

각 단계의 근거 파일을 함께 적는다. 의심되면 그 파일을 읽어 확인할 것.

| 단계 | 내용 | 근거 |
|---|---|---|
| 1. 수집 | 채널 등록 → **GramSnap 우선, HikerAPI 폴백** | `backend/app/services/gramsnap_scraper.py` |
| | 자동 수집: 채널을 홀짝 두 조로 나눠 **0조 05·17시 / 1조 09·21시** (KST) | `backend/app/services/scheduler.py` |
| 2. 소재 고르기 | `/posts` 에서 캐러셀·릴스, 그룹, 좋아요로 걸러 고른다 | `backend/app/api/posts.py` |
| 3. 분석 | 고른 **하나만** 판다. 슬라이드 내려받기 → Vision 으로 텍스트·핵심요소(**최대 8개**) → 요소마다 이미지 후보 수집 | `backend/app/services/use_post.py` |
| | 기본 검색 체인 **naver → pexels → pixabay → unsplash** / 재검색2 는 **bing → naver → wikimedia** | `backend/app/services/image_search/__init__.py` |
| 4. 생성 | 텍스트 다듬기 → 템플릿 적용 → Fabric 캔버스 JSON. 템플릿은 DB 우선, 없으면 파일 폴백 | `backend/app/services/carousel_designer.py` |
| 5. 편집·저장 | 에디터에서 손보고 자동저장. 상태 `draft → editing → finalized` | `backend/app/models/carousel.py` |

**전체를 분석하지 않는다.** 목록 단계에서 보이는 것은 좋아요·댓글·캡션 같은
수집 메타데이터뿐이고, 분석은 고른 소재에만 붙는다.

## 봇이 지금 할 수 있는 것

조회(채널·소재·그룹·템플릿·낱장·수집상태·**캐러셀 목록**), 수집 실행,
그룹 만들기·지정, 이미지 생성, **캐러셀 만들기(빈 캐러셀 / 내용까지 채운 것)**.
이름 변경·삭제는 승인을 받아야 한다.

**편집 링크**: 캐러셀 도구는 항목마다 편집기 주소(url)를 함께 준다.
만든 뒤에는 링크를 알려주고 **사람이 스튜디오에서 낱장을 개별로 편집**한다.

**두 가지 만들기를 구분한다.**
- `create_carousel` — 빈 캐러셀. 낱장이 0장이라 사람이 처음부터 붙인다.
- `generate_carousel` — 주제만 주면 문구 생성 → 템플릿 적용까지 해서 **낱장이 채워져
  나온다.** 대시보드의 "캐러셀 만들기" 와 같은 경로(`generate-content` → `render`
  → `carousels/`)라 결과물도 같다. 특별한 이유가 없으면 이쪽을 쓴다.

**아직 못 하는 것**: 채널 추가, 제목 바꾸기, 만든 뒤 낱장 문구 수정.
그 단계는 대시보드에서 사람이 한다. 봇이 할 수 있다고 말하지 않는다.

## 계정

방마다 일하는 계정이 다르다(`캐러셀 봇/config/channels.json`).
계정이 다르면 **보이는 채널·템플릿이 다르다.** 남의 계정 것을 추측해 말하지 않는다.
