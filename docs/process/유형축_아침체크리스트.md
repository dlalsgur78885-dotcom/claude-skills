# 유형 축 — 아침 9시 체크리스트 (2026-10-22 신설)

트립앤라이프 지시 — 「1단계 미리 해서 평일 오전 9시에 바로 착착 진행할 수 있게」.
밤새 **1단계(수집·자동 분류)만** 돌아 있다. 아침에는 **후보 고르기부터** 시작한다.

## 밤에 저절로 도는 것

| 시각 | 무엇 | 도는 유형 |
|---|---|---|
| 23:00 (일~목) | 1단계 수집 + 유형 자동 분류 | 그날 묶음 3개 + 공통 2묶음 |
| 06:00 (월~금) | 같은 1단계, **다음 묶음 3개** | 밤과 겹치지 않는 유형 3개 |

- 한 회차 40분 안쪽. 둘 다 돌아 아침에는 **유형 6개치 후보**가 쌓여 있다.
- 어느 유형이 도는지는 날짜로 돈다 → [_유형공통.md](_유형공통.md) 「1단계 수집은 유형별로 나눠 찾는다」.

## 아침에 사람이 하는 것

1. **스튜디오 → 「유형 자동 분류 원클릭」** 을 연다. 밤에 열린 회차가 그대로 떠 있다.
2. 후보 줄의 **`[출처 · 번호. 유형 · 게이트 N/5]`** 를 보고 하나 고른다. 유형을 따로 고르지 않는다.
   - 출처는 커뮤니티면 이름까지 나온다 — `한국커뮤(디시)` · `일본커뮤(토게터)`.
   - 유형 번호는 **고정**이다(1 커뮤화제 · 2 치이카와 · 3 여행준비뉴스 · 4 한국인만읽는일본어 ·
     5 일본미녀 · 6 일본충격뉴스 · 7 몰랐던일본 · 8 일본인관점의한국 ·
     **9 새로생긴일본 · 10 사라지는일본**).
3. 고르면 2단계부터는 **그 유형 지침서**로 돈다 — 훅 → 사진 → 본문 → 캡션 → 캐러셀.
4. 캐러셀이 나오면 **결과의 `칸 넘친 줄`** 을 본다. 비어 있으면 검증 통과다.

## 걸리면 보는 곳

| 증상 | 먼저 볼 것 |
|---|---|
| 아침에 후보가 비어 있다 | `backend/uvicorn.log.err` 의 `[studio-worker] 23:00 — 「유형」 1단계 수집 시작` 줄 |
| 2단계에서 「유형이 안 붙은 후보입니다」 | 1단계 자동 분류가 실패한 회차다. 다시 돌린다 |
| 글자가 칸을 넘는다 | 표지 10자 · 자막 13자. 문구 단계가 넘는 안을 뒤로 보내지만 전부 넘으면 그대로 나온다 |
| 캡처 카드가 잘린다 | 반응 캡처는 `캡처카드` 낱장(칸)으로 들어가야 한다 — 배경으로 가면 4:5 에 잘린다 |
