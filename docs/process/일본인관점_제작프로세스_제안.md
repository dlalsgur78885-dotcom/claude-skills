# 「일본인 관점의 한국」 유형 — 속지 분석 + 제작 프로세스 제안 (2026-10-20)

트립앤라이프가 준 12건을 **낱장 단위로** 다시 봤다. 수치는 2026-10-20 조회 시점.
표지 비교는 [솔희_레퍼런스분석_2026-10-20.md](솔희_레퍼런스분석_2026-10-20.md) 에 있고,
이 문서는 **속지 구성과 제작 흐름**만 다룬다. 낱장 모음: `tmp/refs/strip_C1.jpg` · `strip_C2.jpg`.

## 1. 12건의 속지는 거의 한 가지 틀이다

**표지 1장 + 원문 증거 1~3장 (+ 반응 1장)**. 설명을 새로 그리는 장은 거의 없다.

|---|---|---|---|
| C04 | 2 | X 원문(글+사진) 1 | 137,536 |
| C05 | 3 | X 원문 캡처 2 | 12,578 |
| C08 | 3 | 영상 캡처 + 자막 2 | 10,436 |
| C10 | 3 | X 원문 캡처 2 (Grok 번역 화면) | 3,140 |

\* C02·C03 은 당일 게시라 수치가 안 익었다.

**장수가 성적을 가른다 — 이 유형 안에서는 신호가 뚜렷하다.**
총 2~3장 묶음 중앙 **6,788** / 4장 이상 묶음 중앙 **389** (성숙분 10건 기준).
A~G 전체로 보면 장수 효과가 약했는데, **이 유형만은 짧을수록 좋았다.**

### 눈에 띄는 것 넷

1. **원문 캡처를 그대로 쓴다.** 흰 바탕에 새로 그린 카드가 아니라 X·유튜브 화면 그대로다.
   「⟳ 원문 언어 일본어 · 원문 보기」, 「Grok 일본어 번역 / 이 번역 평가하기」 같은
   **번역 UI 가 캡처 안에 그대로 남아 있다**(C07·C10·C11·C12). 가공하지 않았다는 표시로 쓰인다.
   → 두 계정은 **X 에 로그인된 브라우저**로 찍는다는 뜻이다. 우리는 로그인이 없어 같은 모양의
   한국어 카드를 직접 만들고 있다([X인용_3-3단계](X인용_3-3단계_본문.md) 에 이미 적힌 제약).
2. **마지막 장이 CTA 가 아니다.** 12건 중 CTA 낱장을 둔 것이 하나도 없다.
   끝이 원문이거나(C07·C12), 한국인 칭찬 댓글이다(C03 「진짜 멋있으십니다!」).
3. **배경 한 장을 고정하고 인용 박스만 바꾸는 변형**(C02) — 사진이 한 장뿐일 때 쓰는 손이다.
4. **표지 사진은 원문에서 나온다.** 따로 찍거나 검색한 티가 나는 것은 C06(인물 사진) 정도다.

## 2. 소재가 성적을 가른 선

| 잘된 것 | 안된 것 |
|---|---|
| C04 BTS 일본 팬이 화재 막음 137,536 | C07 김치냉장고 놀랍다 194 |
| C05 '이바토해 2000' 오독 12,578 | C11 한국 와사비 극혐 308 |
| C08 일본인이 생각한 6.25 10,436 | C12 맘스터치 중독 389 |
| C10 물병·스테인리스 컵 3,140 | C02 한국이 살기 어렵다 81* |

- 잘된 쪽은 **한국인이 몰랐던 각도**다 — 일본인이 한글을 엉뚱하게 읽거나(C05),
  일본인이 한국 역사를 어떻게 아는지(C08), 우리에겐 안 보이던 풍경(C10).
- 안된 쪽은 **한국인이 이미 아는 사실**(김치냉장고·맘스터치가 맛있다)이거나 **감정이 상하는 쪽**이다.
- 단, C08(6.25)은 민감한데도 10,436 이 나왔다. **민감함 자체가 아니라 「한국을 깎는 말」이 안 된다.**

## 3. 제작 프로세스 제안 — 새로 만들 것이 거의 없다

**이 유형은 이미 X인용 축 안에 있다.** `X인용_1단계_주제후보.md` 의 소재 분류표에
「일본인 관점의 한국 음식·문화·역사·경제·사회(놀라움)」이 들어 있다. 문제는 **비중이다** —
그 갈래가 「그 밖 10%」 묶음에 다른 셋과 함께 묶여 있어 회차당 한두 건 나오거나 아예 안 나온다.

그래서 **새 축을 만들지 말고, 수집 묶음을 하나 더하는 쪽**을 권한다.
템플릿(42/86 트립앤라이프 X인용)·단계 흐름·편집·캡션은 **손대지 않는다.**

### 흐름 (바뀌는 칸만 굵게)

| 단계 | 지금 | 이 유형에서 |
|---|---|---|
| 1 수집 | grok 헬퍼로 5묶음 × 10건 | **「일본인 관점의 한국」 묶음 1개 추가** (최근 14일 · 조회 5만 · 10건) |
| 2 거르기 | 조회·댓글·중복·이력 | **+ 한국을 깎는 소재 제외 · 한국인이 이미 아는 사실 제외** |
| 3 고르기 | 사람이 1건 | 그대로 |
| 3-1 훅 | 2줄 | 그대로 (아래 §4) |
| 3-2 표지 | 원문 사진 우선 | 그대로 — 이 유형은 원문 사진이 거의 항상 있다 |
| 3-3 본문 | 원문 캡처 카드 + 답글 | **총 3장 안쪽으로 묶는다** (속지 1~2장) |
| 4 생성 | 스튜디오 | 그대로 |
| 5 캡션 | 캡션 공통 | 그대로 |

### 1단계에 넣을 검색 묶음 (초안)

- 일본어 키워드: `韓国 驚いた` · `韓国 すごい` · `韓国 美味しい` · `韓国 文化 違い` ·
  `韓国 旅行 びっくり` · `ハングル 読めない` · `韓国人 親切` · `韓国の日常`
- 문턱은 다른 묶음과 같게 — 최근 14일 · 조회 5만 · 10건. 명예의전당(14일~6개월·200만)도 같이 걸 수 있다.
- ⚠ `GROK_X_MAX_SEARCHES=20` 으로 부른다. 기본값 6이면 묶음당 1~4건밖에 안 온다(1단계 문서 실측).
- ⚠ 묶음이 여섯이 되면 1단계가 **40분 → 48분쯤**으로 길어진다. 20:30 회차는 22:00 지도 축과
  간격이 좁아진다. 묶음을 더하는 대신 「그 밖 10%」 묶음을 이걸로 **바꾸는 선택지**도 있다.

### 거르기에 더할 기준 (이번 분석에서 나온 것)

1. **한국을 깎는 소재는 뺀다** — 살기 어렵다·바가지·극혐 류. 레퍼런스에서 전부 바닥이었다.
2. **한국인이 이미 아는 사실은 뺀다** — 「한국 치킨이 맛있다」, 「김치냉장고가 있다」.
   새로운 각도가 없으면 넘길 이유가 없다.
3. **민감한 소재(역사·정치)는 빼지 않는다.** C08 이 10,436 이었다. 다만 **한국을 깎지 않는 선**에서만.

## 4. 이 유형 전용 문구 규칙 (레퍼런스에서 뽑음)

- **훅** — 2줄, 줄당 9~13자. 「일본인이 ~한다는」 전언체 + **구체 대상**.
  된 것: 「일본인이 한국와 꼭 찍는다는 / '이바토해 2000'」, 「일본인이 생각한 / 6.25 전쟁」.
  안 된 것: 「일본인들이 / 한국인에게 놀라는 이유」 — 무엇에 놀랐는지가 없다.
- **본문 문구** — 캡처가 말을 하므로 설명은 짧게. 1줄로 툭 던지고 2줄에서 받는다
  (X인용 3-3단계에 이미 있는 규칙 그대로).
- **캡션** — 트립초초형이 이 유형에 맞다. 한두 문장마다 줄바꿈, 「~인데요」, **마지막은 질문**,
  해시태그 5~6개. 니혼테레비형 기사체(`[제목]` + 사실 나열)는 이 유형에서 C04 한 건만 터졌다.

## 5. 사람이 정할 것

1. **묶음을 더할지, 「그 밖 10%」 묶음을 이걸로 바꿀지.** (더하면 1단계가 8분쯤 길어진다)
2. **CTA 낱장을 쓸지.** 레퍼런스 12건은 전부 CTA 가 없다. 우리 X인용 축은 CTA 낱장을 둔다.
3. 위 거르기 기준 세 가지를 1단계 문서에 넣을지 — **지침서 수정은 승인 후에 한다.**
