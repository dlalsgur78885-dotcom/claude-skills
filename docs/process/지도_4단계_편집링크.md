# 지도 — 4단계 캐러셀 스튜디오 생성, 편집 링크 전달

작성: solhee 방 / 2026-08-25 회차 진행
최종 수정: 2026-08-28 (**메시지 첫 문구 `[4단계]` · 마지막 문구 `[5단계] 만들까요?`** · 지도 캐처는 카드 없는 컷으로)

## 이 단계에서 하는 일

3단계 결과(훅 문구·썸네일 사진·본문 3개·CTA1 문구)를 스튜디오에 올리고 **편집 링크**를 준다.
**링크에서 사람이 낱장별로 문구·사진을 개별로 고친다.**

**시작 신호는 3-4 의 CTA1 문구 확정이다.** 확정되면 확인 없이 바로 이 단계로 들어온다.
"이제 만들까요?", "템플릿은 트래블뷰(지도)로 할까요?" 처럼 **이미 정해진 것을 다시 묻지 않는다.**

## 문구는 3단계 산출물에서 **글자 그대로** 옮긴다

**4단계에서 문구를 새로 쓰거나 다듬지 않는다.** 복사해 붙이는 것이 전부다.

| 가져오는 곳 | `slides` 키 | 슬롯 역할 |
|---|---|---|
| 3-1 확정 훅 문구 (줄바꿈 `\n` 그대로) | `headline` | HEADLINE |
| 3-1 고정 서브헤드라인 `장소 50개 · 댓글 달고 공유 받아가세요` | `subtext` | SUBHEADLINE |
| 3-3 매장명 | `headline` | HEADLINE |
| 3-3 📍위치 | `subtext` | SUBHEADLINE |
| 3-3 특징 설명 **4줄** | `body` | BODY |
| 3-4 강조 문구 **2줄** (줄바꿈 `\n` 그대로) | `headline` | HEADLINE |
| 3-4 공감·수량 문구 **1줄** | `subtext` | SUBHEADLINE |
| 3-4 팔로우 유도 문구 **2줄** (줄바꿈 `\n` 그대로) | `body` | BODY |

> **표지 서브헤드라인은 2026-08-27 에 바뀌었다.** 옆 문구 `트래블뷰 · 공유 목록 · 장소 50개` 를
> 지난 회차 문서나 캐러셀(429·431·432)에서 보고 베끼지 않는다. → [3-1 문서](지도_3-1단계_훅문구.md)

- **키 이름 주의**: SUBHEADLINE 슬롯이 읽는 값은 `subheadline` 이 아니라 **`subtext`** 다
  (`backend/app/services/carousel_renderer.py:106-125`).
- **칸을 한 칸에 뭉치지 않는다.** 매장명·위치·특징을 `body` 하나에 밀어 넣지 않는다.
  **CTA1 도 세 칸이다** — 강조·공감수량·팔로우유도를 `body` 하나로 합치지 않는다 (2026-08-26 변경).
- **CTA1 의 `body` 첫 줄은 고정 문구**다 — `@travel.view_official 팔로우하고 댓글 남겨주시면`.
  계정명을 바꾸거나 줄이지 않는다. 둘째 줄만 3-4 에서 채워 온 값을 그대로 옮긴다
  (→ [3-4 문서](지도_3-4단계_CTA1문구.md)). **개수를 비운 회차면 비운 채로 넘긴다.**
- **줄임·의역·어미 손질 금지.** 줄바꿈도 그대로 넣는다.
- 위치 칸의 **일본어 주소도 한 글자도 고치지 않는다** (2026-08-25 추가). 단 3-3 에서 우편번호·건물 이름·층·호수를 뺀 것이 기준이다(2026-09-22).

### 한국어 문구도 **한 글자씩 확인하고 넘긴다** (2026-08-26 추가)

**2026-08-26 실제 사고** — 표지와 CTA1 의 `교토의 진짜 부엉` 이 **`부업`** 으로 나갔다(캐러셀 430).
**받침 하나 차이는 에러가 아니라 그대로 렌더된다.**

- 넘기기 전에 3단계 문서의 문자열과 **눈으로 대조**한다. 특히 **여러 장에 반복되는 문구**는
  한 곳이 틀리면 다른 곳도 틀려 있다.
- 이미 만든 뒤에 발견하면 **같은 내용으로 다시 만들고**(새 id), 사람에게 어느 것을 쓰는지 알린다.
  버린 id 는 이력 파일에 한 줄로 남긴다.

## 낱장 배치

| 순번 | 재료 | 낱장 | 이미지 |
|---|---|---|---|
| 0 | 3-1 확정 훅 문구 | `표지_지도` | 3-2 확정 사진 — **배경**(`user_image_urls`) |
| 1 ~ 3 | 3-3 확정 본문 3개 | `본문_지도` | 3-3 장소별 사진 — **배경**(`user_image_urls`) |
| 4 | 3-4 확정 CTA1 문구 (3칸) | `CTA1` | 3-2 확정 사진 — **칸 1**(`items` + `user_item_image_urls`) |
| 5 | 문구 없음 | `CTA2` | 3-2 확정 사진 (표지와 **같은 1장**) — **배경**(`user_image_urls`) |

캐러셀 총 장수 = **6장**

- `CTA2` 는 문구가 없어도 **슬라이드 자리를 채운다**(`headline: ""`). 그래야 순번이 안 밀린다.
- **표지·`CTA1`·`CTA2` 에 넣는 지도 캐처는 카드가 안 보이는 컷이어야 한다** (2026-08-28 사람 지시).
  확정 컷에 카드가 남아 있으면 **같은 앵커로 더 확대해 다시 찍어** 넣는다. 범위가 좁아지는 건 괜찮다 —
  구도는 사람이 편집기에서 조절한다. → [3-2 문서](지도_3-2단계_썸네일이미지.md)

## 네 인자는 **반드시 함께 넘긴다**

| 인자 | 안 넘기면 |
|---|---|
| `slides` | 서버가 문구를 **새로 지어낸다.** 3단계 확정본이 사라진다 |
| `layout_overrides` | **전부 표지로 렌더된다** |
| `user_image_urls` | 표지·본문·CTA2 **배경이 빈 채로** 나온다 |
| `user_item_image_urls` | `CTA1` 위의 지도가 **안 들어간다** |

```
generate_carousel(
  topic: "…",
  template_id: 81,
  slides: [
    { headline: "<3-1 확정 훅 1줄>\n<2줄>", subtext: "장소 50개 · 댓글 달고 공유 받아가세요", type: "cover" },
    { headline: "<매장명1>", subtext: "📍<주섘1>", body: "<특징 4줄>" },
    { headline: "<매장명2>", subtext: "📍<주섘2>", body: "<특징 4줄>" },
    { headline: "<매장명3>", subtext: "📍<주섘3>", body: "<특징 4줄>" },
    { headline: "<CTA1 강조 1줄>\n<2줄>",
      subtext:  "<공감·수량 1줄>",
      body:     "@travel.view_official 팔로우하고 댓글 남겨주시면\n<지역> <소재> <개수>곳 구글 지도 공유해드립니다",
      items: [{}, {}] },
    { headline: "", type: "cta" }
  ],
  layout_overrides: {
    "0":"표지_지도", "1":"본문_지도", "2":"본문_지도", "3":"본문_지도",
    "4":"CTA1", "5":"CTA2"
  },
  user_image_urls: {
    "0":"https://…3-2 확정 사진",
    "1":"https://…매장1 사진", "2":"https://…매장2 사진", "3":"https://…매장3 사진",
    "5":"https://…3-2 확정 사진"
  },
  user_item_image_urls: {
    "4": { "1": "https://…3-2 확정 사진" }
  }
)
```

- 키는 **슬라이드 순번(0부터)**, 값은 **낱장 이름**. 여섯 순번을 빠짐없이 적는다.
- 낱장 이름은 `list_layouts` 결과를 **글자 그대로** 복사한다. **오타는 조용한 폴백**이다.
- **`capture_page` 로 찍은 지도 캐처도 그대로 넣는다.** 표지(0)·`CTA2`(5)에 **같은 값**으로.
- 본문 배경은 **외부 사이트 URL 을 그대로 넣어도 된다** (2026-08-25·08-26·08-27 확인).
  URL 안에 일본어나 `%2C` 같은 인코딩이 있어도 그대로 통과했다.

### `CTA1`(순번 4)만 길이 다르다 — 배경이 아니라 **칸 1**

- **`CTA1` 순번에 `user_image_urls` 를 넣지 않는다.** 넣으면 배경으로 꽉 차게 깔린다.
- 대신 **칸**으로 넣는다 — `slides[4].items: [{}, {}]` + `user_item_image_urls: {"4": {"1": "https://…"}}`.
- **칸 0 이 아니라 칸 1 이다.** 칸 0 에 넣으면 앞 상자로 들어가 화면을 덮는다.
- **`items` 를 빼먹으면 `user_item_image_urls` 는 조용히 무시된다.**
- 자리가 틀리면 캐러셀이 아니라 **템플릿의 `CTA1` 낱장**을 고친다.

**왜 안 주면 표지만 나오나** — 렌더러는 낱장을 `photo_with_caption` 같은 **영문 키**로 고른다
(`carousel_renderer.py:32`). 트래블뷰(지도) 낱장은 한글이라 하나도 안 걸리고 첫 낱장으로 떨어진다.

**왜 어떤 칸은 안 보이나** — 텍스트는 **낱장에 그 역할 슬롯이 있을 때만** 그려진다.
**CTA1 은 세 칸(HEADLINE·SUBHEADLINE·BODY)이 다 보이는지 특히 확인한다.**

## 전달

메시지는 **첫 문구 `[4단계 — 캐러셀 스튜디오 생성]` 으로 열고,
마지막 문구 `[5단계 — 캐프션 문구] 만들까요?` 로 닫는다**
(2026-08-28 사람 지시 — 방 지침의 첫 줄·끝 줄 규칙. 두 축 공통이다).
그 사이에 아래를 적는다.

1. **편집 링크**
2. **CTA1 위의 1:1 지도는 봇이 칸 1 로 넣어 두었다**는 안내
3. 배경 **위치·크기는 편집기에서 조정**하면 된다는 안내
4. **3단계 산출물과 스튜디오 낱장이 같은지 한 장만 확인해 달라**는 부탁
5. **위치 칸의 긴 일본어 주소는 한 줄에 안 들어갈 수 있다**는 안내

- 링크만 던지고 끓지 않는다. 마지막 문구가 곹 5단계 질문이다.
- 묻기 전에 캐프션을 미리 써 두지 않는다. 사람이 만들자고 하면 그때 5단계로 간다.

만든 뒤의 낱장 문구 수정은 봇이 못 한다. 그건 사람이 편집기에서 한다.
