## ⚠ 4코스 낱장과 다른 세 가지

| 다른 점 | 내용 |
|---|---|
| **`tag` 가 5칸이다** | 맨 위 일자 안내 띠는 없다. 대신 아래 띠 **핀 사이 y1295 에 `tag`~`tag5`**(폭 181 · 24px) — 구간 이동시간을 넣는다(2026-10-22 사람 지시) |
| 사진 칸 | **400×180** (4코스는 400×220) · cover-crop · 가로 16:9 로 넘긴다 |
| **아래 흰 띠에 이름이 한 번 더** | y1232 에 `subheadline`~`subheadline6` 칸이 한 벌 더 있다(폭 220~231 · 28px · 아이콘 6개 위) |

- 렌더러는 역할이 같은 칸을 **전부** 찍는다(`carousel_renderer.py` 4번 루프) → **장소 이름 6개가 아래 띠에도 그대로 나간다.**
  이름은 **📍 없이 장소 이름만** 넘기고(2026-10-22 사람 지시), 띠 폭 **220px**(한글 8자 안팎)을 넘으면 두 줄로 밀려 아이콘(y1288)과 겹친다 → 3-3 에서 짧게 짓는다.
- 사진을 6장 다 안 넘기면 빈 칸이 **회색 사각형**으로 찍힌다(`_make_rect` 폴백).

## ⚠ 사진 `items` 순서가 자리 순서와 다르다

템플릿 91 `본문(여행코스)2` 의 빈 사진 칸 배열은 **(580,867) → (100,867) → (580,190) → (100,190) → (580,518) → (100,518)** 이다(2026-10-22 조회).

| `items` 자리 | 들어가는 칸 | 그 칸의 코스 |
|---|---|---|
| `items[0]` | (580, 867) 오른쪽 아래 | **코스 6** |
| `items[1]` | (100, 867) 왼쪽 아래 | **코스 5** |
| `items[2]` | (580, 190) 오른쪽 위 | **코스 2** |
| `items[3]` | (100, 190) 왼쪽 위 | **코스 1** |
| `items[4]` | (580, 518) 오른쪽 가운데 | **코스 4** |
| `items[5]` | (100, 518) 왼쪽 가운데 | **코스 3** |

- 그러니 `items: [코스6, 코스5, 코스2, 코스1, 코스4, 코스3]` 으로 넘긴다. 코스 순서대로 넣으면 **사진이 엉뚱한 설명 옆에 붙는다.**
- **이 순서는 템플릿에 저장된 배열이라 사람이 칸을 다시 그리면 바뀐다.** 회차마다 조회해 x·y 순서로 이 표를 맞춘다.

## 본문·CTA 배경 · CTA 글 · 검정 막 — 4코스판과 같다

[여행코스_4단계_편집링크.md](여행코스_4단계_편집링크.md) 의 세 절을 그대로 쓴다. **여기에 베껴 적지 않는다.**

- 「CTA 글 — 「<주제> 코스 필요하시면」」 — 한 줄 · 공백 빼고 15자 안쪽 · 마침표·이모지 없음
- 「본문·CTA 배경에도 표지 사진을 깐다」 — 본문 배경은 흰색 + 검정 70% 라 **사진을 안 넘기면 흰 장식이 사라진다**. 표지와 같은 한 장을 네 자리에 모두
- 「검정 막 · 그림자」 — 표지·CTA 는 지울 막 없음, 본문의 검정 70% 는 그대로 둔다

  본문 한 장에 **글칸 12개**(이름 6 + 설명 6)다 — 날마다 12칸이 3-3 확정 문구와 같은지 본다. 설명에 **줄바꿈이 들어간 칸**이 있으면 3-3 으로 돌려보낸다(이 갈래는 설명 한 줄).
- 사진 짝을 **렌더 좌표로 검산**한다(날마다 6/6). 위 순서 표를 틀리면 여기서 드러난다.
- **아래 띠 이름이 두 줄로 밀렸는지** 본다 — 폭 220·231 을 넘긴 이름이 있으면 3-3 으로 돌아가 줄인다.
- **이동시간 칸을 센다** — 날마다 5칸(1박 2일이면 10칸)이 3-3 에서 잰 값과 글자로 같은지 본다.

- CTA 글이 **한 줄인지**, 「댓글 남겨주세요!」와 겹치지 않는지 본다.
