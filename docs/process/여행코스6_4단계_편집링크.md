## ⚠ 사진 `items` 순서가 자리 순서와 다르다

템플릿 91 `본문7` 의 빈 사진 칸 배열은 **(580,997) → (100,997) → (580,300) → (100,300) → (580,649) → (100,649)** 이다(2026-10-26 조회).

| `items` 자리 | 들어가는 칸 | 그 칸의 코스 |
|---|---|---|
| `items[0]` | (580, 997) 오른쪽 아래 | **코스 6** |
| `items[1]` | (100, 997) 왼쪽 아래 | **코스 5** |
| `items[2]` | (580, 300) 오른쪽 위 | **코스 2** |
| `items[3]` | (100, 300) 왼쪽 위 | **코스 1** |
| `items[4]` | (580, 649) 오른쪽 가운데 | **코스 4** |
| `items[5]` | (100, 649) 왼쪽 가운데 | **코스 3** |

- 그러니 `items: [코스6, 코스5, 코스2, 코스1, 코스4, 코스3]` 으로 넘긴다. 코스 순서대로 넣으면 **사진이 엉뚱한 설명 옆에 붙는다.**
- **이 순서는 템플릿에 저장된 배열이라 사람이 칸을 다시 그리면 바뀐다.** 회차마다 조회해 x·y 순서로 이 표를 맞춘다.

- CTA 글이 **한 줄인지**, 「댓글 남겨주세요!」와 겹치지 않는지 본다.
