# X인용 — 3-1단계 썸네일 훅 문구

작성: solhee 방 / 2026-09-15 축 신설
낱장: 템플릿 42 `썸네일` 의 `headline` (→ [4단계 문서](X인용_4단계_편집링크.md))

## 이 단계에서 하는 일

고른 게시물로 **썸네일 훅 문구 후보 10개**를 짓는다(codex sol — 방 지침서 「문구 후보는 codex sol 로 짓는다」).

## 형식

- **2줄 · 줄마다 공백 포함 12자 이내 · 10개.** 3줄 후보는 없다.
  (2026-09-15 사람 지시 — 처음 안은 15자였으나 `썸네일` 칸이 폭 911px · 글자 100px 라 「공백 포함 12글자」로 줄였다.)
- 지은 뒤 줄마다 글자 수를 센다. 넘는 줄이 있으면 다시 짓는다.
- **일본어(가나·한자)를 쓰지 않는다.** 가게·브랜드·지명은 한국어 발음으로(焼肉きんぐ → 야키니쿠킹), 뜻이 자연스러운 말은 뜻으로.
  (2026-10-07 트립앤라이프 피드백 — 「焼肉きんぐ 앱 / 1078만 건 유출」 이 표지에 그대로 나왔다. 이제 코드가 주제 제목·훅·본문에서
  일본어가 섞인 문구만 골라 한국어 표기로 바꾼다 — `studio_steps._koreanize`.)
- 12자 줄은 칸에 빠듯할 수 있다(추정). 첫 회차 편집기에서 넘치는지 보고 [4단계 문서](X인용_4단계_편집링크.md) 에 적는다.

## 문구 결

- 공감이 될 만한 문구 · 클릭을 유발하는 문구 · 직관적이고 호기심을 유발하는 문구.
- **주제에 맞는 가장 강력한 후킹 방식을 매번 새로 고안한다** — 도발 · 유머 · 상식 파괴 · 감성 자극 · 극단적 수치 · 의문 등 자유.
- **「감정 + 대상」 틀**을 후보에 넣는다 (2026-09-16 레퍼런스 4건 중 3건이 이 결이었다 — 트립초초 @trip__chocho).
  1줄에 계기(브랜드·행동·상황), 2줄에 **누가 어떤 감정인지**를 놓는 식이다.
  실제 레퍼런스 — `BHC` / `먹고 화가난 일본인` · `매너 없는 한국인에` / `화가난 일본인` · `한국인이 이해안가는` / `일본인` · `일본 여행 조심하세요` / `정말 죽습니다`
  ⚠ **10개를 이 틀로 채우지 않는다.** 회차마다 같은 틀이 또 나오면 바꾼다는 규칙이 우선이다 — 한 회차에 두세 개까지.
  10개가 한 방식으로 몰리지 않게 섞는다. 앞 회차 훅([X인용_이력.md](X인용_이력.md))과 같은 틀이 또 나오면 바꾼다.
- codex 는 이 문서를 읽지 않는다 — 위 형식·결·아래 예시·「숫자와 사실」을 **prompt 에 그대로** 담는다.

- 일본 / 번역 근황ㅋㅋㅋ
- 한국망신 일본 가게 / 심각한 리뷰..

(예시는 결을 보라는 것이다. 그대로 베끼지 않는다.)

## 숫자와 사실

- 말투 과장은 되지만 **원문에 없는 사건·결과를 지어내지 않는다.** 「최후」·「죽습니다」 같은 말은 원문이 그런 내용일 때만.
- 숫자(조회수·금액·인원)는 원문·1단계에서 확인한 값만 쓴다.
- **등장인물의 국적·신분도 사실이다.** 원문 당사자가 일본인이면 훅에서 「한국인」으로 바꾸지 않는다.
  「감정 + 대상」 틀의 대상도 원문 속 사람이다. 한국인의 시선으로 말하는 것과 주인공을 한국인으로 바꾸는 것은 다르다.
  (2026-10-05 — 일본인이 551 대신 蓬莱 만두를 먹었다는 글에 `551 간판 보고` / `착각한 한국인` 이 나왔다.
  훅에 주제 한 줄만 넘겨 모델이 당사자를 짐작한 탓이라, 이제 원문·작성자를 함께 넘긴다.)
