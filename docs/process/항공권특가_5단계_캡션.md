# 항공권특가 — 5단계 캡션

공통 규칙(템플릿·낱장)은 [솔희_캐러셀기획.md 「항공권특가 축」](솔희_캐러셀기획.md) 에 있다.

## 기본 원칙

- 간결하고 힘 있는 문어체, 줄바꿈·이모지 활용.
- **대화형 오프닝(「아니...」「여러분」「안녕하세요」) 금지**, 억지 좋아요·구독 강요 금지, 맥락 없이 국가·지역명 특정 금지.

## 구조 — 4블록, 순서를 지킨다

① 오프닝 훅 — 1행 혜택·문제 제기(이모지) / 2행 넘기면 손해라는 경고 / 3행 `👉 댓글에 “핵심키워드” 남기시면...`
② `—` 구분선 + 핵심 요약 ✔ 3개
③ `—` 구분선 + 세부 정보 불릿(주의사항 — 예: 특가 가격은 실시간으로 바뀐다, 좌석 소진 시 종료)
④ 해시태그 — **메인 키워드만 2~3개 · 채널 이름(#트립앤라이프)은 넣지 않는다** (2026-09-16 사람 지시 — 「해시태그 문구 필요없는 건 지우고, 메인 키워드만 2~3개」·「해시태그에 채널 이름 빼줘」). 주제를 바로 가리키는 말만 남기고, 있으나 마나 한 태그는 뺀다. 공백 없이

- ⚠ **노선 리스트 블록과 마무리(타이밍 강조·알람 설정·저장 유도) 블록은 넣지 않는다** (사람 지시 — 「이 부분을 아예 없애도록」).
  처음 받은 안은 6블록이었다. OTA할인 축 캡션과 **다르다**(그쪽은 클로징이 있다).

## 넣지 않는 것 (사람 지시 — 「출발일, 수집시각, 각 항공권 왕복 금액 부분은 안 나오도록」)

- **출발일**(날짜 범위 포함) · **수집 시각** · **항공권별 왕복 금액**
- 금액·날짜는 본문 장에 이미 있다. 캡션은 「일본 N개 노선」「최대 N% 하락」 같은 묶음 정보로 채운다.
- 숫자는 **받은 값으로 계산한 것만**. 할인율 규칙은 2단계와 같다.
