작성: solhee 방 / 2026-09-14 축 신설
낱장: `표지_2줄` 배경 · 빈 이미지 칸(**800×500** · 트래블뷰 84) / `CTA(OTA할인)` 배경

## 이 단계에서 하는 일

1. 훅과 어울리는 **배경 이미지 5장을 생성**해 **갤러리 링크 하나**로 전달한다.
2. 표지의 빈 이미지 칸에 넣을 **이벤트 배너 원본 이미지**를 확보한다.

## 배경 이미지

- 소재 예: 비행기, 하늘, 주제와 관련된 여행지 풍경.
- 방 지침서의 **이미지 품질** · **중앙 1:1 구도** 규칙을 프롬프트에 넣는다.
- **jpg·png 파일은 보내지 않는다 — 링크만.**
- 사람이 고른 1장은 **`썸네일` 과 `CTA(OTA할인)` 배경에 같이** 쓴다. 같은 장면을 다시 생성하지 않는다.

## 표지 빈 칸 — 이벤트 배너 원본

- 표지의 **빈 이미지 칸(800×500 · 트래블뷰 84 · x139 y333)** 에는 **그 이벤트의 배너 원본 이미지**를 넣는다(사람 지시). (87 로 만들 때만 709×565)
- 칸 사진은 `items` 로 넣는다. 표지 이미지 장식 순서가 **로고 → 빈 칸**이면 항공권특가 축처럼
  `{"0":{"0":로고,"1":배너}}` 로 두 개를 준다(0번을 비우면 로고 위에 회색 사각형이 덮인다). **넣기 전에 순서를 확인한다.**
- 배너를 못 받으면(페이지 삭제·봇 차단) **지어내거나 비슷한 그림을 생성하지 말고** 사람에게 알린다.
  2026-09-14 에어프레미아 이벤트 페이지는 「찾을 수 없음」, 홈은 봇 확인 화면이었다.
- ⚠ 배너는 남의 브랜드 이미지다. 캐러셀에 쓰는 것은 사람이 정한 것이며, 문제가 되면 사람이 판단한다.
