# 일본맛집 — 제작 이력

작성: solhee 방 / 최초 생성 2026-09-01

1단계에서 주제 후보를 뽑기 **전에 이 파일을 먼저 읽고**, 여기 있는 주제는 후보에서 버린다.
[상황별일본어_이력.md](상황별일본어_이력.md) 와 같은 방식이다.

## 규칙

- **제작한 주제만** 한 줄씩 누적한다. 안 고른 후보는 적지 않는다.
- 캐러셀을 만들 때마다(4단계 완료 시점) 한 줄을 추가한다.
- **100건을 넘으면 오래된 줄부터 지워 100건을 유지한다** (2026-11-05 솔희 지시 — 「최근 100건 남기는 걸로 하고 지워줘」).
  번호는 이어서 센다. **주제 중복 판정에 쓰이는 범위는 그중 최근 30건**이다(코드 `history[-30:]`).
