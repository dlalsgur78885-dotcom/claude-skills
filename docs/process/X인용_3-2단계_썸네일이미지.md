# X인용 — 3-2단계 썸네일 이미지

작성: solhee 방 / 2026-09-15 축 신설
낱장: 템플릿 42 `썸네일` 배경 하나뿐이다. `CTA(X인용)` 은 템플릿 이미지가 통째로 덮어 사진을 넣지 않는다.

## 이 단계에서 하는 일

표지에 쓸 사진 1장을 정한다.

## 올라온 사진이 있으면 그걸 쓴다 (2026-09-16 사람 지시)

사람 지시 — 「표지 배경은 업로드된 사진이 있다면 그걸로 사용하고, 사진이 없는 경우에만 생성」.

⚠ **원본 X 게시물에 붙은 사진도 「올라온 사진」이다 (2026-09-16 2차 사람 지시 — 「이미지가 있는데 왜 썸네일, CTA 이미지가 또 생성된거야?」).**
- 게시물에 사진이 있으면 **그 사진으로 표지·CTA 배경을 만든다. 생성하지 않는다.**
- 그 사진은 3-3 본문 칸에도 들어가므로 **같은 사진이 표지와 본문에 겹쳐도 된다.**
- 원본 사진은 1:1 흰 여백판이 아니라 **사진 부분만 잘라 4:5(1080×1350)로** 만들어 배경에 쓴다. 여백판을 그대로 깔면 위아래에 흰 띠가 남는다.
- 사진이 여러 장이면 **표지에 쓸 한 장을 묻는다.**

- **회차를 시작할 때 사람이 올린 사진이 있는지 먼저 본다.** 있으면 **생성하지 않는다** — 그 사진을 표지 배경으로 쓰고 바로 3-3 으로 넘어간다.
- 올라온 사진이 여러 장이면 어느 것을 쓸지 묻는다.
- 올라온 사진이 없을 때만 아래대로 **생성**해 갤러리 링크 하나로 전달하고, 사람이 1장을 고른다.

## 만드는 것 (사람이 준 안 그대로)

| 묶음 | 장수 | 내용 |
|---|---|---|
| 인물 | 5장 | 주제와 관련된 인물 포함 이미지 |
| 풍경 | 5장 | 주제와 관련된 풍경 이미지 |

- **지도 이미지는 만들지 않는다** (2026-09-15 사람 확인). 처음 안에 있던 「관광지 5곳을 지도에 표시한 이미지」는 X 주제에 관광지가 없는 경우가 많아 뺐다.
- `generate_image` 로 **한 번에** 만든다(`prompts` 에 몰아서) → `make_gallery` 로 묶어 **링크 하나**만 준다.
- **jpg·png 파일은 보내지 않는다 — 링크만.** 파일이 있다는 안내도 하지 않는다.

## 비율과 구도

- **모든 이미지는 4:5**(표지 1080×1350). 메인이 되는 영역(인물 얼굴 · 중심 건물 · 음식)은 **중앙 1:1 안**에 들어오게.
- 생성 크기가 1024×1536(2:3)이면 4:5 로 넣을 때 **위아래가 잘린다.** 방 지침서 「구도 — 주요 피사체는 정중앙 1:1 안에」 문장을 프롬프트에 그대로 넣고,
  만든 뒤 가운데 정사각(세로 256~1280) 경계를 그어 보고 벗어난 장만 다시 그린다.
- 방 지침서 **이미지 품질(인물·풍경)** 문장도 그대로 넣는다. 인물 지정이 없으면 20대 한국인 여자.
- 배경 이미지에 **글자를 넣지 않는다**(훅은 텍스트 슬롯이 채운다). 지도의 지명 글자는 정확히 쓰거나 비운다.
- 만든 뒤 `local_path` 를 Read 로 열어 기준에 맞는지 보고, 안 맞는 장만 다시 그린다.

## 고른 1장

- 정한 **1장**은 `썸네일` 과 `CTA(X인용)` **두 낱장 배경에만** 쓴다 (2026-09-16 사람 지시 — 「본문에는 배경으로 넣는 거 제외, 썸네일·CTA만 배경 동일하게」).
- **본문 낱장에는 배경 사진을 넣지 않는다.** 본문은 흰 배경에 캡처 카드와 검정 글자로 간다(같은 날 오전에 잠깐 있던 「본문에도 배경」 규칙은 폐기).
- 고를 때 **CTA 템플릿 이미지(불투명도 70%) 뒤에 비쳐도 지저분하지 않은지** 함께 본다.
- `썸네일` 은 **위쪽 가운데에 로고**(y56~434), **아래쪽에 흰 훅 문구**(y900~)가 올라간다 — 고를 때 얼굴·주요 피사체가 로고나 글자와 겹치지 않는지 본다.
