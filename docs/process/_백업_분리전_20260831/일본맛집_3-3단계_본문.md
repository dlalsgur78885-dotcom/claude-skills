# 일본맛집 — 3-3단계 본문 (매장 8곳)

작성: solhee 방 / 2026-08-31 축 신설

> **공통 규칙은 [지도_3-3단계_본문.md](지도_3-3단계_본문.md) 를 그대로 따른다.**
> 말투·주소 표기·사진 고르는 기준(워터마크·콜라주·검색어)는 거기 한 벌만 둔다.
> **이 문서에는 다른 것만 적는다.**

## 이 단계에서 하는 일

본문 **8개**를 만든다. 1곳 = 1페이지, 낱장은 `본문(장소)`.
**본문 글과 그 장의 배경 사진은 한 묶음이다.** 글을 먼저 확정받고 사진을 따로 묻지 않는다.

## 전달 형식 — 8곳을 한 번에 (2026-08-31 사람 지시)

사람이 준 형식 그대로 낸다. 임의로 순서를 바꾸거나 칸을 빼지 않는다.

```
1. 매장명 [HEADLINE],
📍위치 [SUBHEADLINE]
특징 설명 문구 3~4줄 (요다체로 관광객 타겟의 자연스러운 설명) [BODY]

사진 5장 → <링크 하나>

2. 매장명 [HEADLINE],
📍위치 [SUBHEADLINE]
특징 설명 문구 3~4줄 [BODY]

사진 5장 → <링크 하나>

… 8까지
```

- **8곳을 한 번에** 낸다. 한 곳씩 나눠 보내지 않는다.
- **메시지가 너무 길어지면 4곳씩 끊어 보낸다** (2026-08-31 사람 허용). 1~4 → 5~8 두 번이다.
  끊었으면 **바로 다음 메시지에 나머지를 이어 보낸다.** 앞의 4곳만 보내고 턴을 끝내지 않는다.
- **jpg·png 파일을 첨부하지 않는다. 링크만 준다** (2026-08-31 사람 지시).
- 매장 사이는 빈 줄로 띄운다.
- **정확한 정보 확인 필수** — 매장명·위치·특징을 지어내지 않는다.
  이 축은 가이드가 없으므로 **`place_info`(일본은 `country:"jp"`) 로 실존·주소를 확인한 것만** 적는다.

## 한 장에 들어가는 것

| 칸 | 슬롯 역할 | `slides` 키 | 내용 |
|---|---|---|---|
| 매장명 | **HEADLINE** | `headline` | 가게 이름 (한국어 표기) |
| 📍위치 | **SUBHEADLINE** | `subtext` | 구글맵 주소 그대로, 우편번호(`〒`) 포함. 넘치면 2줄 |
| 특징 설명 | **BODY** | `body` | **3~4줄.** 요다체, 관광객 타겟 |
| 배경 이미지 | (레이아웃 배경) | `user_image_urls` | 사람이 고른 사진 1장 (매장당 후보 5장 중) |

- **키 이름 주의**: SUBHEADLINE 슬롯이 읽는 값은 `subheadline` 이 아니라 **`subtext`** 다.
- **표지엔 SUBHEADLINE 이 없지만 본문 낱장엔 있다** (2026-08-31). 둘을 헷갈리지 않는다.
- 세 칸을 한 칸에 뭉치지 않는다. 낱장에 그 역할 슬롯이 없으면 에러가 아니라 **그 칸만 조용히 사라진다.**

## 사진 — 매장당 5장

**구글맵 3장 + 네이버 검색 2장 = 5장**, 세로형·고화질로 고른다.

| 출처 | 장수 | 도구 |
|---|---|---|
| 구글맵 사진 | **3장** | `place_info(place: "<가게 이름>", country: "jp", photo_count: 8)` |
| 네이버 검색 | **2장** | `search_images(q: "<매장명> <지역>", style: "photo", limit: 10)` |

- 세로형·고화질·워터마크 없는 것·콜라주 제외 — 기준은 [지도_3-3단계_본문.md](지도_3-3단계_본문.md) 그대로다.
- **받은 사진은 Read 로 열어 보고 고른다.** 동영상(`type` 이 `video`)은 걱러낸다.
- **갤러리는 `make_gallery` 의 `galleries` 배열로 한 번에 8개를 만든다.** 여덟 번 나눠 부르지 않는다.
  `caption` 에 출처·구도·비율을 적어 대화에 따로 나열하지 않는다.
- **한 장소에 갤러리를 두 번 만들지 않는다.** 둘이면 「4번」이 어느 쪽 4번인지 알 수 없다.
- 8곳이 각자 자기 장소 사진을 쓴다. 한 장을 돌려쓰지 않는다.
- 3-2(표지·`CTA` 배경)와는 **따로 고른다.** 3-2 는 같은 사진 1장, 본문은 가게마다 다른 사진이다.

## 본문·링크는 낸 자리에서 이 문서에 적는다

**사람에게 본문을 보낸 그 턴에** 아래 「이번 회차 본문」을 채운다. 고르기를 기다리지 않는다.
**8곳이라 지도 축(3곳)보다 메시지가 길어 앞쪽이 더 잘 밀린다.**
사람이 번호를 말하면 그 번호가 가리키는 **전체 주소도 그 자리에서** 적는다.

## → [사용자 선택]

**본문과 사진을 한 번에 고른다.** 매장마다 「본문 쓸지 / 사진 몇 번」을 함께 받는다.

- 글만 고르고 사진을 다음 턴에 다시 묻지 않는다.
- 본문을 고쳐 달라고 하면 고친 뒤 **그 매장의 사진 후보를 다시 붙여** 보여준다.
- 사람이 사진을 안 고르고 **편집기에서 직접 넣겠다**고 하면 그대로 넘어간다.

## 넘길 때 남길 것

- 확정 본문 8개의 **세 칸을 칸 그대로** (4단계가 `headline`·`subtext`·`body` 로 옮겨 담는다)
- 페이지 순서 — 표의 1~8 이 곳 낱장 순번 1~8 이다
- 본문 낱장 = `본문(장소)` × 8
- 각 본문의 **확정 사진 번호와 전체 주소(https://…)**

캐러셀 총 장수 = 표지 1 + 본문 8 + `CTA` 1 = **10장**
