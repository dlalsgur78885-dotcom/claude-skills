작성: solhee 방 / 2026-08-31 회차
주제: **택시에서 기사님께 쓰는 일본어** (2단계 확정)

## 확정 — 4번 (2줄)

```
일본 택시 탈 때
꼭 필요한 말 10개
```

- 확정 훅 문구(줄바꿈 그대로): `일본 택시 탈 때\n꼭 필요한 말 10개`
- **표지 낙장 = `표지_2줄`**

## 2줄 후보 (1줄당 공백 포함 15자 이내) — 고르면 `표지_2줄`

| # | 1줄 | 2줄 |
|---|---|---|
| 1 | 일본 택시에서 | 문 손대면 큰일 나요 |
| 2 | 택시 잡고 나서 | 말문 막히는 3초 |
| 3 | 여기서 세워주세요 | 이 말 하나면 끝나요 |
| **4** | **일본 택시 탈 때** | **꼭 필요한 말 10개** ← 확정 |
| 5 | 기사님이 물어보는데 | 뭐라고 답하죠? |
