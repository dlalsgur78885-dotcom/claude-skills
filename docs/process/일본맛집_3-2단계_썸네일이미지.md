# 일본맛집 — 3-2단계 썸네일 이미지

작성: solhee 방 / 2026-08-31

## 이 단계에서 하는 일

표지와 `CTA` 배경에 깔 사진 **1장**을 정한다. 두 장이 아니라 **같은 1장**이 양쪽에 들어간다.

## 후보 — **음식 5장을 먼저 생성한다. 인물 5장은 요청할 때만** (2026-09-22 변경)

사람 말 그대로 — 「앞으로 일본 맛집 캐러셀에 인물 사진은 미리 생성 안 해줘도 돼. 인물 5장은 생성 버튼을 눌러야 생성할 수 있게」.
**기본은 음식 5장**이고, 그중 1장이 표지·`CTA` 배경이 된다.
(2026-08-31 인물 5장 → 2026-09-09 인물 5장 + 음식 5장 → 2026-09-22 음식 5장 + 인물은 요청 시.)

- **인물 5장은 미리 만들지 않는다.** 원클릭 화면은 「인물 5장 생성」 버튼을 눌렀을 때만 그린다(밤에 미리 만들 때도 음식만).
  디스코드에서는 사람이 인물 사진을 달라고 할 때만 만든다. 음식 링크를 줄 때 「인물 5장도 필요하면 말해 주세요」 한 줄만 붙인다.
  인물을 만들 때는 [방 지침서](솔희_캐러셀기획.md) 「이미지 품질 — 인물 이미지」를 그대로 따른다.
- **검색이 아니라 생성이다.** `generate_image` 의 `prompts` 에 **5개를 한꺼번에** 넣어 동시에 만든다.
  한 장씩 다섯 번 부르면 시간이 다섯 배가 된다.
- **3-1 에서 확정한 훅 문구와 어울리게** 만든다. 음식 5장은 **그 주제의 지역·메뉴에 실제로 있는 음식**으로 보여준다.
- **음식 컷에는 사람을 넣지 않는다.**

### 음식 사진의 결 — 실제 후기 사진처럼 (2026-09-22 사람 지시)

사람 지시 — 「음식 사진을 좀 더 실제 후기 사진처럼」.
잘 차린 광고·잡지 사진이 아니라, **손님이 자리에 앉아 폰으로 찍어 구글 지도·블로그 후기에 올린 사진**이다.

- **시점** — 자리에 앉은 눈높이에서 살짝 내려다본 45°, 또는 상 바로 위에서 내려다본 것. 음식에 바짝 붙인 광고식 접사는 피한다.
- **그 가게 자리가 같이 보인다** — 가게 테이블·쟁반·나무 카운터, 젓가락·물컵·물수건·양념통처럼 실제로 그 자리에 있는 것.
  흰 배경·대리석·린넨 천 같은 촬영용 소품은 쓰지 않는다.
- **나온 그대로** — 담긴 양, 흘린 소스, 김, 부스러기를 다듬지 않는다. 음식을 새로 늘어놓거나 장식을 얹지 않는다.
- **가게 조명 그대로** — 천장 조명·노란 전구·창가 빛. 보정하지 않은 폰 카메라 색. 배경은 살짝만 흐리게(인물 모드처럼 과하게 날리지 않는다).
- **후기 사진 3장(1~3번)은 시점과 음식을 나눈다** — 위에서 본 상차림, 45° 대표 메뉴, 속이 보이게 가른 단면, 곁들이·음료까지 담은 자리처럼.
  같은 접시 클로즈업으로 채우지 않는다. 4·5번은 아래 「누끼 콜라주」다.
- 캔버스가 세로(1080×1350)라 `size` 는 기본값 `1024x1536`(세로)을 쓴다.
- **그림 안에 글자를 넣지 않는다.** 문구는 낱장의 텍스트 슬롯이 채운다. 간판·메뉴판 글자도 마찬가지다.
- **만든 뒤 `local_path` 를 Read 로 열어 본다.** 글자가 박혔거나 훅과 안 맞는 장은 **그 장만 다시 그린다.**

### 음식 5장 중 2장(4·5번)은 누끼 콜라주 (2026-09-22 사람 지시)

사람 말 그대로 — 「일본 맛집 캐러셀 음식 사진 생성에서 5장 중 2장은 누끼 콜라주 이미지 생성하도록」.
**1~3번은 위 후기 사진, 4·5번은 누끼 콜라주**다. 이것도 검색·합성이 아니라 **생성**이다.
실사(구글 지도 사진 누끼 합성)와 비교한 뒤에도 **생성으로 확정**했다(2026-09-22 사람 결정 — 「생성으로 할게」 · 아래 「오사카 혼밥 … 비교」). 실사 콜라주 기능은 원클릭에 붙이지 않는다.

- **모양** — 후기 사진 한 장(그 주제의 대표 메뉴)이 배경으로 화면을 채우고, 그 위에 **그 주제의 다른 메뉴 6~8개를 누끼 딴 스티커처럼** 붙인 한 장.
  누끼는 흰 테두리 없이 깔끔하게 오려져 있고 옅은 그림자가 있다. 크기·각도는 조금씩 다르게.
- **자리** — 누끼는 **가운데까지 화면 전체에 고르게** 흩어 놓는다. 제목 자리로 비워 두는 곳은 없다(2026-09-22 사람 지시 — 처음엔 봇이 「아래 3분의 1 가운데는 제목 자리로 비운다」를 덧붙였으나 사람이 「중앙은 왜 비우냐」며 뺐다).
- **음식** — 배경·누끼 모두 **그 주제의 지역·메뉴에 실제로 있는 음식**이다. 여러 가게를 돌며 먹은 것을 모은 느낌으로, 메뉴가 겹치지 않게 한다.
- **4번과 5번은 배경 메뉴와 누끼 구성을 서로 다르게** 한다.
- 사람·글자·간판·로고를 넣지 않는 것은 후기 사진과 같다.
- 배경 사진의 결(가게 테이블·조명·폰 카메라 색)은 위 「음식 사진의 결」을 따른다.

> 이전의 「`search_images` 검색으로 음식/가게 사진」은 그대로 **폐기**다 — 음식 사진도 **검색이 아니라 생성**이다.
> **3-3 본문 8장만 그 가게 실제 사진**이다. 표지는 생성 이미지, 본문은 실사 — **섞지 않는다.**
> 지도 캐처도 안 쓴다(템플릿 82 에 지도 낱장이 없다).

## 전달 — **링크 하나로** (2026-08-31 사람 지시)

- 만든 사진을 `make_gallery` 로 묶어 **링크 하나**로 준다. 인물을 나중에 만들었으면 음식 5장과 합쳐 다시 묶는다.
- **jpg·png 파일을 같이 보내지 않는다.** URL 을 줄줄이 늘어놓지도 않는다.
- `caption` 에 장마다 무슨 장면인지 한 줄씩 적는다. 인물이 있으면 **인물 → 음식 순**으로 적는다. 콜라주 장은 caption 앞에 `누끼 콜라주 ·` 를 붙인다.

**→ [사용자 선택]** 사람이 만든 사진 중 **1장**을 고른다. 고를 때까지 다음 단계로 넘어가지 않는다.

## 넘길 때 남길 것

- 고른 번호와 **그 이미지 전체 주소(https://…)**
- 도구가 주는 `url` 이 `/api/images/…` 로 시작하는 상대 주소면 **앞에 앱 주소를 붙여** 적어 둔다.
- 4단계에서 `user_image_urls: {"0": …, "9": …}` 로 **표지와 `CTA` 에 같은 1장**을 깔다.
