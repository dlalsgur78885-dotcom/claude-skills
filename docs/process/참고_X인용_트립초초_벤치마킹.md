## 3. 낱장 구조

### 표지

- 배경 = **그 사건의 실제 사진·스샷·밈 한 장**을 꽉 채운다. 생성 이미지가 아니다.
- 훅은 **왼쪽 아래**. 굵은 고딕 흰 글씨 + 아래쪽에만 검정 그라데이션. 배경이 밝으면 **검정 글씨로 바꾸고 그라데이션을 안 쓴다**(12·15번).
- 훅 밑에 작게 `일본 현지인 정보 @trip__chocho`, 왼쪽 위에 `TRIP CHOCHO KRJPMAG` 로고.
- **글만 있는 X 글은 표지에서 읽히게 하지 않는다**(10번) — 글 카드를 작게 넣어 질감으로만 쓰고 훅이 끌어온다.

### 본문

- **검정 배경 + 원본 매체를 가운데 + 그 아래 흰 글씨 가운데 정렬 2~3줄.** 왼쪽 위에 작게 `트립초초 일본 여행 매거진`.
- 원본이 세로로 길면 아래 문구 없이 **카드만** 넣고, 넘치면 다음 장으로 잘라 잇는다(10번은 X 글을 2장에 나눠 실었다).
- **장수 — 2장 7건 · 3장 5건 · 5장 2건 · 6장 1건.** 15건 중 12건이 3장 이하다(표지 포함).
- **CTA 낱장이 15건 전부 없다.** 마지막 장은 마지막 이야기로 그냥 끝난다.
- 질문으로 닫는 장이 댓글을 끌었다 — 4번은 마지막 장 문구가 「일본인들 빼고는 다 읽는다고.. / 읽어지시나요?」 였고 **댓글 229개**로 15건 중 1위다.

### X 글을 쓸 때 — 우리와 반대다

- **X UI 를 살리지 않는다.** 프로필 사진·계정 이름·아이디·인증 배지·게시 시각·좋아요·답글 줄을 **통째로 잘라내고 글 본문 카드만** 흰 박스로 남긴다(10번).
- 카드 맨 윗줄에 X 자체 번역 UI 줄(`원문 언어 일본어 · 원본 보기 ⚙`)이 **그대로 보인다** — X 번역 화면을 그대로 찍은 것으로 보인다(추정 — 확인 불가).
- 「반응」은 답글 3개 카드가 아니라 **웃긴 댓글 하나짜리 스샷**이다(8번 — 인스타 댓글 2개, 아이디·좋아요 수 그대로 노출, 블러 없음).
