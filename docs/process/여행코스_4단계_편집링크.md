## 이 단계에서 하는 일

템플릿 91 에 앞 단계 결과를 넣어 캐러셀을 만들고 **편집 링크**를 전달한다.

- 템플릿: **트래블뷰(여행코스) id 91**. 낱장 이름을 **그 자리에서 다시 조회한다**(사람이 고칠 수 있다).
- 2026-10-16 확인 — 낱장 `표지(여행코스)` · `본문(상황일본어)` · `CTA` 셋. 본문 이름이 「상황일본어」인 것이 맞다.

## 넘길 값 (2박 3일 = 5장 기준, 본문 수는 기간에 따라 1~5)

| 순번 | 낱장 | `slides` | 배경 `user_image_urls` | 사진 칸 `items` |
|---|---|---|---|---|
| 0 | `표지(여행코스)` | `headline` = 확정 훅(줄은 `\n`) | 3-2 에서 고른 사진 | — |
| 1 … N | `본문(상황일본어)` | `headline` = `1일차` · **`tag` = 일자 안내 한 줄** · `subtext`/`body` · `subtext2`/`body2` · `subtext3`/`body3` · `subtext4`/`body4` | 3-2 에서 고른 **같은** 사진 (아래 ⚠) | 코스 사진 4장 |
| N+1 | `CTA` | `headline` = 「<주제> 코스 필요하시면」 (아래 절) | 3-2 에서 고른 **같은** 사진 |— |

- `layout_overrides` 는 **순번을 빠짐없이** 적는다. 빠진 순번이나 한 글자 틀린 이름은 에러 없이 표지가 된다.
- `slides` 에 확정 문구를 **반드시** 넘긴다. 안 넘기면 서버가 문구를 새로 짓는다.
- **`tag` 를 빠뜨리면 낱장 맨 위 흰 띠가 빈 칸으로 나간다** (2026-10-16 추가 — 그 전까지는 안 넘겨서 띠가 비어 있었다).
  3-3 에서 날마다 지은 안내 한 줄을 **글자 그대로** 넘긴다 → [3-3 「일자 안내 띠」](여행코스_3-3단계_본문.md).
- 3-1·3-3 문구는 **글자 그대로** 옮긴다. 기준은 사람에게 마지막으로 보여준 글이다.

## CTA 글 — 「<주제> 코스 필요하시면」 (2026-10-16 사람 지시)

사람 지시 — 「여행 코스 캐러셀 CTA headline 문구는 "주제" 여행 코스 필요하시면 으로」.

- `CTA` 낱장 `headline` 에 **「<주제> 코스 필요하시면」** 한 줄을 넣는다. 전에는 빈 값(`""`)이었다.
- 주제에서 **지역 + 기간(또는 테마)** 만 뽑아 쓴다. 앞의 수식어(「친구와 맛집 털기」 같은 것)는 뺀다.
  기간이 뚜렷한 주제는 기간을, 테마 주제는 테마를 쓰고, 둘 다 애매하면 「여행」을 쓴다.
- 사람이 준 예 (그대로 기준이다):

```
오사카 3박 4일 코스 필요하시면
삿포로 여행 코스 필요하시면
후쿠오카 쇼핑 코스 필요하시면
```

- 글자 칸: x79 · y170 · 폭 920 · 60px · 가운데 정렬 · 흰색 (템플릿 91 `CTA` `text_slots` — 2026-10-16 조회).
- **한 줄로 끝낸다.** 폭 920 ÷ 60px 라 공백 뺀 **15자 안쪽**이 한 줄이다(계산값이다 — 넘칠 것 같으면 편집기에서 눈으로 본다).
  두 줄이 되면 낱장 그림의 **「댓글 남겨주세요!」와 겹친다.**
- 마침표·물음표·이모지는 붙이지 않는다.

## ⚠ 본문 사진 4장은 `items` 순서가 자리 순서와 다르다

사진은 `slides[i].items[j].image_url` 로 넘기고, 서버는 **템플릿에 저장된 사진 칸 배열 순서**대로 짝짓는다.
템플릿 91 의 배열 순서는 **오른쪽아래 → 왼쪽위 → 왼쪽아래 → 오른쪽위** 다(2026-10-16 조회).

| `items` 자리 | 들어가는 칸 | 그 칸의 코스 |
|---|---|---|
| `items[0]` | x602 y971 (오른쪽 아래) | **코스 4** |
| `items[1]` | x77 y180 (왼쪽 위) | **코스 1** |
| `items[2]` | x77 y707 (왼쪽 아래) | **코스 3** |
| `items[3]` | x602 y444 (오른쪽 위) | **코스 2** |

- 그러니 `items: [코스4, 코스1, 코스3, 코스2]` 로 넘긴다. 코스 순서대로 넣으면 **사진이 엉뚱한 설명 옆에 붙는다.**
- `user_item_image_urls = {순번: {0: 코스4, 1: 코스1, 2: 코스3, 3: 코스2}}` 로 넘겨도 같다(이쪽은 `items` 에 빈 객체 4개가 먼저 있어야 한다).
- **이 순서는 템플릿에 저장된 배열이라 사람이 스튜디오에서 칸을 다시 그리면 바뀐다.** 회차마다 템플릿을 조회해 빈 사진 칸의 x·y 순서를 보고 이 표를 맞춘다.
- 사진은 400×220 칸에 **cover-crop** 으로 들어간다 — 가로 16:9 로 만든 장을 넘긴다.

## 본문·CTA 배경에도 표지 사진을 깐다 (2026-10-16 사람 지시로 확정)

- `본문(상황일본어)` 배경은 **흰색 단색 + 검정 70% 오버레이**로 설정돼 있다. 렌더러는 **사진 배경이 있을 때만 오버레이를 깐다**(`carousel_renderer.py`).
- 그래서 **사진을 안 넘기면** 배경이 흰색으로 남고, 흰 글씨는 자동으로 검정으로 뒤집히지만 **가운데 세로선과 점 4개(흰색 장식)는 그대로 흰색이라 사라진다.**
- 배경 사진을 넘기면 검정 70% 가 전체에 깔려 **어두운 판**이 되고 흰 글씨·흰 장식이 다 보인다 → **표지와 같은 사진을 넘긴다.**
- **사람 지시(2026-10-16)** — 「표지 이미지로 본문, CTA 배경으로 깔도록」. 세 자리 모두 3-2 에서 고른 **한 장**이다.
- 검정 70% 막과 흰 장식이 실제로 어떻게 보이는지는 **1회차에서 본문 한 장을 렌더해 눈으로 보고**, 다르면 이 절을 고친다.

## 검정 막 · 그림자

- 표지와 CTA 는 템플릿 오버레이가 **「없음」**이라 서버가 검정 막을 얹지 않는다 — **지울 막이 없다.**
- 본문의 검정 70% 는 **템플릿이 정한 것이라 그대로 둔다**(글이 읽히게 하는 막이다).
- 글자 그림자는 템플릿이 켠 것만 들어간다. 표지 훅에는 그림자가 켜져 있다.

## 만든 뒤 확인

- 저장본 글을 다시 읽어 **보여준 문구와 한 글자씩 대조**한다(`GET /carousels/<id>` 의 `canvas_slides`).
- 편집기에서 모든 장을 보고 **사진이 빠진 칸 · 엉뚱한 자리에 간 사진 · 넘친 글칸**을 본다.
  특히 **코스 설명과 사진이 짝이 맞는지** — 위 순서 표를 틀리면 여기서 드러난다.
- CTA 글이 **한 줄인지**, 아래 「댓글 남겨주세요!」 와 겹치지 않는지 본다. 두 줄이면 문구를 줄인다.
- 넘친 칸이 있으면 3-3 문구를 다시 짓는다(봇이 손으로 자르지 않는다).
