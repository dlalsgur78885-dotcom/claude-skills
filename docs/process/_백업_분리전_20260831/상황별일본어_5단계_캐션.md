# 상황별 일본어 — 5단계 캐션

## 확정 캐션

```
손 들고 "저기요…" 하다가 결국 못 부른 적 🙋

일본 식당은 벨이 없는 데가 많잖아요.
점원은 저 끝에 있고, 눈은 안 마주치고,
그 사이 옆 테이블은 벌써 음식이 나오고.

근데 부르는 말이 따로 있어요.
그거 하나만 알면 그다음은 쉬워요.
언제 불러야 하는지, 아직 못 정했을 땐 뭐라고 하는지,
추가 주문하고 계산할 때까지 10문장 담았어요.

다음 여행 때 메뉴판 앞에서 얼지 않으려면 저장 📌
같이 갈 사람 태그해서 미리 연습시키기 👇

#일본여행 #여행일본어 #일본어회화 #일본식당 #여행꿀팁
```

## 원칙 점검

| 원칙 | 어떻게 |
|---|---|
| 오픈닝 | 못 부른 경험을 한 줄로 먼저 던지고 저장 유도는 맨 뒤로 |
| 이모지 | 🙋 📌 👇 — 부르는 장면·저장·소환 자리에만 (앞 회차 🍺 와 걹치지 않게) |
| 본문 | 설명 없이 장면만. 「못 부른 적」으로 공감 열고 짧은 문장으로 끊음 |
| CTA | 저장 + 친구 태그 두 개, 이번 주제(같이 식당 감)에 맞춰 새로 썼 |
| 해시태그 | 5개 |
| 예시 문장 금지 | 일본어·읽는 법을 한 줄도 안 옮기고 **범위만** 말함("부르기부터 계산까지 10문장") |
