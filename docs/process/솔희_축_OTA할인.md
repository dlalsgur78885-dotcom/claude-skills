## 템플릿은 99·101·102 한 벌이다 (2026-11-05 솔희 지시)

축마다 있던 템플릿 대신 **표지 `트래블뷰(표지)` 99 · 본문 `트래블뷰(본문)` 101 · CTA `트래블뷰(CTA)` 102**
한 벌을 쓴다. 바탕은 101 이고 표지·CTA 는 `@99:<낱장>`·`@102:<낱장>` 으로 빌린다.

- 아래에서 「템플릿 84」·`GET /templates/84` 로 적힌 자리는 **101**(표지는 99 · CTA 는 102)로 읽는다.
  낱장 값은 2026-11-05 에 한 벌과 **값이 같은지 대조**해 옮긴 것이다 — 글칸 위치·크기·폰트·장식이 같다.
- 옛 템플릿 84 는 **지우지 않았지만 쓰지 않는다**(솔희 지시). 이미 만든 캐러셀은 그대로 열린다.
- 회차를 시작할 때 낱장 이름을 다시 볼 때는 `GET /api/templates/layouts` 로 99·101·102 를 본다.

```
1 주제 → 2 표지 훅 → 3 표지 사진·본문 → 4 스튜디오 생성·편집 링크(캡션 포함)
```

> **2026-10-26 — 캡션은 4단계에서 함께 짓는다.** 캐러셀을 만들 때 `canvas_data.caption` 에 전문을 넣어 저장하고,
> 편집 링크와 같은 메시지에 캡션을 담아 `[6단계 — 세션 끊기]` 로 닫는다. 5단계 메시지는 없다(문구 규칙은 5단계 문서 그대로).
> 공통 규칙은 [방 지침서 「캡션은 4단계에서 함께 짓는다」](솔희_캐러셀기획.md).
