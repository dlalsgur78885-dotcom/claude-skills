주제: **일본인이 하는 혼잣말** (2단계 확정 · 사람이 직접 지정)

## 확정 — 6번 (3줄) (2026-09-02)

```
일본인이
혼자 있을 때
하는 말 10개
```

- 확정 훅 문구(줄바꿈 그대로): `일본인이\n혼자 있을 때\n하는 말 10개`
- **표지 낱장 = `표지_3줄`**
- 훅이 「말 10개」라 고 있으므로 **3-3 본문은 10개**를 그대로 맞춘다.

**같은 단어를 두 줄에 겹쳐 쓰지 않는다** (2026-09-03 사람 지시 · 세 축 공통).

- 2줄이든 3줄이든 **한 후보 안에서** 같은 말을 두 번 넣지 않는다.
- 조사·어미만 다른 것도 겹친 것으로 본다 (일본인이 / 일본인은).
- 겹치는 후보는 그대로 올리지 말고 **그 줄을 고쳐서** 낸다.
- `generate_copy` 프롬프트에도 이 규칙을 적어 보낸다 — codex 는 이 문서를 읽지 않는다.

### 지금까지 쓴 훅의 형식 — 5틀 (2026-09-03 사람이 준 11개를 정리)

새 후보는 이 다섯 틀 안에서 낸다. 예시는 모두 실제로 썼던 훅이다.

| 틀 | 뼈대 | 실제 예시 |
|---|---|---|
| **A. 대상 지목** | [누가]가 / [어떻게] 하는 / [무엇] N | 한국인이 / 많이 실수하는 / 일본어 10 · 일본 MZ가 / 실제로 사용하는 / 일본어 9 · 일본인이 / 혼자 있을 때 / 하는 말 10 |
| **B. 권위 부정** | [교과서·번역기·한국인]은 모르는 / [어떤] / [무엇] N | 교과서에도 없는 / 웃길 때 쓰는 / 일본어 10 · 한국인은 / 절대 모르는 / 현지 일본어 10 · 번역기는 모르는 / 일본 신조어 |
| **C. 상황 재현** | [하고 싶은 것] / [막히는 것] / 그럴 때 한마디 | 라멘은 먹고 싶고 / 기계는 못 읽고 / 그럴 때 한마디 |
| **D. 금기·반전** | [쓰면 안 되는 · 오글거리지만] / [어디의] / [무엇] N | 실제로 쓰면 안되는 / 일본 영화 속 / 야쿠자 일본어 8 · 오글거리지만 / 의미있는 / 일본 명언 8 |
| **E. 실전 지목** | [언제] 써먹는 / 실전 [무엇] | 전화할 때 써먹는 / 실전 일본어 · 나만 몰랐던 / 일본 식당에서 / 제일 많이 쓰는 말 |

**어느 틀을 쓰든 지킬 것.**

- **마지막 줄에 「무엇 + 숫자」를 놓는다.** `일본어 10` `하는 말 10` `일본 명언 8`.
  이 숫자가 3-3 본문 개수다 — 훅에 10을 썼으면 본문도 10개를 만든다.
  개수를 못 정하는 주제만 숫자를 뺀다 (`전화할 때 써먹는 / 실전 일본어`).
- **숫자 뒤에 「개」를 붙이지 않는다** (2026-09-04 사람 지시). `하는 말 10` 이지 `하는 말 10개` 가 아니다.
  「개」·「가지」·「선」 같은 단위를 숫자 뒤에 달지 말고 숫자로 끝낸다.
  `generate_copy` 프롬프트에도 이 줄을 적어 보낸다 — codex 는 이 문서를 읽지 않는다.
  ⚠ 이 문서 위쪽 지난 회차 확정본에 `하는 말 10개` 가 남아 있지만 그건 규칙이 바뀌기 전 기록이다. 따라 하지 마라.
- **줄은 의미 단위로 끊는다.** [누가] / [어떤] / [무엇 N]. 한 줄에 두 덩어리를 넣지 않는다.
- **강조어는 한 후보에 하나만.** 절대 · 제일 · 실제로 · 진짜 중 하나. 두 개 겹치면 광고처럼 읽힌다.
- 앞 줄에서 세운 것을 뒷줄에서 뒤집는다(B·D). 뒤집을 것이 없으면 A 로 간다.
- 바로 위의 **같은 단어 겹쳐 쓰지 않기** 규칙은 여기에도 그대로 적용된다.
- `generate_copy` 로 후보를 받을 때 **이 표의 틀 이름과 뼈대를 프롬프트에 적어 보낸다.**

**→ [사용자 선택]** 사람이 하나를 고른다. 고른 줄 수가 표지 낱장을 정한다. 다음 단계로 넘어가기 전에 받는다.

**넘길 때 남길 것** — 3-1 산출물에 이 두 줄을 적는다. 4단계가 이걸 그대로 읽어 쓴다.
