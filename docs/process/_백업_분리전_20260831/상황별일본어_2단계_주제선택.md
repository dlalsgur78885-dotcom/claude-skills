# 상황별 일본어 — 2단계 주제 선택

작성: solhee 방 / 2026-08-31 회차

## 확정 주제

**택시에서 기사님께 쓰는 일본어** (1단계 후보 6번)

- 사람이 1단계 후보 중 6번을 골랐다.
- 범위: 탑승 직전부터 내릴 때까지 — 행선지 말하기, 자동문·트렁크, 길 안내, 세워달라는 위치, 결제·잔돈·영수증.
- 일본 택시의 문화 차이(문을 손으로 안 열기, 팁 없음)도 본문에 섮을 수 있다.

## 템플릿 — 고정

| 항목 | 값 |
|---|---|
| 템플릿 | 트래블뷰 (id 80) |
| 표지 낙장 | 3-1에서 고른 훅의 줄 수에 따라 `표지_2줄` 또는 `표지_3줄` |
| 본문 낙장 | `본문(상황일본어)` — 고른 문장 수만큼 |
| 마지막 낙장 | `CTA` |
| 표지·CTA 배경 | 3-3에서 고른 사진 **같은 1장** |
