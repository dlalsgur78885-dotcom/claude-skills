# 개발 요청 — 「찾은 사진을 갤러리 링크로 묶는 도구」

요청자: solhee 방 (캐러셀기획) · 2026-08-28
상태: **완료** (2026-08-28) — `make_gallery` 로 붙음. 지도 3-3 지침서도 「링크 하나」로 교체됨.

## 뭐가 필요한가

`place_info` · `search_images` 로 **찾은 사진 URL 여러 개를 링크 하나로 묶어 주는 봇 도구**.

지금은 `generate_image` 로 **새로 그린** 이미지에만 갤러리 링크가 붙어 나온다.
조회로 찾은 사진은 URL 문자열로만 오기 때문에 대화창에 긴 URL 을 줄지어 뿌려야 한다.

## 왜 필요한가

2026-08-28 사람 지시로 **지도 축 3-3단계** 전달 형식이 바뀌었다
(→ [지도_3-3단계_본문.md](지도_3-3단계_본문.md)).

> 「매장당 이미지 5개씩(구글맵3장, 네이버 검색 2장/세로형/고화질) 찾아서 **하나의 링크**」

매장 3곳 × 5장 = **한 턴에 URL 15개**다. 지금대로 나열하면

- 디스코드 메시지가 길이 제한에 걸려 잘리고(실제로 2026-08-27 회차에 두 메시지로 나뉘었다),
- 사람이 URL 을 하나씩 눌러야 사진을 볼 수 있어 고르는 데 오래 걸린다.

갤러리 링크면 **한 화면에서 5장을 나란히 보고 번호로 고를 수 있다.**

## 서버는 이미 되어 있다

`backend/app/api/galleries.py` 에 그대로 쓸 수 있는 것이 있다.

| 항목 | 내용 |
|---|---|
| 생성 | `POST /api/galleries/` · 본문 `{title, images:[{url, prompt}]}` · 인증 필요 (`:45-62`) |
| 응답 | `{id, count}` — `id` 는 64비트 난수 |
| 보기 | `GET /api/galleries/{id}` · **인증 없음** · HTML 그리드, 장마다 번호·설명·저장 버튼 (`:65-129`) |
| 저장 | 새 테이블 없이 `app_settings` 에 `gallery:<id>` 키로 얹힌다 |

**외부 URL 이라도 된다.** `_render` 가 `<img src="{url}">` 로 그대로 뿌려주므로
구글맵·네이버 사진 주소를 넣어도 그대로 보인다 (앱에 올리는 과정이 필요 없다).

## 그래서 뭐를 만들어 달라는 것인가

위 API 를 부르는 **봇 도구 하나**. 이름은 알아서 — 예: `make_gallery`.

```
make_gallery  [create]  사진 URL 여러 개를 링크 하나로 묶어 보여준다.
  인자:
    title:  string?          갤러리 제목 (예: "1. 미키케이란 — 사진 5장")
    images: [{url, caption}] url 은 필수. caption 은 그 장 설명
                             (예: "구글맵 · 점포 정면 · 세로")
  돌려줌: 갤러리 전체 주소 (https://…/api/galleries/<id>)
```

- `caption` 은 서버의 `prompt` 필드에 그대로 넣으면 된다. 그 값이 갤러리 에서 장마다 설명으로 보인다.
- 돌려주는 주소는 **전체 주소(https://…)** 로 준다. 상대 경로로 주면 봇이 매번 앞에 앱 주소를 붙여야 한다.
- 한 번에 여러 갤러리를 만들 수 있으면 더 좋다 (매장 3곳 = 갤러리 3개를 한 턴에 만든다).
  안 되면 세 번 부르면 되므로 필수는 아니다.

## 붙으면 바로 쓰이는 곳

- **지도 3-3단계** — 매장당 사진 5장을 링크 하나로. 지침서에 이미 「링크 하나」로 적어 둔다.
- 그 밖에도 사진 후보를 여러 장 보여주는 자리면 어디든 같이 쓸 수 있다.

## 그때까지는

지도 3-3 은 URL 을 매장별로 5줄씩(`1-A`~`1-E`) 나열해 보낸다.
매장 3곳을 한 메시지에 담는 것은 그대로 지킨다.
도구가 붙으면 지침서의 「링크 하나」 규칙으로 바로 넘어간다 — 사람에게 다시 묻지 않는다.

## 완료 (2026-08-28)

`make_gallery` 도구로 붙였다. 요청한 스펙 그대로다.

```
make_gallery  [create]
  title:     string?          갤러리 제목
  images:    [{url, caption}] 한 개 만들 때
  galleries: [{title, images}] 여러 개를 한 번에 (요청서의 "있으면 더 좋다")
  돌려줌: url (전체 주소) · count / 실패한 갤러리만 error
```

- `caption` 은 서버의 `prompt` 필드로 실어 갤러리 화면에 설명으로 뜬다 — 확인함.
- 구글맵 외부 URL 을 그대로 넣어 열리는 것 확인(앱 업로드 없음).
- 매장 3곳을 한 번에 만들고, 잘못된 URL 이 섞인 갤러리만 실패로 표시되는 것 확인.
- 지도 3-3 지침서의 임시 형식(`1-A`~`1-E` 나열)은 폐기하고 「링크 하나」로 교체했다.
